# «Заказы» — приложение учёта заказов фрилансера (PWA)

Ставится на главный экран Android, работает полностью офлайн, ничего никуда не
отправляет: все данные лежат в самом телефоне (IndexedDB). Сервера, регистрации и
интернета не нужно — интернет нужен только один раз, чтобы приложение загрузилось.

---

Правило простое: **данные** живут в `db/`, **расчёты** — в `lib/`, **внешний вид** —
в `ui/`, **экраны** собираются из готовых кирпичиков. Если нужно поменять цвет —
`src/index.css`. Поменять формулу денег — `src/lib/calc.ts`. Поменять текст на
экране — соответствующий файл в `src/screens/`.

## Как считаются деньги

В базе хранится только сумма, аванс и **снимок процента комиссии** (`commissionRate`)
на момент создания заказа. Остальное считается на лету (`src/lib/calc.ts`):

| Величина | Формула |
|---|---|
| Комиссия | `сумма × процент` |
| На руки | `сумма − комиссия` |
| Остаток (сколько должны) | `сумма − аванс` |
| Дней до срока | `дедлайн − сегодня`, не считается для «Оплачен» и «Отказ» |

Именно поэтому смена процента у источника **не трогает старые заказы**: у каждого
заказа свой сохранённый процент.

## Запуск на компьютере (если захочешь править)

```bash

npm install       # один раз

npm run icons     # перерисовать иконки приложения
```

## Публикация на GitHub Pages — что нажать

Сборка и публикация делаются сами при пуше в ветку `main` — за это отвечает файл
`.github/workflows/deploy-orders-app.yml`. Один раз нужно включить Pages:

1. Открой репозиторий на GitHub → вкладка **Settings** (сверху справа, шестерёнка).
2. В левом меню найди раздел **Pages**.
3. В блоке **Build and deployment** → **Source** выбери **GitHub Actions**
   (не «Deploy from a branch»). Сохранять отдельно ничего не нужно.
4. Вернись на вкладку **Actions** (сверху). Там будет запуск
   «Публикация приложения „Заказы“ на GitHub Pages».
   Если запуска нет — нажми на этот workflow слева и кнопку **Run workflow** справа.
5. Дождись зелёной галочки (1-2 минуты). Ссылка появится в самом низу шага
   «Публикация», а также в **Settings → Pages** сверху.

Адрес будет такой:

```
https://caesart966-web.github.io/first_reposirtory/
```

> Если когда-нибудь переименуешь репозиторий — поменяй одну строку `base`
> в `orders-app/vite.config.ts` на новое имя, иначе стили и иконки не найдутся.

### Установка на телефон

1. Открой ссылку в **Chrome на Android**.
2. Либо нажми в приложении «Ещё → На главный экран → Установить»,
   либо меню Chrome (три точки) → **«Установить приложение»**.
3. Иконка появится на рабочем столе. При запуске — **без адресной строки**.
4. Дальше интернет не нужен: включи авиарежим и проверь — приложение открывается,
   показывает и добавляет заказы.

Установка возможна только по HTTPS — GitHub Pages его даёт, поэтому всё работает.

## Резервная копия

Настройки → **Экспорт в JSON** — скачивается файл со всеми данными. Он же
восстанавливается кнопкой **Импорт из JSON** (полностью заменяет текущие данные).
**Экспорт заказов в CSV** — таблица для Excel и Google Таблиц.

Данные лежат в браузере телефона. Если удалить приложение вместе с данными сайта или
почистить данные Chrome — они пропадут. Раз в месяц делай экспорт: файл маленький.

## Уведомления

Включаются вручную в «Ещё → Уведомления» (разрешение спрашивается только там).
Напоминают утром: что горит сегодня, что просрочено и какие заказы висят в статусе
«Сдан» дольше недели. Работают, пока приложение хоть иногда открывается — это
локальные напоминания без сервера. Если браузер их не поддерживает, приложение
работает как обычно.

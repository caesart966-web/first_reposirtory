# В каких СРО состоят компании

Принимает список компаний (название + ИНН) и отвечает, в каких
саморегулируемых организациях они состоят.

Источник — **открытые реестры**:

* [reestr.nostroy.ru](https://reestr.nostroy.ru) — строители;
* [reestr.nopriz.ru](https://reestr.nopriz.ru) — проектировщики и изыскатели.

Оба бесплатны, ключей не требуют, суточных лимитов нет.

## Запуск

**Windows.** Перетащите Excel со списком компаний на `НАЙТИ-СРО.bat`.
При первом запуске он сам создаст окружение и поставит зависимости.

**Командная строка.**

```bash
pip install -r requirements.txt
python3 find_sro.py компании.xlsx
```

Результат — `компании_СРО.xlsx` рядом с исходным файлом.

## Входной файл

Нужны только **название и ИНН**. Ни порядок колонок, ни наличие шапки
значения не имеют: колонки определяются по содержимому, а ИНН проверяется
контрольной суммой. Повторяющиеся ИНН запрашиваются один раз.

| | |
|---|---|
| `ООО "ОЛЛИ ИТ"` | `7813692784` |
| `ООО "ЭКГК ФАКТСТРОЙ"` | `7817158012` |

## Что в результате

| Колонка | Содержание |
|---|---|
| Название компании | из входного файла, ОПФ сокращена до `ООО «…»`, `АО «…»` |
| ИНН | как во входном файле |
| СРО | наименование организации |
| Рег. номер СРО | `СРО-С-410-16122014` |
| Реестр | НОСТРОЙ или НОПРИЗ |
| Статус членства | как в реестре: «Является членом СРО», «Исключён» |
| Дата вступления | из реестра |
| Результат проверки | пусто, если всё нашлось |

**Компания может состоять сразу в нескольких СРО** — например, в строительной
и в проектной. Тогда на неё приходится несколько строк, по одной на членство.
Поэтому опрашиваются оба реестра, а не первый ответивший.

## «Не состоит» и «не проверено» — разные вещи

Это главное правило отчёта, и оно важнее скорости.

* **Розовая строка** — реестры ответили, записи нет. Компания действительно
  не состоит в СРО. Это достоверный отрицательный ответ.
* **Жёлтая строка** — реестр не ответил (недоступен, таймаут, сбой сети).
  Проверка **не состоялась**. Такую строку нужно перезапустить позже.

Смешивать их нельзя: выдать «не состоит в СРО» там, где проверка не
выполнялась, значит подсунуть выдумку вместо факта. В сводке после запуска
эти два числа тоже разведены.

## Частота запросов

По умолчанию один запрос в секунду — реестры общие и публичные, частить
невежливо. Для больших списков можно ускорить:

```bash
python3 find_sro.py компании.xlsx --rps 3
```

## Тесты

```bash
python3 -m unittest discover -s tests
```

Сеть не нужна: ответы реестра подменяются образцами.

# Исходники фирменного знака

| Файл | Что это |
| --- | --- |
| `logo-original.pdf` | макет логотипа в том виде, в каком его прислал заказчик |
| `logo-original.png` | тот же знак картинкой, извлечён из PDF (508×552) |
| `logo-mark.svg` | векторная версия — она и стоит на сайте |

Векторная версия получена трассировкой картинки: `potrace` по увеличенному
в 4 раза чёрно-белому оттиску, затем чистка и приведение к `currentColor`.
Цвет исходника — `#03213D`.

На сайте знак живёт в двух файлах, оба надо менять вместе:
`src/components/LogoMark.astro` (шапка, подвал, превью) и
`public/favicon.svg` (иконка вкладки).

Эти файлы здесь лежат как архив: сайт их не использует и в сборку они
не попадают.

# Фирменные файлы

## ⚠️ Знаков здесь ДВА, и на сайте стоит второй

| Файл | Что это | На сайте |
| --- | --- | --- |
| `logo-original.pdf` | макет, который заказчик прислал ПЕРВЫМ: монограмма «Б» с колонной, цвет `#03213D` | **нет** |
| `logo-original.png` | тот же знак картинкой, извлечён из PDF (508×552) | **нет** |
| `logo-mark.svg` | векторная версия того же «Б» (трассировка `potrace`) | **нет** |

Заказчик прислал несколько логотипов и выбрал из своего набора другой —
монограмму, в которой читаются «Н» и латинская N. Она и стоит на сайте.
Файлы выше остались архивом первого варианта; раньше в этом README было
написано, что `logo-mark.svg` «стоит на сайте», — это устарело и вводило
в заблуждение: взяв его, вы поставили бы на визитку не тот знак.

**Действующий знак живёт в разметке, а не картинкой**, и менять его нужно
сразу в двух местах: `src/components/LogoMark.astro` (шапка, подвал)
и `public/favicon.svg` (значок вкладки).

## Готовые файлы действующего знака

Собираются командой **`npm run brand`** (`scripts/make-brand.mjs`).

| Файл | Размер | Для чего |
| --- | --- | --- |
| `znak.svg`, `znak-belyy.svg` | вектор | только монограмма; белая — для тёмного фона |
| `znak.png` | 1024×1024 | знак с прозрачным фоном |
| `logotip.png` | 552×172 | знак + «НОРМА» + подпись, прозрачный фон |
| `logotip-belyy.png` | 552×172 | то же для тёмной подложки |
| `logotip.pdf` | вектор | для типографии: шрифты вшиты, не рассыплется |
| `avatar.png` | 512×512 | аватар в мессенджерах и соцсетях |
| `pochta-shapka.png` | 1200×280 | шапка письма (600×140 на экране) |

**Руками эти файлы не правьте.** Цвета берутся из `src/styles/global.css`,
телефон и название — из `src/config/site.ts`, контуры знака — из
`LogoMark.astro`. Нарисованный однажды и положенный в папку логотип
разойдётся с сайтом при первой правке телефона или оттенка, и заметить
это будет некому. Поменяли телефон — прогоните `npm run brand` заново.

Файлы этой папки в сборку сайта не попадают: сайт рисует знак сам.

# Реестр членов Ассоциации «Петровское объединение строителей»

Сводная таблица по выгрузке реестра с сайта СРО (СРО-С-303-22122020).

## Что получилось

`Реестр_членов_СРО_ПОС.xlsx` — 1590 записей, два листа:

- **Реестр** — таблица с колонками: № · Полное наименование · Сокращённое наименование ·
  ИНН · Контактные телефоны · Дата вступления · Дата прекращения · Статус.
  Закреплённая шапка, автофильтр, статус выделен цветом.
- **Сводка** — счётчики (формулами, пересчитываются при правках таблицы).

## Исходные данные

Четыре файла выгрузки: `register-1-500`, `register-501-1000`, `register-1001-1500`,
`register-1501-1590`. В каждом одна запись занимает несколько строк (решения, проверки,
страхование), данные о самой компании — только в первой строке блока; строка считается
началом записи, если заполнены «N п/п» и «Полное наименование».

Соответствие колонок выгрузки:

| В таблице            | В выгрузке                          |
|----------------------|-------------------------------------|
| Дата вступления      | Дата регистрации в реестре СРО      |
| Дата прекращения     | Дата прекращения членства           |
| Статус               | производный: пусто = «Действующий»  |

## Телефоны

Приведены к единому виду `+7 (код) номер`. Нормализация консервативная: номер
переписывается, только если разбирается однозначно и все цифры исходной строки
израсходованы без остатка (`phones.py`), иначе значение остаётся ровно таким, как в
выгрузке. Обрабатываются несколько номеров в одной ячейке, общий код города для
нескольких местных номеров, четырёх- и пятизначные коды, добавочные номера.

`verify_phones.py` проверяет, что цифры результата идут в том же порядке, что в источнике
(допускается пропуск кода страны 7/8 и унаследованного кода города).

## Как пересобрать

```bash
pip install openpyxl
python3 extract.py        # выгрузки -> rows.json
python3 phones.py         # нормализация телефонов -> rows.json
python3 verify_phones.py  # контроль целостности номеров
python3 build.py          # rows.json -> Реестр_членов_СРО_ПОС.xlsx
```

Скрипты ожидают файлы `register-*.xlsx` в текущем каталоге.

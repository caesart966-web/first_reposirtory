# Обои с кэшбэком для iPhone

Таблица кэшбэка по банкам — полупрозрачное стекло по центру поверх своего
фона. Категории по-русски, рядом процент и тонкая line-иконка одного набора
(Lucide, лицензия ISC). Цвет стекла и текста подбирается под фон.

## Как сделать обои

1. Скрины категорий из банков → файл `wallpapers/<месяц>.json` (образец —
   `wallpapers/demo-light.json`): банк, категории, проценты.
2. Фон → `backgrounds/` (JPG, PNG или WebP; в git не попадает — личное фото).
3. Сборка:

   ```bash
   npm install          # один раз
   node render.mjs wallpapers/2026-10.json
   ```

   В `out/` появятся обои (`2026-10.png`, ровно в разрешение экрана),
   предпросмотр с часами экрана блокировки (`-preview.png`) и отчёт
   (`.report.json`): раскладка, плотность стекла, контраст, что склеено.

Другой iPhone: `--device iphone-17-pro` (список — `lib/devices.mjs`).
По умолчанию — 17 Pro Max, 1320×2868.

## Если фон — снимок экрана блокировки

На снимке поверх обоев нарисованы часы, дата, строка состояния и кнопки —
положенные в обои, они встанут под настоящие часы iOS вторым слоем.
Их нужно убрать:

1. Маска — белым всё, что нарисовал iOS (`backgrounds/<фон>.mask.png`).
   Цифры часов рисуются толстыми линиями по их осям, с запасом 4 px на
   ободок стекла: маска своя у каждого снимка, время на нём разное.
   Строку состояния закрывать только надписями и значками, а не полосой
   во всю ширину: у края экрана нейросети не за что зацепиться, и полоса
   выходит серой, со швом.
2. `python3 scripts/inpaint.py снимок.png маска.png backgrounds/fon.png --model big-lama.pt`
   — восстановление нейросетью LaMa (модель ~200 МБ, в git не идёт:
   https://github.com/Sanster/models/releases/download/add_big_lama/big-lama.pt;
   нужен PyTorch). Вне маски остаются пиксели оригинала.

## Где стоит таблица

`placement` в обоях или `--placement` при сборке:

- `center` — по центру экрана (по умолчанию);
- `under-clock` — под крупными часами iOS 26: они опускаются почти
  до середины экрана, и таблица по центру ложится на цифры. Здесь
  таблица между низом часов и кнопками, и буквы мельче — места меньше.

Колонок две, если в одну не помещается; дальше — плотнее строки, уже поля,
и только потом мельче буквы. На узком экране (393 pt) упирается всё
в ширину: длинные названия вроде «Перекрёсток Доставка» не сокращаются.

## Поля обоев

| Поле | Что значит |
| --- | --- |
| `device` | экран iPhone (`lib/devices.mjs`), по умолчанию 17 Pro Max |
| `background` | путь к фону от файла обоев |
| `placement` | `center` или `under-clock` (выше) |
| `bgPosition` | какая часть фона видна, если он другой пропорции (`"50% 30%"`) |
| `title` | строка над таблицей (`"Кэшбэк · октябрь"`), `null` — без неё |
| `phrase` | фраза под таблицей; `phraseFont`: `"serif"` (курсив) или `"sans"` |
| `duplicates` | категория у нескольких банков: `"keep"` — у всех, `"best"` — только где % выше |
| `sort` | `"percent"` — по убыванию процента (по умолчанию), `"none"` — как на скрине |
| `banks[].categories[]` | `{ "name", "percent" }` — название как на скрине; можно `icon` (имя из Lucide) и `label` (другая подпись) |

## Названия и дубли

Подписи банков и категорий — **ровно как на скринах**, без сокращений
и замен («Продуктовые магазины», «ЖКХ», «Hoff»). Словарь
`lib/categories.mjs` подписи не меняет: он даёт иконку и узнаёт дубли.

- один банк на нескольких скринах — один раздел;
- одна категория внутри банка — одна строка, при разных процентах
  остаётся больший;
- одна категория у разных банков под разными подписями («Здоровье
  и медицина» и «Медицинские услуги») — дубль по полю `duplicates`,
  но у каждого банка своя подпись;
- название сразу из двух категорий («Театры и кино») с каждой из них
  дублем не считается.

Новая категория без иконки получает запасную (`tag`), отчёт об этом говорит —
добавьте правило в `lib/categories.mjs` с иконкой из того же набора Lucide.

## Почему стекло такой плотности

Плотность не задаётся руками: скрипт снимает обои без текста и под каждой
строкой меряет контраст по настоящим пикселям — с размытием и бликами,
как их нарисовал браузер. Стекло делается ровно настолько плотным, чтобы
самая слабая строка давала 4,5:1 (иконки — 3:1), и не плотнее — иначе это
уже плашка, а не стекло. Светлое оно или тёмное — решает яркость фона
под таблицей; оттенок берётся из его среднего цвета. Фраза лежит прямо
на фоне: её цвет выбирается по фону под ней, а при нехватке контраста
за буквами появляется мягкий ореол.

Таблица стоит по центру, не выше ~42 % экрана и не заходит под часы
(верхние 29 %) и кнопки внизу; много категорий — две колонки, потом
кегль чуть меньше.

`npm run demo` — два тестовых фона (светлый и тёмный) и обои на них.

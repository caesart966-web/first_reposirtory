# Обои с кэшбэком

Обои для Android: категории повышенного кэшбэка нескольких банков собраны
в одну таблицу на полупрозрачном стекле поверх фона. Фон рисуется здесь же —
готовая картинка не нужна.

Готовые файлы лежат в `out/`. Их можно просто скачать и поставить на телефон.

```
out/wallpaper-midnight-1080x2400.png    тёмно-синий, основной
out/wallpaper-graphite-1080x2400.png    графит, без цвета
out/wallpaper-indigo-1080x2400.png      насыщенный синий
out/wallpaper-paper-1080x2400.png       светлый, тёплая бумага
```

## Как поменять содержимое

Всё, что показано на обоях, лежит в одном файле — `data/wallpaper.json`.
Больше нигде цифры и названия не написаны.

```json
{
  "size":   { "width": 1080, "height": 2400 },
  "background": "midnight",
  "caption": "Кешбэк · сентябрь",
  "card":   { "width": 700, "offsetY": 0 },
  "banks": [
    { "name": "Ozon Банк", "brand": "#005BFF",
      "categories": [ { "title": "Супермаркеты", "percent": 3 } ] }
  ]
}
```

- `background` — `midnight`, `graphite`, `indigo` или `paper`.
  Чтобы взять свою фотографию вместо рисованного фона, добавьте
  `"backgroundFile": "bg/моя-картинка.jpg"` — цвет и контраст таблицы
  подстроятся под неё сами.
- `brand` — фирменный цвет банка. Пишется настоящий, как в его логотипе;
  под фон он подгоняется при сборке (см. ниже).
- `offsetY` — сдвиг таблицы вверх (отрицательное) или вниз в пикселях,
  если на домашнем экране она попадает под иконки.
- `icon` у категории — необязателен: иконка подбирается по названию.
  Если подобралась не та, впишите ключ вручную, список — в `src/icons.mjs`.

Пересобрать:

```bash
npm run build                      # один файл по data/wallpaper.json
npm run all                        # все четыре фона
node render.mjs --preset paper --width 1440 --height 3200
npm run check                      # проверка контраста
```

## Почему сделано именно так

**Цвет банка подгоняется под фон, а не берётся как есть.** Жёлтый Т-Банка
`#FFDD2D` на светлом фоне даёт 1.4:1 — надпись не читается вовсе; синий Ozon
`#005BFF` на тёмном даёт 2.1:1. Поэтому цвет разбирается на тон, насыщенность
и светлоту (OKLCH), и меняется **только светлота** — ровно настолько, чтобы
вышло 4.6:1. Тон остаётся банковским: синий остаётся синим, жёлтый жёлтым,
на светлой бумаге он темнеет до охры. Правится в `src/adapt.js`.

**Заливка стекла подбирается замером, а не на глаз.** Под карточкой берутся
настоящие пиксели фона, усреднённые так, как их усреднит размытие, и ищется
наименьшая заливка, при которой **самая тёмная и самая светлая** точка под
карточкой всё ещё дают тексту 4.5:1. Проверяются все точки, а не среднее:
среднее проходит и там, где текст тонет в одном углу.

Снизу заливка ограничена 18%. На тёмном фоне подбор честно выдавал 6% —
контраст проходил, но карточка переставала быть карточкой: оставались буквы
в воздухе. Стекло должно быть видно как предмет.

**Кадр снимает браузер.** Ради `backdrop-filter`: настоящее размытие
подложки под стеклом сложением слоёв в графической библиотеке не повторить.

**Фон рисуется, а не берётся стоковый.** Он всегда точно в разрешении
телефона (ничего не растягивается), в центре у него ровное поле — стекло
размывает то, что под ним, и пёстрый центр превращается в грязь, — и его
можно пересобрать под другой экран, не ища заново исходник. У градиентов
добавлено зерно: без него на 8-битном экране видны кольца.

**Повторы объединяются.** Одинаковая категория внутри банка схлопывается
в одну строку (остаётся больший процент); категория, которая есть у обоих
банков, остаётся у того, где процент выше. Что именно объединилось —
печатается при сборке.

## Проверка

`npm run check` (`scripts/test-contrast.mjs`) снимает каждый фон **дважды** —
с надписями и без — и меряет те самые пиксели, поверх которых легла каждая
строка. 140 замеров на четырёх фонах, порог 4.5:1 для текста и 3:1 для
иконок. Считать по задуманным цветам нельзя: размытие, насыщенность стекла
и зерно фона меняют то, что получилось, а `adapt.js` работает по приближению
до съёмки — проверка обязана мерить результат.

Она же ловит длинное название категории, которое вёрстка обрежет
многоточием: на обоях это заметят только на телефоне.

## Шрифты

Inter (насыщенность 100–900) — весь набор; Golos подставляется только там,
где у Inter нет знака. Оба лежат в `fonts/`, лицензия SIL OFL.

## Грабли, на которые уже наступали

- **ID СРО ≠ регистрационный номер.** `reestr.nostroy.ru/sro/247` — это ID,
  а `СРО-С-230-07092010` — номер. Их не связать вручную; `--sro-number`
  переводит одно в другое сам.
- **Реестры игнорируют `pageSize`** и отдают по 20 записей, не сообщая об
  этом. НОПРИЗ из-за этого качался 2 часа вместо получаса.
- **Реестры молча игнорируют незнакомый фильтр** и возвращают общий список
  вместо отфильтрованного — отсюда правило качать целиком и сверять локально.
- **ИНН в Excel хранятся числом** — у регионов 01–09 теряется ведущий ноль.
- **Вид деятельности СРО — по её регистрационному номеру** (`СРО-П-` /
  `СРО-И-`), а не по названию: ООО «Проектстрой» в изыскательской СРО иначе
  уезжает в проектирование.
- **Списка СРО у НОСТРОЯ нет ни по одному известному адресу API**, и перебор
  по `/api/sro/{id}/member/list` тоже не отвечает — ID приходится смотреть
  руками на сайте. Найденные записаны выше; для новых СРО открыть карточку и
  взять число из адреса.
- **На странице СРО есть кнопка «Выгрузить реестр членов СРО»** — если она
  отдаёт файл, это надёжнее любого API.
- **Долгие команды молчали** и выглядели зависшими — теперь печатают счётчик
  строк каждые 25 тысяч.

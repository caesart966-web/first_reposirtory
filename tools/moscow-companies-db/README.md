# mosstroybase — база строительных компаний Москвы

CLI-инструмент, который собирает базу **юридических лиц с московским адресом**
и строительными ОКВЭД (стройка, проектирование, инженерные изыскания), находит
их **телефоны и e-mail** и выгружает общую базу в CSV/XLSX.

## Откуда данные

| Шаг | Источник | Что даёт |
|---|---|---|
| `build` | [Реестр МСП ФНС](https://www.nalog.gov.ru/opendata/7707329152-rsmp/) (официальные открытые данные, бесплатно) | базовый список юрлиц: ИНН, ОГРН, название, регион, ОКВЭД |
| `enrich-egrul` | ЕГРЮЛ (бесплатное JSON-зеркало egrul.itsoft.ru) | e-mail, статус (действует/ликвидировано), полный адрес, ОКВЭД |
| `enrich-checko` | [Checko API](https://checko.ru/integration/api) (нужен бесплатный ключ, ~100 запросов/сутки) | телефоны, e-mail, сайт |
| `enrich-sites` | сайты компаний (страницы контактов) | телефоны, e-mail |

Отбор по умолчанию: регион **77 (Москва)**, ОКВЭД-2 **41, 42, 43**
(строительство зданий, инженерных сооружений, специализированные работы),
**71.11** (архитектура), **71.12** (инженерные изыскания и проектирование).
Совпадение проверяется и по основному, и по дополнительным кодам.

## Установка

```bash
cd tools/moscow-companies-db
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Использование (конвейер)

```bash
# 1. Скачать выгрузку реестра МСП (~1.5–2 ГБ, обновляется ежемесячно)
python -m mosstroybase fetch-rsmp --out data/rsmp.zip

# 2. Отобрать московские строительные/проектные/изыскательские юрлица в SQLite
python -m mosstroybase build --rsmp-file data/rsmp.zip

# 3. Обогатить из ЕГРЮЛ: e-mail, статус, адрес (небыстро — пауза между запросами)
python -m mosstroybase enrich-egrul

# 4. (опционально) Телефоны и сайты через Checko API
export CHECKO_API_KEY=ваш_ключ
python -m mosstroybase enrich-checko --limit 100

# 5. (опционально) Добрать контакты со страниц сайтов компаний
python -m mosstroybase enrich-sites

# 6. Сводка и выгрузка
python -m mosstroybase stats
python -m mosstroybase export --csv moscow_stroy.csv --xlsx moscow_stroy.xlsx \
    --only-active --with-contacts-only
```

Все команды принимают `--db путь.sqlite3` (по умолчанию `mosstroybase.sqlite3`
в текущей папке). База наполняется инкрементально: повторный запуск дополняет
записи, дубликаты схлопываются по ИНН, контакты из разных источников
объединяются. Обогащение можно прерывать и продолжать — уже обработанные
компании помечены источником и повторно не запрашиваются.

Полезные варианты:

```bash
# Пробный прогон на 200 компаниях
python -m mosstroybase build --rsmp-file data/rsmp.zip --limit 200

# Свои ОКВЭД и регион
python -m mosstroybase build --rsmp-file data/rsmp.zip --okved 41 42 43 71.1 --region 77

# Добавить крупные компании (их нет в реестре МСП) списком ИНН
python -m mosstroybase import-inn --file inns.txt   # затем enrich-egrul
```

## Если главное — телефоны (Checko)

Телефоны в основном приходят из Checko API, а его бесплатный тариф — ~100
запросов в сутки. Программа тратит квоту экономно: по умолчанию
`enrich-checko` пропускает ликвидированные компании и те, у кого телефон уже
найден, а первыми запрашивает компании с **основным** строительным ОКВЭД.
Обработанные помечаются и повторно не запрашиваются, поэтому рабочий режим —
просто запускать команду раз в сутки:

```bash
export CHECKO_API_KEY=ваш_ключ
python -m mosstroybase enrich-checko --limit 100   # ежедневно
python -m mosstroybase enrich-sites                # бесплатно добирает контакты с сайтов,
                                                   # которые дал Checko
```

Математика: 100 запросов/сутки ≈ 36 тыс. компаний в год. Если база в десятки
тысяч компаний и телефоны нужны быстро, варианты:

- **платный тариф Checko** (тысячи запросов в сутки — см. цены на checko.ru);
- **готовая выгрузка ОФДата** (ofdata.ru — поставщик данных Checko): продают
  базу организаций с контактами целиком, для массовой задачи это дешевле и
  быстрее, чем API;
- сузить базу перед обогащением: `--only-active`, только нужные ОКВЭД,
  категории «малое»/«среднее» вместо «микро».

## Ограничения и честные оговорки

- **Реестр МСП покрывает только малый и средний бизнес.** Крупных застройщиков
  и генподрядчиков добавляйте через `import-inn` — остальное дотянет ЕГРЮЛ.
- **Телефонов в ЕГРЮЛ почти нет** (e-mail — есть у заметной части компаний).
  Основные источники телефонов — Checko API и сайты компаний.
- Зеркало egrul.itsoft.ru — сторонний бесплатный сервис: работайте с паузами
  (`--delay`), не гоняйте десятки тысяч запросов подряд.
- Полные коммерческие альтернативы, если нужен масштаб: платная выгрузка ЕГРЮЛ
  ФНС, DaData, Контур.Фокус, СПАРК.

## Правовые заметки

- Сведения ЕГРЮЛ и реестра МСП — открытые данные; контактные данные юрлиц
  не являются персональными данными. Если включаете ИП (`--include-ip`),
  их данные — персональные: соблюдайте 152-ФЗ.
- Массовые рассылки по собранным адресам подпадают под закон «О рекламе»
  (ст. 18: реклама по сетям связи — только с согласия адресата). База
  предназначена для аналитики рынка и адресной B2B-работы.
- Уважайте условия использования сторонних API и сайтов.

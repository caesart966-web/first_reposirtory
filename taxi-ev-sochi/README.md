# Электромобили в таксопарке Сочи — дерево решения и презентация

Тестовое задание на анализ и визуализацию данных: к консультанту обратился владелец
таксопарка в Сочи (около 200 автомобилей) с вопросом, стоит ли покупать электромобили.
В папке — дерево решения, расчётная модель и презентация на 10 слайдов, собранная
в присланном корпоративном шаблоне.

## Ответ на вопрос кейса

**Весь парк переводить нельзя, но пилот на 20 машин имеет смысл.**

1. **Выгодно.** За 3 года и 270 тыс. км электромобиль дешевле бензинового
   на **531 тыс. ₽** на автомобиль. Экономия набегает в пути: 4,4 ₽/км против
   7,9 ₽/км. Порог окупаемости — 120 тыс. км, то есть 16 месяцев работы такси.
2. **Но выполнимо только в малом объёме.** 200 электромобилей требуют
   **1,36 МВт** присоединённой мощности для ночной зарядки. Краснодарский край
   энергодефицитен — 580 инвестпроектов уже стоят в очереди за мощностью.
   Реалистичный лимит для базы парка — 200–300 кВт, то есть 20–35 машин.
3. **И только при трёх условиях.** Субсидия Минпромторга 925 тыс. ₽ на машину
   (без неё проект теряет 394 тыс. ₽ на авто); техприсоединение получено
   до заказа автомобилей; арендная ставка водителю поднята примерно
   на 600 ₽/сутки — иначе экономию на топливе заберёт водитель, а не парк.

Ключевой вывод модели: **ни один операционный риск по отдельности не делает проект
убыточным — убыточным его делает только отсутствие субсидии.**

## Структура презентации

Логика слайдов повторяет логику дерева: главный вопрос → три условия
(выгодно / выполнимо / устойчиво) → рекомендация.

| № | Слайд |
|---|---|
| 1 | Титульный |
| 2 | Executive Summary |
| 3 | Дерево решения |
| 4 | Выгодно? Юнит-экономика ДВС против электромобиля |
| 5 | Выполнимо? Мощность сети, запас хода, сервис |
| 6 | Устойчиво? Чувствительность и три риска |
| 7 | Рекомендация: пилот, дорожная карта, критерии Go / No-Go |
| 8 | Разделитель «Приложение» |
| 9 | Приложение 1. Допущения модели и их источники |
| 10 | Приложение 2. Рынок электромобилей и регулирование |

## Как пересобрать

```bash
cd taxi-ev-sochi
pip install python-pptx
python3 model.py       # печатает расчёты TCO, окупаемость и чувствительность
python3 build_deck.py  # собирает output/…pptx из assets/template.pptx

# PDF (нужен LibreOffice)
soffice --headless --convert-to pdf --outdir output \
        "output/Электромобили_в_таксопарке_Сочи.pptx"
```

## Правила, которым следует презентация

Из инструкции к заданию и из служебных слайдов шаблона:

- первый содержательный слайд — Executive Summary;
- логика презентации повторяет логику дерева;
- заголовок слайда — вывод, не более двух строк;
- технические и методические слайды вынесены в приложение;
- шрифт в теле слайда 10–12 пт;
- у каждого графика — название по принципу «что, где, когда, в какой размерности»,
  размерность набрана серым;
- гистограммы с накоплением, значения от большего снизу к меньшему сверху,
  цвета от тёмного к светлому, белая обводка сегментов, сумма над столбцом;
- вся визуализация построена самостоятельно (никаких вставленных картинок);
- внизу каждого слайда — источники названиями компаний и ресурсов, без ссылок.

## Модель и её честность

Модель детерминированная: горизонт 3 года, 270 тыс. км, один автомобиль,
сравниваются Lada Vesta и Evolute i-Joy — обе модели допущены к работе в такси
после 01.03.2026.

В приложении 1 каждое допущение помечено как **факт** (есть источник) или
**оценка** (принято рабочей группой). Сознательно не учтены НДС и страхование
(одинаковы для обоих вариантов), а также ускоренный износ шин у электромобиля
(минус) и региональные льготы по транспортному налогу (плюс) — величины малы
и разнонаправлены.

Проверить любой сценарий можно, поправив словарь `P` в `model.py` и запустив файл:
он печатает таблицу TCO, точку безубыточности и восемь стресс-сценариев.

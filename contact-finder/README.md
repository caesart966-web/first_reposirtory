# contact-finder — пробив контактов компаний по ИНН

Программа берёт список «Организация + ИНН» и ищет **телефоны, e-mail и сайты**
сразу по нескольким источникам, сверяя каждую находку с ИНН, чтобы не путать
однофамильцев. Результат — готовый Excel.

> **Почему это отдельная программа, а не «внутри чата».** В облачной среде, где
> меня запускают, весь внешний интернет закрыт egress-политикой на уровне
> инфраструктуры (заблокированы rusprofile, checko, list-org, 2ГИС, Яндекс и
> вообще все сайты). Обойти это изнутри нельзя и не нужно. Правильное решение —
> запускать пробив **на вашем компьютере**, где блокировок нет. Этим и занимается
> эта программа.

---

## Быстрый старт

1. Установите **Python 3.9+** (python.org → «Add Python to PATH» при установке).
2. Положите ваш список рядом как `company_list.xlsx`
   (1-й столбец — название, 2-й — ИНН, первая строка — шапка).
3. Запустите:
   - **Windows:** двойной клик по `run.bat`
   - **macOS/Linux:** `bash run.sh`

Через несколько минут появится `contacts_result.xlsx`.

Вручную то же самое:

```bash
pip install -r requirements.txt          # необязательно, но лучше с ними
python find_contacts.py --in company_list.xlsx --out result.xlsx --delay 2 -v
```

Программа запускается и **без единой зависимости** — на голой стандартной
библиотеке (тогда результат сохранится в CSV, а не XLSX).

## Что внутри и как оно ищет

Для каждой компании последовательно опрашиваются источники, пока не найдётся
надёжный телефон:

| # | Источник | Как ищет |
|---|----------|----------|
| 1 | **Агрегаторы** (rusprofile, list-org, audit-it, checko, sbis, ngee) | прямые URL карточки по ИНН, а если не вышло — через веб-поиск |
| 2 | **Официальный сайт компании** | находит домен поиском, заходит на `/contacts`, `/kontakty` и снимает телефоны |
| 3 | **Гео-справочники** (2ГИС, Zoon, Yell, Orgpage) | по названию и адресу из ЕГРЮЛ; для 2ГИС — точный Catalog API, если задан ключ |

**Главный принцип — проверка ИНН.** Телефон записывается в «зелёную» зону,
только если на странице реально найден искомый ИНН (сравнение идёт по цифровому
следу страницы, поэтому переживает любую вёрстку). Если контакт нашёлся, но ИНН
не подтверждён (например, однофамилец), он не теряется — попадает в столбец
**«Отброшено (проверить)»** для ручной сверки.

Телефоны нормализуются (`+7 (931) 238-95-81`), мусор (ОГРН, КПП, БИК, расчётные
счета) отсекается контекстным фильтром.

## Файл результата

Лист **«Контакты»** — по строке на компанию:
№, Организация, ИНН, Телефон(ы), E-mail, Сайт, Адрес, Директор, Источник(и),
Достоверность, Отброшено. Зелёный — телефон найден; жёлтый — есть кандидат на
проверку; красный — ничего.

Лист **«Сводка»** — статистика и пояснение логики.

## Ключи API (необязательно, повышают полноту)

Задаются переменными окружения. Без них программа тоже работает.

| Переменная | Зачем | Где взять |
|------------|-------|-----------|
| `DGIS_API_KEY` | точные телефоны из 2ГИС | dev.2gis.ru |
| `YANDEX_XML_USER`, `YANDEX_XML_KEY` | точный поиск по РФ | Яндекс XML (yandex.ru/dev/xml) |
| `CF_PROXY` | ходить через прокси | ваш прокси-провайдер |

```bash
# пример (macOS/Linux)
export DGIS_API_KEY=xxxxxxxx
python find_contacts.py --in company_list.xlsx --out result.xlsx
```

## Параметры командной строки

```
--in FILE          входной xlsx/csv (обязательно)
--out FILE         выходной файл (по умолчанию contacts_result.xlsx)
--delay 2          пауза между запросами к одному хосту, сек (вежливость)
--timeout 25       таймаут запроса, сек
--retries 3        число попыток на запрос
--workers 1        параллельные потоки (наращивать только с прокси!)
--limit N          обработать первые N строк (для теста)
--check-inn        проверить контрольные суммы ИНН и выйти
-v, --verbose      подробный лог
```

## Как добавить свой источник

1. Создайте `cf/sources/мой.py` с функцией
   `def мой(company, fetcher, cfg) -> list[Found]: ...`
2. Впишите её в список `SOURCES` в `cf/sources/__init__.py`.

`Found` — это то, что удалось снять с одной страницы: телефоны, почта, сайт и
флаг `inn_confirmed`. Слияние и приоритеты — на движке, вам достаточно вернуть
находки.

## Ограничения и этика

- Инструмент собирает **только открытые** контакты юрлиц/ИП из публичных
  источников — то же, что видно вручную. Не обходит платные подписки, капчи и
  авторизацию.
- Соблюдайте `robots.txt` и здравые паузы (`--delay`), не устраивайте лавину
  запросов. По умолчанию 1 поток и пауза — так безопаснее для вас и для сайтов.
- Телефона часто нет в принципе: в ЕГРЮЛ он не хранится, а у молодых микро-фирм
  веб-присутствия может не быть. Пустой результат — это честный результат, а не
  ошибка программы.

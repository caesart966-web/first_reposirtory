Буклет правится в самих операторах показа текста PDF (тот же шрифт, кегль и место); картинки презентации —
рендеры листов буклета 300 и 160 dpi, их положение находится по совпадению со старым буклетом, и переносятся
только изменившиеся пиксели. PNG презентации пережимаются без потерь: 167 → 9,5 МБ.

Сверка фасадов 18.11.2026 (`tools/facades.py`): геометрия ВПМ совпадает с листами 8–9 буклета —
48 × 24 м по осям, панели и пояса по высоте, ленточное остекление +4,92…+6,12, двери, козырьки,
ворота 3,6 × 3,7 м в осях 5–4, лестница на кровлю, водостоки. Фасад 1-9 модели — вид с −Y после
поворота на −17°, 9-1 — с +Y, А-Д — с +X, Д-А — с −X.

Требования к моделям — совместное распоряжение ДИТ и ДГП от 18.08.2026 (приложения 1 и 2, схема geojson —
приложение 10 к требованиям к ВПМ). Координаты в МСК-77 переводятся в WGS-84 той же проекцией, что в
`../agr-shchelkovskoe-17a/tools/osm_base.py`.

## Запуск

```bash
python3 tools/fix_models.py <ВПМ здания> <ВПМ благоустройства> <НПМ> <выход>
```

Нужны `numpy` и `Pillow`; для проверки — `../agr-shchelkovskoe-17a/tools/check_vpm.py` (умеет FBX из Blender:
нормали IndexToDirect, подвал SDK) и `ufbx`. После правки архивы подписывает ЭП заявителя
(имя подписи — имя архива + `.sig`).

Буклет и презентация (нужны `pikepdf`, `pymupdf`, `opencv-python`):

```bash
python3 tools/fix_booklet.py <буклет 13.10>.pdf <новый буклет>.pdf
python3 tools/fix_presentation.py <буклет 13.10>.pdf <новый буклет>.pdf <презентация 13.10>.pptx <новая>.pptx
```

Фасады для сверки с буклетом (нужны еще `scipy`):

```bash
python3 tools/facades.py <распакованная ВПМ>/SM_<адрес>.fbx <распакованная ВПМ> <префикс вывода>
```

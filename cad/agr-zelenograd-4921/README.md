Требования к моделям — совместное распоряжение ДИТ и ДГП от 18.08.2026 (приложения 1 и 2, схема geojson —
приложение 10 к требованиям к ВПМ). Координаты в МСК-77 переводятся в WGS-84 той же проекцией, что в
`../agr-shchelkovskoe-17a/tools/osm_base.py`.

## Запуск

```bash
python3 tools/fix_models.py <ВПМ здания> <ВПМ благоустройства> <НПМ> <выход>
```

Нужны `numpy` и `Pillow`; для проверки — `../agr-shchelkovskoe-17a/tools/check_vpm.py` (умеет FBX из Blender:
нормали IndexToDirect, подвал SDK) и `ufbx`. После правки архивы подписывает ЭП заявителя
(имя подписи — имя архива + `.sig`).

Фасады для сверки с буклетом (нужны еще `scipy`):

```bash
python3 tools/facades.py <распакованная ВПМ>/SM_<адрес>.fbx <распакованная ВПМ> <префикс вывода>
```

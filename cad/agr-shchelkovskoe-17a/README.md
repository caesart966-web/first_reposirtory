## Архивы ВПМ

`fix_vpm.py` правит оба архива (здание и благоустройство):

* из метаданных FBX убираются пути к рабочим папкам автора;
* коллизии благоустройства пересобираются. В исходном файле четыре блока из пяти
  были невыпуклыми (один выходил за свою форму на 9 м), в первом оставались
  четырёх- и пятиугольники, имена шли без `SM_`. Теперь это 27 выпуклых блоков
  `UCX_SM_<адрес>_Ground_001…027`, которые повторяют рельеф с отклонением до 1 см,
  не пересекаются и закрывают участок целиком;
* белый слой цвета вершин у сетки благоустройства убирается (на вид не влияет,
  у принятой модели здания его нет);
* две текстуры благоустройства из палитрового режима переводятся в RGB 8 бит на канал;
* в geojson здания обновляются `s_obsh` и `s_naz`.

`fbxio.py` читает и пишет двоичный FBX 7.4 без потерь: файл без правок собирается
побайтно таким же, как исходный. `check_vpm.py` проверяет результат: имена, треугольники,
выпуклость и замкнутость коллизий, плитки UDIM и текстуры, счётчики объектов, а также
открывает файл независимой библиотекой `ufbx`.

## Порядок запуска

```bash
python3 tools/patch_ifc.py <исходные AR/PS/BiO.ifc> out_ifc
cp <исходные>/BiO.ifc out_ifc/ && python3 tools/patch_ifc_names.py out_ifc
python3 tools/fix_vpm.py <папка здания> <папка благоустройства> out_vpm 520.63
python3 tools/check_vpm.py out_vpm/SM_ShchelkovskoeShosse_17A_1 out_vpm/SM_ShchelkovskoeShosse_17A_1_Ground
python3 tools/build_sagr.py <распакованный комплект> out_ifc out_sagr 520.63 РФ-77-4-52-3-05-2026-11594-0
```

Нужны `numpy`, `scipy`, `shapely`, `Pillow`, `ifcopenshell`, `ufbx`; для схем и буклета ещё
`matplotlib`, `trimesh`, `pyproj`, `networkx`, `python-pptx` и LibreOffice.

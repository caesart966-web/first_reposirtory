# Строй-Герой — прототип сайта

Статичный HTML-макет нового сайта сети магазинов строительных материалов
«Строй-Герой» (Петропавловск-Камчатский и Елизово). Показывается заказчику
на утверждение, потом переносится в тему OpenCart (`.twig`).

## Как открыть

Двойной клик по `index.html`. Сервер, сборка и интернет не нужны.
Важно: папка `assets` должна лежать рядом с html-файлами, иначе пропадут
стили и логотип. Если открывать html прямо из ZIP-архива, Windows достаёт
только один файл — архив нужно сначала распаковать.

Для быстрого показа есть `stroigeroi-preview.html` — все четыре страницы,
стили, скрипт и логотип в одном файле. Ему ничего рядом не нужно: открывается
откуда угодно, можно переслать одним вложением. Для переноса в OpenCart
берутся обычные страницы, а не он.

## Файлы

```
stroigeroi-site/
├── index.html      Главная: промо, категории, товары, магазины, преимущества
├── catalog.html    Категория «Гипсокартон»: фильтры, сортировка, сетка, пагинация
├── product.html    Карточка товара: галерея, цена, вкладки, похожие товары
├── contacts.html   Три магазина, общие контакты, форма вопроса
└── assets/
    ├── style.css   Все стили одним файлом, переменные в :root
    ├── app.js      Минимальный ванильный JS: меню, выпадашки, вкладки, счётчик
    └── logo.png    Эмблема, 480×480, прозрачный фон
```

Шапка и подвал одинаковые и физически повторены в каждом файле — правку нужно
повторить во всех четырёх. В теме OpenCart это станет одним `header.twig`.

## Что использовано из фирменного стиля

- **Белый фон.** Красный больше не заливает шапку — он остался только акцентом:
  кнопка «Найти», кнопки покупки, ценники, плашка «Скидка».
- **Диагональные полоски** нарисованы кодом (`repeating-linear-gradient`),
  картинки нет. Работают дозированно: лента 10 px по верхнему краю шапки,
  подложка промо-блока, засечка слева от заголовков секций, полоска над подвалом
  и над карточками магазинов. Основное полотно страницы белое.
- **Логотип** всегда на белом: в шапке, в белом круге поверх полосок в промо-блоке,
  в подвале. На цветную подложку не ставится.
- **Иконки** — инлайн SVG, все 24×24, толщина линии 1.75. Эмодзи и иконочных
  шрифтов нет.
- **Шрифт** системный, Google Fonts не подключаются — на российском хостинге
  внешние шрифты могут не грузиться.

## Переменные для переноса в OpenCart

Всё, что нужно поменять при смене фирменных цветов, лежит в `:root`
в начале `assets/style.css`:

| Переменная | Значение | Где используется |
|---|---|---|
| `--sg-blue` | `#010b87` | кнопки, ссылки, заголовки, иконки |
| `--sg-red` | `#d81921` | «Найти», «В корзину», цены, плашки скидок |
| `--sg-white` | `#ffffff` | фон |
| `--sg-ink` | `#1b1b1f` | основной текст |
| `--sg-muted` | `#63636e` | второстепенный текст |
| `--sg-line` | `#e6e6ec` | границы |
| `--sg-stripes` | градиент | тонкие ленты полосок |
| `--sg-stripes-lg` | градиент | крупные полоски промо-блока |

Дальше в том же блоке — шкала отступов (`--sp-*`), радиусы (`--r-*`) и тени.
Хардкода цветов в разметке нет.

## Что в макете не работает

Это концепт: корзина, избранное, сравнение, вход, фильтры, пагинация и форма
обратной связи присутствуют визуально, но ничего не отправляют. При клике
внизу всплывает короткая подсказка, что действие в макете не работает.

## Чего не хватает от заказчика

Ничего из этого не выдумано — на всех местах в макете стоят заметные
пунктирные плейсхолдеры.

| Что нужно | Где стоит плейсхолдер |
|---|---|
| **Прайс: 18 позиций** (название, цена, описание, категория, бренд, фасовка) | карточки товаров на всех страницах, фильтр «Бренд», счётчики количества товаров |
| Фотографии товаров | плитки «фото из прайса», галерея на карточке товара |
| Режим работы трёх магазинов | выпадашка «График работы», карточки магазинов, «Контакты» |
| Условия доставки | блок «Почему к нам» на главной |
| Действующие акции и размеры скидок | блок «Почему к нам» на главной |
| Реквизиты: юрлицо, ИНН, ОГРН | подвал, страница «Контакты» |
| Ключи/координаты для Яндекс.Карт | карточки магазинов и общая карта на «Контактах» |

## Что проверено

Все четыре страницы прогнаны в Chromium на 360, 768, 1280 и 1920 px:
горизонтальной прокрутки нет, ошибок в консоли нет, битых внутренних ссылок нет,
у всех картинок есть `alt`, фокус с клавиатуры видно. Меню каталога, выпадающие
списки, мобильное меню, вкладки и счётчик количества работают и закрываются по Esc.

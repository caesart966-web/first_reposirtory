# Черновые варианты главной (октябрь 2026)

Три направления главной, сделанные, пока ждали варианты заказчика из GPT:

- `1-vitrina.html` — «Витрина»: светлые плитки, объёмные значки;
- `2-geroi.html` — «Герой»: фирменный тёмно-синий, герой с баннера во весь рост;
- `3-kamchatka.html` — «Камчатка»: небо, вулканы и город, плоские цветные значки.

**Отложены.** Заказчик прислал свою концепцию: шапка в две строки, вулкан
и герой на первом экране, плитки разделов с товарами, карточки
«калькулятор / акции / магазины» и полоса преимуществ. Главная делается
по ней, эти страницы остались как черновики и на сайт не идут.

Шапка и подвал у вариантов — из `../index.html`, своё у каждого только
содержимое `<main>`. Товары — пустые места: выдуманных товаров в макете
нет. Цифры (с 2007 года, 10 000+ товаров, 150 000 клиентов в год,
50+ сотрудников) — со страниц заказчика «О компании» и «Юрлицам».

## Как пересобрать

```bash
python3 variants/make.py                  # из stroigeroi-site
python3 -m http.server 8000               # шрифты по file:// браузер не грузит
# открыть http://127.0.0.1:8000/variants/1-vitrina.html
```

Исходники — `src/main-N.html` (метки вида `{{cats-v1}}` раскрывает make.py),
стили — `variants.css`.

У Russo One зарезервировано имя «Russo», а урезанный шрифт по OFL считается
изменённым — поэтому внутри файла он переименован в SG Display Draft.

Герой (`img/mascot.webp`, `img/mascot-bust.webp`) вырезан из баннера
заказчика `../assets/banner.jpg`.

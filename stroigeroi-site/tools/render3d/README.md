# Картинки главной: своя трёхмерная съёмка

Первый экран и плитки разделов по концепции заказчика (октябрь 2026) просят
фотографий: вулкан над городом, стройка, предметы в разделах. Чужих фотографий
взять негде (фотобанки из среды сборки закрыты, а выдуманный «наш магазин»
на стоковом снимке был бы неправдой), поэтому всё снято в Blender по коду.
Это иллюстрации, а не снимки: на сайте они ничего не утверждают про товар.

**С 06.10.2026 фон первого экрана — фотография** Петропавловска с Корякским
вулканом (прислана 06.10.2026, `assets/home/scene-*`). Снятая здесь сцена
на телефоне выглядела искусственной, а на фото заказчик узнаёт свой город.
Пейзаж и стройка ниже остались для истории, плитки разделов и карточки —
по-прежнему отсюда. **Внимание:** `make-home-images.py` пишет и `scene-*` —
запущенный целиком, он затрёт фотографию снятой сценой. Исходник фото —
`kamchatka-photo.jpg` здесь же; `scene-*` из него — `python3 photo-scene.py`.

Что откуда:

| Файл | Что снимает |
|---|---|
| `hero_plate.py` + `terrain.py`, `city.py`, `noise.py` | небо, Корякский и Авачинский (высота ×1,6, как на открытках), сопки, город у бухты |
| `hero_site.py` + `parts.py` | каркас дома, башенный кран, забор из синего профлиста, поддоны с кирпичом, газоблоком и цементом |
| `products.py` | предметы для плиток: кирпич, дрель, молоток с рулеткой, розетка с лампочкой, смеситель, крепёж, радиатор, тачка, каска; калькулятор с чертежом и ведро краски с валиком для карточек |
| `make-home-images.py` | сводит сцену (облака, стройка поверх пейзажа), режет размеры, пишет AVIF и WebP в `assets/home/` |

Герой и печать на первом экране — с баннера заказчика (`assets/banner.jpg`,
`assets/logo.png`), герой вырезан заранее (`variants/img/mascot.webp`).

## Как пересобрать

```bash
pip install bpy==5.0.1          # Blender как модуль Python, нужен Python 3.11
cd tools/render3d
mkdir -p out
python3 hero_plate.py -- w=2400 h=1000 s=96 grid=hi out=out/plateA.png
python3 hero_plate.py -- w=2400 h=1000 grid=hi mode=mask out=out/plateA-mask.png
python3 hero_site.py -- w=1000 h=1150 s=128 out=out/plateB.png
for n in bricks drill hammer socket faucet bolts radiator wheelbarrow hardhat calculator paint; do
  python3 products.py -- name=$n res=640 s=128 out=out/prod-$n.png
done
python3 make-home-images.py out     # из этой папки; пишет в ../../assets/home
cd ../.. && node build.mjs          # копирует картинки в тему
```

На четырёх ядрах пейзаж считается около 15 минут, стройка — минуту,
каждый предмет — около минуты. Параметры сцены (`az=` и `el=` — солнце,
`lens=`, `shift=` — камера, `slew=` — куда повёрнута стрела крана)
передаются после `--`.

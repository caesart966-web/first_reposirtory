# Как собрать приложение для коллег

Программу можно превратить в **одну самостоятельную программу** (.exe), которую
коллеги запускают двойным щелчком — **без установки Python и чего-либо ещё**.

Есть два пути. **Способ 1 проще**: ничего собирать не нужно, программу собирает
сам GitHub, а вы просто скачиваете готовое.

---

# Способ 1. Скачать готовую программу с GitHub (проще всего)

Ничего устанавливать не нужно — ни Python, ни сборщик. Сборку делает GitHub,
вам остаётся скачать архив.

1. Откройте репозиторий на сайте GitHub, вкладка **Actions**.
2. Слева выберите **«Сборка программы «Документы СРО» для Windows»**.
3. Справа кнопка **«Run workflow»** → ещё раз **«Run workflow»**
   (ветку можно оставить ту, что предложена).
4. Подождите 3–5 минут, пока рядом с запуском не появится **зелёная галочка**.
5. Щёлкните по этому запуску. Внизу страницы, в разделе **Artifacts**, будет
   архив **`Dokumenty-SRO-Windows`** — скачайте его.
6. Распакуйте архив. Внутри — папка с программой: её целиком можно передать
   коллеге (см. раздел «Как передать коллеге» ниже).

Сборка запускается и сама, при каждом изменении программы, — тогда шаги 3–4
пропускаются: просто откройте последний зелёный запуск и скачайте архив.

> Скачать артефакт может только тот, кто вошёл на GitHub под своей учётной
> записью. Коллегам аккаунт не нужен — вы передаёте им уже скачанный архив.

# Способ 2. Собрать у себя на компьютере

## Что нужно один раз

Соберётся из уже готового окружения программы. Поэтому сначала, если ещё не
делали, **запустите `START.bat` один раз** — он создаст папку `.venv`
с нужными библиотеками (нужен интернет, 1–2 минуты).

## Сборка

1. Двойной щелчок по **`BUILD_APP.bat`**.
2. Он поставит сборщик (PyInstaller) и соберёт программу. Это займёт
   1–3 минуты, в чёрном окне будет идти текст — так и должно быть.
3. Когда увидите строку **«Готово. Папка для передачи коллегам: …»** —
   всё собралось.

Результат — папка **`dist\Документы-СРО`**. Внутри:

```
Документы-СРО\
    ДокументыСРО.exe      сама программа
    sro\                  бланки всех СРО
    config\               настройки
    assets\               значок программы
    ПРОЧТИ.txt            короткая памятка для коллеги
```

## Как передать коллеге

1. Щёлкните по папке **`Документы-СРО`** правой кнопкой → **«Отправить»** →
   **«Сжатая ZIP-папка»** (или заархивируйте любым архиватором).
2. Передайте ZIP коллеге (почта, мессенджер, флешка).
3. Коллега распаковывает архив и запускает **`ДокументыСРО.exe`** двойным
   щелчком. Устанавливать ничего не нужно.

## Важно

- Файлы **`sro`** и **`config`** должны лежать **рядом** с программой — не
  удаляйте и не переносите их отдельно от `.exe`.
- Готовые документы у коллеги появятся в папке **`output`** рядом с программой;
  там же будут `logs` и счётчик `usage.json` — они создаются сами.
- **PDF.** Чтобы программа сохраняла ещё и PDF, у коллеги должен быть
  установлен Microsoft Word или LibreOffice. Без них программа делает DOCX,
  а PDF из него всегда можно сохранить вручную: **Файл → Сохранить как → PDF**.
- **Антивирус / SmartScreen.** Свежесобранные `.exe` иногда вызывают
  предупреждение Windows SmartScreen («Windows защитила ваш компьютер») или
  антивируса — это ложное срабатывание, обычное для программ, собранных
  PyInstaller. Нажмите **«Подробнее» → «Выполнить в любом случае»**. Если
  антивирус в организации строгий — попросите добавить файл в исключения.
- Программа полностью локальная: никуда ничего не отправляет, работает без
  интернета.

## Если что-то пошло не так

- **«Run START.bat once first…»** — не создано окружение `.venv`. Запустите
  сначала `START.bat`, потом снова `BUILD_APP.bat`.
- **Сборка прервалась с ошибкой** — в чёрном окне будет текст ошибки. Чаще
  всего это отсутствие интернета при установке сборщика. Проверьте интернет
  и запустите `BUILD_APP.bat` заново.

# Документы дисциплинарной комиссии СРО — автогенерация

Программа читает ежедневный эксель-файл с решениями по компаниям и сама делает
готовые Word-документы по трём СРО (Ассоциация «СФЕРА изыскателей»,
Ассоциация «СФЕРА проектировщиков», Ассоциация «ЦОС «СФЕРА-А»):

- **положительные акты плановых проверок** — по строкам с результатом
  «Положительный» (номер = рег. номер/год, дата — из колонки «Акт»);
- **предписания о приостановлении права** — по строкам, где в колонке
  «Решение» стоит **«Отказ»** (приостановка продолжается) или
  **«Приостановить»** (первичная приостановка). Дата — из колонки
  «Дата решения», срок — 90 дней (колонка «Дата отказа в возобновлении»),
  вариант текста — по колонке «Причина приостановки/исключения»:
  - «Акт» — предписание по неустранённым нарушениям плановой проверки;
  - «Страховка» — предписание по страхованию гражданской ответственности;
  - «Акт; Страховка» — объединённый вариант;
  - у изыскателей «Взнос; Акт; Страховка» — вариант с задолженностью по
    взносам; у стройки и проекта взнос в тексте не упоминается.

**Не делает** (остаётся ручной работой, попадает в сводку с пометкой):

- документы по отрицательному результату текущей проверки
  (отрицательный акт, «Предписание на 14 дней» об устранении нарушений);
- восстановления после устранения нарушений;
- строки, где не заполнены нужные колонки.

## Установка (один раз)

1. Установите Python с сайта <https://www.python.org/downloads/>
   (кнопка «Download Python 3.x»). При установке обязательно поставьте
   галочку **«Add python.exe to PATH»**.
2. Откройте эту папку (`sro-docs`), в адресной строке проводника наберите
   `cmd` и нажмите Enter. В открывшемся чёрном окне выполните:

   ```
   pip install -r requirements.txt
   ```

## Как пользоваться каждый день

1. Скопируйте свежий ежедневный эксель-файл в папку `sro-docs`
   (или просто перетащите его мышкой на файл `run.bat`).
2. Запустите `run.bat` двойным кликом.
3. Программа создаст папку **«Документы <имя файла>»**, внутри — подпапки
   по СРО с готовыми `.docx`, и файл **Сводка.txt** — что сделано,
   что пропущено и почему.
4. Откройте предписания и **впишите первую часть номера** — программа
   оставляет её пустой: `№ ____/1366` (вторая часть — рег. номер компании,
   подставляется автоматически).

Если файлов несколько, программа берёт самый свежий `.xlsx` в папке.
Можно указать файл явно: `run.bat "C:\путь\25.08.2026.xlsx"`.

## Требования к эксель-файлу

Первая строка листа — заголовки. Используются колонки: «СРО», «Рег номер»,
«Контрагент», «ИНН», «Акт», «Результат проверки»,
«Причина приостановки/исключения», «Решение», «Дата решения»,
«Дата отказа в возобновлении». Порядок колонок не важен — поиск по названию.
Значения в «СРО»: «СФЕРА изыскатели», «СФЕРА проект», «СФЕРА-А».

## Шаблоны

Лежат в `templates/<сро>/…` — это ваши фирменные бланки, в которых данные
заменены полями вида `{{company}}`, `{{inn}}`, `{{date_full}}`, `{{until}}`,
`{{reg}}`, `{{year}}`, `{{day}}`, `{{month_gen}}`, `{{company_full}}`.
Текст можно править прямо в Word — главное не удалять и не разрывать
сами поля `{{…}}` (не вставлять внутрь них ничего и не менять их написание).

| Файл | Когда используется |
| --- | --- |
| `akt.docx` | результат проверки «Положительный» |
| `predpisanie_akt.docx` | причина «Акт» |
| `predpisanie_strahovka.docx` | причина «Страховка» |
| `predpisanie_akt_strahovka.docx` | причина «Акт; Страховка» |
| `predpisanie_vznos_akt_strahovka.docx` | только изыскатели: «Взнос; Акт; Страховка» |

## Если что-то пошло не так

- **«Не установлена библиотека openpyxl»** — выполните
  `pip install -r requirements.txt` (см. «Установка»).
- **«Не найдены нужные колонки»** — проверьте, что первая строка листа
  содержит заголовки как в обычном ежедневном файле.
- В сводке раздел **«ВНИМАНИЕ, ТРЕБУЕТ ПРОВЕРКИ»** — строки, по которым
  программа не смогла сделать документ (нет даты, не распознана СРО и т.п.);
  эти документы нужно сделать вручную или поправить эксель и запустить снова.
- Повторный запуск по тому же файлу просто пересоздаёт документы заново.

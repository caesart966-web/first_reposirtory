## Поля, которые текущим шаблонам не нужны

Программа их читает и хранит — пригодятся будущим документам СРО, —
но никогда не требует для формирования заявления и доверенности.

| Поле | Название |
| --- | --- |
| `kpp` | КПП |
| `registration_date` | Дата регистрации |
| `postal_address` | Почтовый адрес |
| `website` | Сайт |
| `bank_name` | Наименование банка |
| `bank_account` | Расчётный счёт |
| `bank_corr_account` | Корреспондентский счёт |
| `bank_bik` | БИК |
| `okpo` | ОКПО |
| `okato` | ОКАТО |

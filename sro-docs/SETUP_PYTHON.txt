ЧТО ПРОИЗОШЛО

На компьютере не установлен Python - без него программа работать не может.
Это бесплатная программа, ставится один раз за пару минут.


ЧТО СДЕЛАТЬ

1. Откройте в браузере:  https://www.python.org/downloads/

2. Нажмите большую жёлтую кнопку "Download Python" вверху страницы.

3. Запустите скачанный файл.

4. ВАЖНО! В самом первом окне установщика, ВНИЗУ, есть галочка
   "Add python.exe to PATH"  (или "Add Python to PATH").
   Обязательно поставьте её ДО нажатия кнопки "Install Now".
   Без этой галочки программа снова не запустится.

5. Нажмите "Install Now" и дождитесь надписи "Setup was successful".

6. Закройте установщик и запустите START.bat ещё раз.


ЕСЛИ ГАЛОЧКУ ЗАБЫЛИ ПОСТАВИТЬ

Запустите установщик Python ещё раз, выберите "Modify", дойдите до
конца и на последнем шаге отметьте "Add Python to environment variables".
Либо просто удалите Python и установите заново, уже с галочкой.


ЕСЛИ КОМПЬЮТЕР РАБОЧИЙ И УСТАНОВКА ЗАПРЕЩЕНА

Обратитесь к системному администратору: попросите установить
Python версии 3.10 или новее с галочкой "Add Python to PATH".

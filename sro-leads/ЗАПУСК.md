# sro-leads: пошаговая инструкция по запуску

Инструкция для рабочей машины на Windows. Делайте по порядку, шаги с первого по седьмой
выполняются один раз, восьмой и дальше — обычная ежедневная работа.

Все команды набираются в командной строке. Открыть её: клавиши `Win + R`, ввести `cmd`,
нажать Enter.

---

## Шаг 1. Проверить Python

```bat
python --version
```

Нужен Python 3.11 или новее. Если команда не найдена или версия старее, скачайте Python с
python.org и при установке обязательно поставьте галочку **Add python.exe to PATH**, иначе
командная строка его не увидит. После установки закройте окно командной строки и откройте
заново.

## Шаг 2. Забрать код

Вариант с git, если он установлен:

```bat
cd %USERPROFILE%
git clone https://github.com/caesart966-web/first_reposirtory.git
cd first_reposirtory
git checkout claude/new-session-5ps5x2
cd sro-leads
```

Вариант без git: откройте в браузере
`https://github.com/caesart966-web/first_reposirtory/tree/claude/new-session-5ps5x2`,
нажмите зелёную кнопку **Code**, выберите **Download ZIP**, распакуйте архив, зайдите в
папку `sro-leads` внутри распакованного и в адресной строке проводника наберите `cmd`,
чтобы открыть командную строку сразу в этой папке.

Проверьте, что вы в нужной папке:

```bat
dir run.py
```

Файл должен найтись. Все команды ниже выполняются из этой папки.

## Шаг 3. Установить библиотеки

```bat
pip install -r requirements.txt
```

Идёт пару минут. Если `pip` не найден, попробуйте `python -m pip install -r requirements.txt`.

Проверка, что всё встало:

```bat
python -m pytest -q
```

Должно написать, что все тесты прошли. Это проверка самой программы, сеть для неё не нужна.

## Шаг 4. Вписать токен Dadata

```bat
copy .env.example .env
notepad .env
```

В открывшемся блокноте в строке `DADATA_TOKEN=` после знака равно вставьте свой токен из
личного кабинета Dadata, сохраните файл и закройте блокнот.

Токен нужен, чтобы по ИНН подтягивались название, адрес, ОКВЭД, руководитель и признак
ликвидации. Без токена программа работает, но контакты будут только из локального
справочника и с сайтов компаний.

Файл `.env` в репозиторий не попадает, токен останется только у вас на машине.

## Шаг 5. Положить справочник компаний

Если у вас есть выгрузка компаний в Excel с колонками «ИНН», «Название», «Телефоны»,
«email» (тот самый файл `Компании (4).xlsx`), скопируйте его в папку `data\companies\`.
Программа возьмёт оттуда контакты для найденных лидов. Файлов может быть несколько.

## Шаг 6. Проверить, что API реестров отвечает

Это главная проверка перед первым сбором. Она делает один короткий запрос и показывает,
совпала ли настройка программы с тем, что реально отдаёт API.

```bat
python run.py --check-api nostroy
python run.py --check-api nopriz
```

Смотрите на **последнюю строку** вывода, она бывает трёх видов.

**`OK: карта полей совпала, backfill применим`**
Всё хорошо, переходите к шагу 7.

**`ВНИМАНИЕ: карта полей совпала, но API отдаёт только действующих, доступен только дифф`**
Реестр не отдаёт исторические исключения. Тогда на шаге 7 запускайте команды **без**
`--backfill 90`. Лиды появятся не сразу, а на второй день, когда программа сравнит
сегодняшний список членов со вчерашним.

**`ОШИБКА: поля ... не найдены в ответе`**
Настройку нужно поправить под реальный ответ API. Сохраните вывод в файл и пришлите его
мне, я поправлю `config.yaml`:

```bat
python run.py --check-api nostroy > check_nostroy.txt 2>&1
```

Файл `check_nostroy.txt` появится в текущей папке. Дальше по шагам не идите, пока это не
исправлено.

## Шаг 7. Первый сбор

Команды ниже скачивают полный реестр. Это долго, десятки минут на каждый реестр, в окне
видно, какая страница качается. Не закрывайте окно до конца работы.

```bat
python run.py --only nostroy_registry --backfill 90
python run.py --snapshot-report nostroy
python run.py --only nopriz_registry --backfill 90
python run.py --snapshot-report nopriz
```

Если на шаге 6 было предупреждение про срез действующих, те же команды, но без `--backfill 90`.

Команда `--snapshot-report` печатает, что именно пришло: сколько записей, какие статусы,
заполнены ли даты, сколько записей попало в окно последних 90 дней. Последняя строка отчёта
скажет, применим ли режим исторической загрузки.

На что смотреть в отчёте:

- **`полнота: ... полный`** — реестр скачался целиком, всё в порядке.
- **`ЧАСТИЧНЫЙ`** — связь оборвалась на середине. Такой снапшот не годится как основа для
  сравнения. Удалите его и повторите сбор:
  ```bat
  python run.py --drop-snapshot nostroy
  python run.py --only nostroy_registry --backfill 90
  ```

## Шаг 8. Собрать файл для обзвона

```bat
python run.py --export-only
```

Готовый файл появится в папке `output` с именем вида `Лиды_2026-09-02.xlsx`. В нём три листа:

- **Горячие** — приоритет 1, ещё не обзвоненные, сверху самые перспективные.
- **Все лиды** — всё, что прошло фильтры.
- **История сигналов** — откуда взялся каждый лид.

Строки закрашены по приоритету: красные самые срочные, жёлтые средние, серые слабые.
Колонка «Телефон (не подтверждён)» означает, что телефон взят с сайта, который не удалось
однозначно связать с этой компанией. Такой номер тоже рабочий, но проверьте при звонке,
туда ли попали.

## Шаг 9. Сверить несколько лидов глазами

Обязательный шаг перед первым обзвоном. Программа может отработать без ошибок, но читать не
то поле даты, и поймать это можно только сверкой с карточкой в реестре.

```bat
python run.py --inspect-top 10 --out inspect.txt
notepad inspect.txt
```

По каждой компании видно: почему она стала лидом, какие сигналы и с какими датами, что
лежит в записи реестра, ссылка на карточку в реестре и контакты. Откройте две или три
ссылки в браузере и убедитесь, что компания действительно исключена или приостановлена и
дата совпадает.

Если данные не сходятся, пришлите мне `inspect.txt`, разберёмся, какое поле читается не то.

## Шаг 10. Настроить ежедневный запуск

Полный ежедневный цикл запускается одной командой:

```bat
python run.py --full
```

Она собирает изменения по всем трём источникам, пересчитывает баллы, обогащает контактами
и делает новый Excel.

Чтобы это происходило само каждое утро:

1. Нажмите `Win`, наберите «Планировщик заданий», откройте его.
2. Справа выберите **Создать задачу** (не «Создать простую задачу»).
3. Вкладка **Общие**: имя задачи, например `sro-leads`. Отметьте **Выполнять вне
   зависимости от регистрации пользователя** и **Выполнить с наивысшими правами**.
4. Вкладка **Триггеры**: **Создать**, ежедневно, время 08:00.
5. Вкладка **Действия**: **Создать**, действие «Запуск программы». В поле «Программа или
   сценарий» укажите полный путь к `run.bat`, например
   `C:\Users\Имя\first_reposirtory\sro-leads\run.bat`. В поле «Рабочая папка» укажите
   `C:\Users\Имя\first_reposirtory\sro-leads`. Поле «Рабочая папка» заполнить обязательно,
   иначе задача не найдёт настройки.
6. Сохраните. Проверьте прямо сейчас: правой кнопкой по задаче, **Выполнить**.

После прогона автоматически откроется папка `output` с готовым файлом.

## Шаг 11. Отмечать результаты обзвона

Чтобы одна и та же компания не попадала в выгрузку каждый день, отмечайте, что с ней
сделали:

```bat
python run.py --mark 7814858513 called "перезвонить в четверг"
python run.py --mark 7814858513 in_progress "отправил КП"
python run.py --mark 7814858513 won
python run.py --mark 7814858513 dead "уже вступили сами"
```

Статусы: `new` (новый), `called` (позвонили), `in_progress` (в работе), `won` (сделка),
`dead` (не наш). По умолчанию в выгрузку идут только те, у кого статус `new`.

## Шаг 12. Добавлять выгрузки TenderGuru

Складывайте файлы `mail_*_contracts.xlsx` в папку `data\tenderguru\`. При следующем
`--full` программа их прочитает, найдёт участников закупок без членства в СРО и переложит
обработанные файлы в `data\tenderguru\processed\`, чтобы не читать их повторно.

После первого такого прогона загляните в лог и убедитесь, что колонки распознались: должна
быть строка вида «строк 1200, сигналов 35». Если сигналов ноль, а строк много, напишите
мне, какие колонки в вашей выгрузке, поправлю распознавание.

## Настройки, которые может понадобиться поменять

Открыть: `notepad config.yaml`. Файл в кодировке UTF-8, менять только значения справа от
двоеточия.

- **Только свой регион.** В блоке `export` в строке `regions` перечислите куски названий:
  `regions: ["Санкт-Петербург", "Ленинградская"]`. Пустой список означает все регионы.
- **Сколько строк на листе «Горячие».** `max_rows: 300`.
- **Не показывать старые лиды.** `signal_max_age_days: 180`, это дни.
- **Порог обогащения.** В блоке `enrich` строка `min_score: 60`. Чем ниже, тем больше
  запросов к Dadata тратится.

После правки файла достаточно пересобрать выгрузку: `python run.py --export-only`.

## Если что-то пошло не так

- **Программа ругается и останавливается.** Полный текст ошибки лежит в папке `logs`, файл
  с сегодняшней датой. Пришлите мне его последние строки.
- **`ProxyError`, `Max retries exceeded`, `Tunnel connection failed`.** Нет доступа к сайту
  реестра с этой машины. Проверьте, открывается ли `reestr.nostroy.ru` в браузере. Если за
  корпоративной сетью, нужен доступ у администратора.
- **Сбор оборвался на середине.** Ничего страшного, снапшот пометится частичным и не
  испортит будущие сравнения. Удалите его командой `--drop-snapshot` и запустите сбор снова.
- **В Excel ИНН превратился в число вида 7,8E+09.** В файлах, которые делает программа,
  этого не будет, колонка форматируется как текст. Если открываете другой файл, при импорте
  укажите для колонки ИНН формат «Текстовый».
- **В консоли вместо русских букв кракозябры.** Выполните `chcp 65001` перед командой. В
  `run.bat` это уже делается автоматически.
- **Хочу начать с нуля.** Удалите файл `data\sro_leads.db`. Вся история сигналов и отметки
  обзвона пропадут, снапшоты придётся снимать заново.

## Куда что складывается

```
sro-leads\
  output\        готовые Excel для обзвона
  logs\          логи по дням, туда смотреть при ошибках
  data\
    sro_leads.db      база: организации, сигналы, снапшоты, статусы обзвона
    snapshots\        сырые ответы реестров по датам
    tenderguru\       сюда класть выгрузки TenderGuru
    companies\        сюда класть справочники компаний для контактов
  config.yaml    настройки
  .env           токен Dadata, никому не показывать
```

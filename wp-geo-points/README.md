# Гео-точки (Google Карты) — плагин WordPress

Отдельная страница под каждую точку на Google Картах: свой адрес, своя карта,
своя микроразметка и свои отзывы. Сделан под задачу «19 точек, один телефон,
продвижение только на картах».

Ставится на существующий сайт, тему не меняет, платных плагинов не требует.

---

## Что он делает

| Шаг ТЗ | Как закрыт |
|---|---|
| 1. 19 отдельных страниц | Тип записи «Точки на картах». Адрес страницы — в корне (`/vskrytie-zamkov-primorsky/`), заголовок H1 — у каждой свой |
| 2. NAP на каждой странице | Адрес — из полей точки, телефон — **один на весь сайт** из настроек, часы работы разбираются из строки |
| 3. Индивидуальная карта | Поле «Код карты Google» у каждой точки; карта грузится по клику, чтобы не сажать скорость |
| 4. Микроразметка LocalBusiness / Locksmith | JSON-LD собирается плагином из тех же полей, что видит посетитель |
| 5. Отзывы и кнопка «оставить отзыв» | Отзывы точки тянутся из Google Places API по её Place ID; кнопка ведёт на форму отзыва именно этой точки |

Сверх ТЗ, потому что без этого задача не работает:

- **Импорт из таблицы** — 19 страниц заводятся из CSV за один заход, повторный импорт обновляет их же.
- **Страница «Проверка»** — показывает по каждой точке, чего не хватает, и **меряет, насколько тексты страниц отличаются друг от друга**.
- **Защита от чужих адресов**: если слаг точки уже занят обычной страницей сайта, плагин не перехватывает адрес, а пишет об этом.

## Чего он НЕ делает — и почему

- **Не рисует звёзды отзывов в выдаче.** Google не учитывает отзывы о самом себе, размещённые на своём же сайте, а за попытку разметить их `aggregateRating` снимает расширенный вид сайта целиком. Отзывы на странице — для посетителя, не для робота.
- **Не поднимает позиции в картах сам по себе.** В локальной выдаче решают сами карточки: категории, фото, отзывы, посты, близость пользователя. Страницы усиливают релевантность и дают куда вести человека, но карточки они не заменяют.
- **Не сверяет адрес на странице с карточкой Google.** Это делается глазами, один раз, символ в символ: у робота нет доступа к вашему профилю.
- **Не пишет тексты.** Девятнадцать страниц, отличающихся только названием района, Google считает дорвеями. Проверка это увидит и скажет, но написать за вас не может.

## Установка

1. Соберите архив: `bash build.sh` → появится `geo-points.zip`.
2. WordPress → Плагины → Добавить новый → Загрузить плагин → выбрать `geo-points.zip` → Установить → Активировать.
3. «Точки на картах» → «Настройки»:
   - название организации и адрес сайта;
   - **телефон в том виде, как в карточках Google**, символ в символ;
   - тип бизнеса — `Locksmith`;
   - схема адресов — «в корне» (как в ТЗ).
4. Настройки → Постоянные ссылки → «Сохранить» (это пересобирает адреса страниц).

## Как завести 19 точек

### Через таблицу (быстро)

1. Возьмите за образец `geo-points/data/points-example.csv`.
2. Заполните по строке на точку. Столбцы можно называть по-русски, порядок любой:
   `слаг; заголовок; район; улица; город; индекс; широта; долгота; метро; улицы; часы; place_id; карта; лид; текст`
3. «Точки на картах» → «Импорт из таблицы» → вставьте файл → **«Показать, что получится»**.
4. Проверьте предпросмотр (что создаётся, что обновляется, где чего не хватает) → «Импортировать».

Повторный импорт той же таблицы **обновляет** точки, а не плодит новые: связь идёт по адресу страницы.
Пустая ячейка не стирает уже написанный на сайте текст.

### Руками

«Точки на картах» → «Добавить точку». Заголовок — это H1. Ниже форма со всеми полями.

## Где взять данные по точке

| Что | Где |
|---|---|
| **Код карты** | Google Карты → ваша точка → «Поделиться» → «Встраивание карт» → «Копировать HTML». Вставляйте целиком, плагин возьмёт из кода только адрес карты |
| **Place ID** | Google Place ID Finder (`developers.google.com/maps/documentation/places/web-service/place-id`), поиск по названию точки. Иногда он уже зашит в скопированную ссылку — тогда плагин подставит его сам |
| **Адрес** | Из карточки Google, символ в символ: «Богатырский пр., 12, корп. 1» — именно с такими сокращениями и запятыми |
| **Часы** | Строкой: `круглосуточно` или `Пн-Пт 09:00-21:00; Сб,Вс 10:00-18:00` |
| **Ключ Places API** | Google Cloud Console → Places API (New) → ключ. Нужен только для показа отзывов; кнопка «оставить отзыв» работает без него |

## Проверка перед сдачей

«Точки на картах» → «Проверка». Красное — чинить обязательно, жёлтое — посмотреть.

Что она ловит:

- незаполненные обязательные поля;
- **одну и ту же карту или один Place ID на нескольких точках** (самая частая ошибка копирования: на странице это выглядит нормально, а кнопка отзыва ведёт в чужой филиал);
- адрес страницы, занятый другой страницей сайта;
- **долю собственного текста страницы** — сколько в ней того, чего нет на остальных восемнадцати. Ниже 35 % — это уже клон;
- страницы, где в тексте не встречается ни одна своя улица или станция метро (гео-привязки нет);
- слишком короткие страницы.

Там же — ссылка «проверить» на Google Rich Results Test по каждому адресу: разметку надо прогнать по всем 19 перед сдачей.

## Шорткоды

Если страницу собирают конструктором (Elementor, блоки), блоки доступны отдельно:

| Шорткод | Что выводит |
|---|---|
| `[geo_nap]` | Адрес, телефон, часы, метро |
| `[geo_map]` | Карту точки |
| `[geo_reviews]` | Отзывы из Google |
| `[geo_review_button]` | Кнопку «оставьте отзыв» |
| `[geo_points_list]` | Список всех точек — для страницы «Адреса» |

Все, кроме последнего, принимают `point="слаг"` — тогда блок берёт данные другой точки:
`[geo_map point="vskrytie-zamkov-kupchino"]`.

Шаблон страницы точки можно переопределить темой: скопируйте
`geo-points/templates/single-geo_point.php` в папку темы и правьте там —
обновление плагина его не затрёт.

## Если что-то пошло не так

**После импорта страницы отдают 404.** Настройки → Постоянные ссылки → «Сохранить».
Либо «Проверка» → «Очистить кэш отзывов и пересобрать адреса».

**Плагин пишет «адрес занят обычной страницей».** На сайте уже есть страница
с таким же слагом. Плагин намеренно не перехватывает её адрес: рабочая страница
важнее новой. Переименуйте одну из двух.

**Адреса верхнего уровня конфликтуют с темой или другим плагином.**
Настройки → схема адресов → «в разделе»: страницы переедут на
`/adresa/vskrytie-zamkov-primorsky/`. Всё остальное продолжит работать.

**Стоит Rank Math или Yoast.** Совместимо: плагин отдаёт только разметку
LocalBusiness, а title и description оставляет SEO-плагину (определяет его сам).
Покупать PRO-версию ради Local SEO не нужно.

**Отзывы не появились.** Проверьте: включена галочка в настройках, вписан ключ
Places API, у точки заполнен Place ID. Ответ Google кэшируется на 12 часов —
после исправлений жмите «Очистить кэш отзывов».

## Разработчику

```bash
php tests/run.php     # 96 проверок: телефон, часы, карта, разметка, похожесть, импорт
bash build.sh         # собрать geo-points.zip
```

Проверки идут без WordPress — на «чистых» классах (`Phone`, `Embed`, `Hours`,
`Schema`, `Similarity`, `Csv`). Правила, которые они стерегут:

- разметка **никогда** не содержит `aggregateRating` и `review`;
- в поле карты сохраняется только адрес с домена Google — произвольный HTML из админки не проходит;
- каждое поле формы имеет столбец в импорте (иначе новое поле молча не заполнится на 19 страницах разом);
- телефон, записанный в любом виде, приводится к одному.

Требования: PHP 7.4+, WordPress 5.9+.

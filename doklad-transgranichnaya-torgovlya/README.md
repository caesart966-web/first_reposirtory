# Доклад «Налоговое законодательство при трансграничной торговле»

Материалы к устному выступлению на 10–12 минут (магистратура, 2 курс).

| Файл | Что это |
|---|---|
| `doklad.docx` | Текст доклада для печати: Times New Roman 14, полуторный интервал, поля 30/15/20/20 мм. 1568 слов ≈ 11 минут чтения. |
| `doklad.pdf` | Тот же текст в PDF. |
| `doklad.md` | Исходник текста — единственная точка правды, `.docx` собирается из него. |
| `prezentaciya.pptx` | Презентация, 16 слайдов, формат 16:9. В заметках к каждому слайду — что говорить. |
| `prezentaciya.pdf` | Презентация в PDF на случай, если на площадке нет PowerPoint. |

## Пересборка

```bash
npm install pptxgenjs docx
node build-presentation.js   # → prezentaciya.pptx
node build-doklad-docx.js    # → doklad.docx (из doklad.md)
```

## Оформление презентации

Шрифты — Cambria (заголовки) и Calibri (текст): оба входят в поставку Microsoft Office,
поэтому вёрстка не поедет на чужом компьютере. Палитра: тёмно-зелёный `#0F3B34`
(доминанта), сургучно-оранжевый `#C8642B` (акцент), белый лист. Сквозной мотив —
круглый номер-«печать».

## Про факты

Все нормы, номера статей и даты указаны по состоянию на сентябрь 2026 года.
Ключевые цифры, которые стоит перепроверить перед выступлением, если пройдёт время:
ставка НДС 22 % (ФЗ от 28.11.2025 № 425-ФЗ), порог 200 € и пошлина 5 % по товарам
электронной торговли в ЕАЭС (Решение Совета ЕЭК от 05.12.2025 № 112, вступает
в силу 01.07.2026), статус приостановленных СИДН (Указ Президента от 08.08.2023 № 585).

## Что внутри

Объект — торговая сеть **Fix Price** (ПАО «Фикс Прайс», операционная компания ООО «Бэст Прайс»),
процесс — «Импорт товаров из КНР» (от утвержденного плана закупок до товара на РЦ, готового
к отгрузке в магазины). Все 12 пунктов задания идут разделами 1–12; схемы:

| Пункт задания | Схема | Нотация |
|---|---|---|
| 2. Оргструктура | рис. 1 | ARIS Organizational Chart |
| 3. Процессы верхнего уровня | рис. 2 | ARIS VAD |
| 4. Границы процесса | рис. 3 | IDEF0 (А-0) |
| 8. Декомпозиция | рис. 4 | ARIS VAD, 2-й уровень |
| 9. Модель AS IS | рис. 5–9 | BPMN 2.0 |
| 11. Модель TO BE | рис. 10–13 | BPMN 2.0 |
| 12. Сравнение | рис. 14, табл. 12–14 | диаграмма |

**Откуда данные.** Сведения о компании (магазины, выручка, ассортимент, доля российских
поставщиков, работа через торговых агентов, ИТ-сервис для поставщиков из Китая, LEAD WMS,
численность) взяты из открытых источников, в тексте у них ссылки [16]–[24] на список
источников. Внутренний порядок работ, сроки этапов, доли повторов и трудозатраты компания
не публикует: в модели они оценочные, и текст прямо это говорит (разделы 1, 5, 10).
Оргструктура укрупненная, названия подразделений обобщенные.

Первая версия была на вымышленной компании «НеваИмпорт» — заменена 07.10.2026: под таким
именем работает реальная компания.

Схемы нарисованы в нотациях ARIS Express, но **не в самой программе ARIS Express**:
если преподаватель требует файл из ARIS Express / PIX / АСПРА, схемы нужно перерисовать
там по картинкам (символы те же).

## Стиль текста

Текст набран так, как его набирают в Word: без длинного тире, стрелок и значков
≈ ≤ ×, буква «е» вместо «ё», проценты без пробела (30%). Короткое тире «–» осталось
только в подписях «Рисунок 1 – …», «Таблица 1 – …» и в списке источников (так
требует ГОСТ, и так его ставит сам Word). Функция `clean()` в `build-docx.mjs`
заменяет «ё» и роняет сборку, если в текст попал запрещённый знак.

## Как пересобрать

```bash
node render.mjs        # схемы → build/img/*.png (Chromium через playwright)
node build-docx.mjs    # документ; содержание — в два прохода через LibreOffice
```

- `diagrams/lib.js` — отрисовка BPMN, оргструктуры, VAD (в браузере, перенос строк по настоящему шрифту);
- `diagrams/defs.js` — все схемы; номера П1–П8 и И1–И8 на задачах совпадают с таблицами 10 и 11;
  обеспечивающие процессы на VAD — В1–В6, чтобы не путаться с номерами проблем;
- `diagrams/chart.js` — диаграмма сравнения;
- `data.json` — длительности и трудозатраты по этапам (на один контейнер): из него считаются
  таблицы 9, 12–14, рисунок 14 и все итоговые числа в тексте (правите число — пересобираете,
  текст сходится сам). Длительности на схемах (метки «21 дн.», доли «40%») вписаны в
  `defs.js` руками и должны совпадать с `data.json`.

## Что внутри

Объект — оптовая компания-импортёр ООО «НеваИмпорт» (**наименование условное**,
численность и длительности — допущения модели), процесс — «Импортная закупка товара»
(от плана закупок до товара, доступного к продаже). Все 12 пунктов задания идут
разделами 1–12; схемы:

| Пункт задания | Схема | Нотация |
|---|---|---|
| 2. Оргструктура | рис. 1 | ARIS Organizational Chart |
| 3. Процессы верхнего уровня | рис. 2 | ARIS VAD |
| 4. Границы процесса | рис. 3 | IDEF0 (А-0) |
| 8. Декомпозиция | рис. 4 | ARIS VAD, 2-й уровень |
| 9. Модель AS IS | рис. 5–9 | BPMN 2.0 |
| 11. Модель TO BE | рис. 10–13 | BPMN 2.0 |
| 12. Сравнение | рис. 14, табл. 12–14 | диаграмма |

Схемы нарисованы в нотациях ARIS Express, но **не в самой программе ARIS Express**:
если преподаватель требует файл из ARIS Express / PIX / АСПРА, схемы нужно перерисовать
там по картинкам (символы те же).

## Стиль текста

Текст набран так, как его набирают в Word: без длинного тире, стрелок и значков
≈ ≤ ×, буква «е» вместо «ё», проценты без пробела (30%). Короткое тире «–» осталось
только в подписях «Рисунок 1 – …», «Таблица 1 – …» и в списке источников (так
требует ГОСТ, и так его ставит сам Word). Функция `clean()` в `build-docx.mjs`
заменяет «ё» и роняет сборку, если в текст попал запрещённый знак.

## Как пересобрать

```bash
node render.mjs        # схемы → build/img/*.png (Chromium через playwright)
node build-docx.mjs    # документ; содержание — в два прохода через LibreOffice
```

- `diagrams/lib.js` — отрисовка BPMN, оргструктуры, VAD (в браузере, перенос строк по настоящему шрифту);
- `diagrams/defs.js` — все схемы; номера П1–П10 и И1–И10 на задачах совпадают с таблицами 10 и 11;
- `diagrams/chart.js` — диаграмма сравнения;
- `data.json` — длительности и трудозатраты по этапам: из него считаются таблицы 9, 12–14,
  рисунок 14 и все итоговые числа в тексте (правите число — пересобираете, текст сходится сам).

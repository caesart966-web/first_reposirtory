# sro-check — проверка контрагентов на членство в СРО

Разбирает выгрузки контрактов 44-ФЗ из `tenderguru.ru`, сводит поставщиков в реестр
(дедупликация по ИНН) и готовит XLSX-отчёт под проверку членства в СРО.

## Запуск

```bash
pip install openpyxl
python3 sro_check.py выгрузка*.xlsx -o sro-report.xlsx
```

Опции:

| Флаг | Назначение |
|---|---|
| `-o, --out` | путь к XLSX-отчёту (по умолчанию `sro-report.xlsx`) |
| `--inns FILE` | выгрузить список ИНН для пакетной проверки в реестре |
| `--json FILE` | выгрузить реестр поставщиков в JSON |
| `--merge FILE` | влить результаты проверки из реестра (CSV/XLSX с колонкой ИНН) |

## Что скрипт делает сам

- **Дедуплицирует** поставщиков по ИНН, агрегируя число контрактов, максимальную
  и суммарную стоимость.
- **Проверяет контрольную сумму ИНН** (10 и 12 знаков) и восстанавливает ведущий
  ноль, срезанный Excel: 11-значный ИНН дополняется нулём и принимается, только
  если после этого сходится контрольная сумма.
- **Определяет вид требуемого СРО** по ОКПД2: группы 41.20/42/43 → НОСТРОЙ,
  41.10 и 71.11/71.12 → НОПРИЗ.
- **Считает обязательность членства** по закону (см. ниже).
- **Помечает пограничные случаи** по предмету договора: экспертиза, обследование,
  паспортизация, отдельная смета, субподряд — там членство может не требоваться,
  хотя код ОКПД2 указывает на проектирование.

## Что скрипт НЕ делает

Не определяет фактическое членство в СРО. Колонка «Статус в реестре СРО» выходит
со значением `НЕ ПРОВЕРЕНО` и заполняется только через `--merge` после выгрузки из
официального реестра — [reestr.nostroy.ru](https://reestr.nostroy.ru/reestr) для
строителей, [reestr.nopriz.ru](https://reestr.nopriz.ru/) для проектировщиков и
изыскателей.

## Правовая база

| Вид работ | Норма | Порог |
|---|---|---|
| Строительство, реконструкция, капремонт | ч. 2 ст. 52 ГрК РФ | членство не требуется при сумме обязательств по каждому договору до 10 млн руб. (ч. 2.1 ст. 52, порог с 01.05.2022) |
| Проектирование | ч. 4 ст. 48 ГрК РФ | порога нет — членство обязательно при любой сумме |
| Инженерные изыскания | ч. 2 ст. 47 ГрК РФ | порога нет |

Дополнительно:

- С 01.03.2026 (309-ФЗ от 31.07.2025) требование о членстве распространено
  на разработку рабочей документации.
- ГУП/МУП, госучреждения и ряд юрлиц с госучастием освобождены при работе
  по договору с учредившим их органом (ч. 2.2 ст. 52, ч. 4.1 ст. 48 ГрК РФ).
- Членство требуется только у лица, заключившего договор напрямую с застройщиком,
  техзаказчиком или региональным оператором. У субподрядчика — не требуется.

## Как трактовать результат

- **«Допуск СРО» не существует с 01.07.2017.** Свидетельства о допуске отменены
  372-ФЗ. Проверяется факт членства и уровень ответственности по компенсационным
  фондам (КФ ВВ — возмещение вреда, КФ ОДО — договорные обязательства).
- **Статус «право выполнения работ приостановлено»** означает, что компания
  числится членом СРО, но работать не вправе. Бинарная колонка «да/нет» это теряет.
- **Отсутствие членства не равно нарушению.** По договорам в пределах порога,
  на субподряде и на некапитальных объектах членство и не нужно.
- **ОКПД2 — косвенный признак.** Окончательно вид работ определяется предметом
  договора, поэтому в отчёте есть колонка «Предмет крупнейшего договора».

## Листы отчёта

| Лист | Содержание |
|---|---|
| Все поставщики | полный реестр, одна строка на ИНН |
| Членство обязательно | те, у кого членство требуется по закону или требует уточнения |
| Членство не требуется | договоры в пределах порога 10 млн руб. |
| Контракты (исходные) | первичные строки выгрузок для прослеживаемости |
| Методика | правовая база, оговорки, статус проверки |

## Оговорка по данным

Отчёт содержит персональные данные (ФИО, телефоны, адреса электронной почты
руководителей и ИП) из открытых источников — ЕИС и агрегатора закупок. В репозиторий
ни исходные выгрузки, ни готовые отчёты не коммитятся: в гите живёт только код.

# Как запустить проверку СРО — пошагово

Инструкция для тех, кто никогда не запускал программы через командную строку.
Делайте по порядку, не пропуская шаги. Всё вместе занимает минут 15,
и только в первый раз — потом запуск будет в одну команду.

Что в итоге получится: программа возьмёт ваш файл со списком компаний,
проверит каждую по ИНН в реестрах НОСТРОЙ и НОПРИЗ и создаст **новый** файл
с дописанными колонками. Исходный файл останется нетронутым.

---

## Шаг 1. Скачать программу на компьютер

1. Откройте в браузере ссылку:
   <https://github.com/caesart966-web/first_reposirtory/tree/claude/sro-membership-verification-nei7m0>

   *Если ссылка не открылась:* зайдите на
   <https://github.com/caesart966-web/first_reposirtory>, нажмите кнопку выбора
   ветки (слева над списком файлов, обычно на ней написано `main`) и выберите
   в списке **`claude/sro-membership-verification-nei7m0`**.
2. Нажмите зелёную кнопку **Code** → **Download ZIP**.
3. Скачается архив. Распакуйте его (правая кнопка мыши → «Извлечь все…»).
4. Внутри найдите папку **`sro-check`**. Это и есть программа.
5. Перетащите папку `sro-check` на **Рабочий стол** — так будет проще всего.

Теперь у вас есть `Рабочий стол\sro-check` с файлами `check_sro.py`,
`README.md` и папкой `sro`.

---

## Шаг 2. Установить Python

Python — это программа, которая умеет выполнять такие файлы. Ставится один раз.

1. Откройте <https://www.python.org/downloads/>
2. Нажмите большую жёлтую кнопку **Download Python** (версия 3.11 или новее).
3. Запустите скачанный установщик.

**⚠️ Windows — самое важное место во всей инструкции.**
В первом окне установщика внизу есть галочка
**«Add python.exe to PATH»** (или «Add Python to PATH»).
**Поставьте её до того, как нажмёте «Install Now».**
Если пропустить — командная строка не будет находить Python, и ничего
не заработает. Если уже установили без галочки — удалите Python через
«Установка и удаление программ» и поставьте заново с галочкой.

**Mac:** просто пройдите установщик обычным способом, галочек нет.

---

## Шаг 3. Открыть командную строку в папке программы

Командная строка — это чёрное (или белое) окно, куда вы будете вводить команды.
Важно открыть её **именно в папке `sro-check`**, иначе программа не найдёт файлы.

### Windows

1. Откройте папку `sro-check` в Проводнике — так, чтобы видеть файл `check_sro.py`.
2. Щёлкните мышью по **адресной строке** сверху (там, где написан путь
   вида `C:\Users\...\Desktop\sro-check`). Путь выделится синим.
3. Наберите вместо него три буквы: **`cmd`** — и нажмите **Enter**.
4. Откроется чёрное окно, и в нём уже будет нужная папка.

### Mac

1. Откройте папку `sro-check` в Finder.
2. Щёлкните правой кнопкой мыши по папке → **«Новый терминал в папке»**.
   (Если такого пункта нет: Системные настройки → Клавиатура → Сочетания
   клавиш → Служба → включите «Новый терминал в папке».)

**Как проверить, что вы в правильном месте.** Введите команду и нажмите Enter:

| Windows | Mac |
|---|---|
| `dir` | `ls` |

В списке должен быть файл `check_sro.py`. Если его нет — вы открыли окно
не в той папке, вернитесь к пункту 1.

---

## Про команды дальше: Windows и Mac пишут по-разному

Это частая причина ошибок, поэтому запомните:

| | Windows | Mac |
|---|---|---|
| Python | `python` | `python3` |
| Установщик дополнений | `pip` | `pip3` |

Дальше в инструкции я пишу оба варианта. Берите свой.

---

## Шаг 4. Установить дополнения (один раз)

Скопируйте команду, вставьте в чёрное окно, нажмите Enter.
Вставка в командной строке — правой кнопкой мыши или **Ctrl+V**
(на Mac — **Cmd+V**).

**Windows:**
```
pip install -r requirements.txt
```

**Mac:**
```
pip3 install -r requirements.txt
```

Побегут строчки текста — это нормально, ждите. Когда снова появится
приглашение для ввода (мигающий курсор), команда закончилась.

Затем — вторая команда, для запасного способа проверки через браузер:

**Windows:**
```
python -m playwright install chromium
```

**Mac:**
```
python3 -m playwright install chromium
```

Если эта команда выдаст ошибку — не страшно, программа будет работать
и без неё, просто без «плана Б».

---

## Шаг 5. Положить ваш файл рядом с программой

Скопируйте `Компании_Список.xlsx` **внутрь папки `sro-check`** —
туда же, где лежит `check_sro.py`. Так не придётся возиться с путями.

---

## Шаг 6. Проверка связи — обязательно перед основным запуском

У реестров нет официального API, и адреса запросов иногда меняются.
Эта команда проверяет, отвечают ли реестры прямо сейчас и правильно ли
программа понимает их ответ.

Возьмите ИНН любой компании, которая **точно состоит в СРО** — например,
крупного подрядчика, с которым вы работаете. Подставьте его вместо цифр:

**Windows:**
```
python check_sro.py --probe 7702521529
```

**Mac:**
```
python3 check_sro.py --probe 7702521529
```

### Что вы увидите и что это значит

```
=== НОСТРОЙ ===
  [РАБОТАЕТ, найдено] nostroy:get-inn  (https://reestr.nostroy.ru/api/...)
      СРО: Ассоциация «Строители России» | № 1234 | действует
```
**`[РАБОТАЕТ, найдено]`** — идеально. Реестр отвечает, компания найдена,
программа правильно прочитала ответ. Переходите к шагу 7.

**`[РАБОТАЕТ, не найдено]`** — реестр отвечает, но этой компании в нём нет.
Тоже нормально: связь есть. Если вы уверены, что компания в СРО состоит —
попробуйте другой ИНН, чтобы убедиться наверняка.

**`[не подошёл]`** у всех строк — этот способ не сработал, рядом написана
причина. Программа тогда сама попробует открыть сайт в браузере и подсмотреть
настоящий адрес. Если у неё получится, в конце появится готовая строка:

```
Найденные адреса API (можно передать в параметрах):
    --nostroy-url "https://reestr.nostroy.ru/api/..."
```

Скопируйте её целиком и допишите в конец команды на шаге 7.

**`ИТОГ: ни один способ не сработал`** — нет связи с реестрами.
Проверьте интернет. Реестры иногда недоступны из-за границы —
тогда нужен российский IP.

---

## Шаг 7. Основной запуск

**Windows:**
```
python check_sro.py --input Компании_Список.xlsx
```

**Mac:**
```
python3 check_sro.py --input Компании_Список.xlsx
```

Если имя файла отличается — впишите своё. Если в имени есть пробелы,
возьмите его в кавычки: `--input "Компании Список.xlsx"`.

### Что будет происходить на экране

```
Файл: Компании_Список.xlsx
Лист: «Лиды по приоритету», строка заголовков: 2
Добавлены колонки: Название СРО, Реестровый номер, Статус членства, ...
К проверке: 393 компаний
Пауза между запросами: 1.0–2.0 с

Проверено 1 из 393 | ООО «Стройка» | ИНН 7702521529 → да | Ассоциация «СРО...»
Проверено 2 из 393 | АО «Ромашка» | ИНН 7707083893 → нет
...
  … промежуточный результат сохранён: Компании_Список_с_СРО.xlsx (да: 12, нет: 7, не удалось: 1)
```

**393 компании — это примерно 20–35 минут.** Между запросами стоит пауза
1–2 секунды, чтобы не создавать нагрузку на государственный реестр.
Ускорять не советую: за частые запросы могут временно закрыть доступ.

Окно можно свернуть, но **не закрывать**. Компьютер не должен уснуть —
на ноутбуке лучше воткнуть зарядку.

**Если нужно прервать** — нажмите **Ctrl+C** в чёрном окне. Всё проверенное
сохранится. Запустите ту же команду позже — продолжит с места остановки,
заново уже проверенные компании опрашиваться не будут.

---

## Шаг 8. Забрать результат

В папке `sro-check` появится файл **`Компании_Список_с_СРО.xlsx`**.
Это копия вашего файла с дописанными колонками:

| Колонка | Что внутри |
|---|---|
| «Есть СРО? (проверить в НОСТРОЙ)» | `да` / `нет` / `не удалось проверить` |
| «Название СРО» | название саморегулируемой организации |
| «Реестровый номер» | номер записи в реестре |
| «Статус членства» | `действует` / `приостановлено` / `исключён` |
| «Дата проверки» | когда проверяли |
| «Источник» | НОСТРОЙ или НОПРИЗ |
| «Примечание» | если проверить не удалось — здесь причина |

Колонка с ответом подкрашена: **зелёный** — да, **красный** — нет,
**жёлтый** — не удалось проверить.

Ваш исходный `Компании_Список.xlsx` не изменился.

Рядом появятся два служебных файла — `..._кэш.json` и `..._лог.txt`.
Не удаляйте их сразу: кэш нужен, чтобы при повторном запуске не проверять
всё заново.

---

## Шаг 9. Перепроверить жёлтые строки

«Не удалось проверить» — это не ошибка программы, а честный ответ:
реестр не отозвался или ответил непонятно. Часто со второго раза проходит.

**Windows:**
```
python check_sro.py --input Компании_Список_с_СРО.xlsx --retry-failed
```

**Mac:**
```
python3 check_sro.py --input Компании_Список_с_СРО.xlsx --retry-failed
```

Строки с «да» и «нет» программа не тронет — обратится к реестру только
по жёлтым. Можно повторять несколько раз, например на следующий день.

## Если что-то пошло не так

**«python» не является внутренней или внешней командой** (Windows)
Не поставили галочку «Add Python to PATH» на шаге 2. Переустановите
Python с этой галочкой.

**`can't open file 'check_sro.py'`**
Чёрное окно открыто не в той папке. Вернитесь к шагу 3 и проверьте
командой `dir` (Windows) или `ls` (Mac), что `check_sro.py` виден.

**`ОШИБКА: файл не найден: Компании_Список.xlsx`**
Файл не лежит в папке `sro-check` (шаг 5), либо имя написано иначе —
например, с пробелом вместо подчёркивания. Посмотрите точное имя
командой `dir` / `ls` и скопируйте его как есть.

**`не нашёл строку заголовков`**
Программа ищет строку со словом «ИНН» в первых 20 строках листа.
Проверьте, что указан правильный лист, добавив к команде:
`--sheet "Лиды по приоритету"`

**Все строки подряд — «не удалось проверить»**
Пропал интернет или сменился адрес API. Вернитесь к шагу 6.

**Все строки подряд — «нет»**
Подозрительно, и программа сама предупредит об этом после 25-й строки.
Скорее всего, реестр изменил формат ответа. Проверьте шагом 6 на ИНН
компании, которая точно состоит в СРО: если `--probe` её не находит —
не доверяйте результату и напишите мне.

**`Permission denied` / файл не сохраняется**
Файл результата открыт в Excel. Закройте его. Программа в этом случае
не падает — сохранит копию с датой в имени.

## Шпаргалка

Всё, что нужно помнить после первой настройки (Windows; на Mac — `python3`):

```
python check_sro.py --probe 7702521529            ← проверить связь
python check_sro.py --input Компании_Список.xlsx  ← основной запуск
python check_sro.py --input Компании_Список_с_СРО.xlsx --retry-failed   ← добить жёлтые
```

Полный список возможностей — в `README.md` в той же папке.

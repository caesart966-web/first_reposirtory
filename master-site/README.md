# Сайт ООО «МАСТЕР»

Одностраничный сайт строительной компании. Чистая статика: HTML, CSS и немного
JavaScript. Никаких конструкторов, фреймворков и сборщиков - папку достаточно
скопировать на хостинг, и сайт заработает.

Всё содержимое сайта взято из презентации компании. Полная выписка фактов -
в файле `CONTENT.md`, решения по оформлению - в `DESIGN.md`.

---

## Что нужно сделать перед публикацией

Пять шагов. Каждый занимает пару минут, технических знаний не требует - нужен
любой текстовый редактор (Блокнот, TextEdit, Notepad++).

### Шаг 1. Указать адрес сайта

Сейчас в файлах стоит заглушка `example.com`. Её надо заменить на ваш настоящий
домен - например `ooo-master.ru`.

Откройте по очереди четыре файла и замените **все** `example.com` на свой адрес
(в редакторе это делается через «Найти и заменить», обычно Ctrl+H):

| Файл | Сколько раз встречается |
| --- | --- |
| `index.html` | 11 |
| `privacy.html` | 1 |
| `sitemap.xml` | 2 |
| `robots.txt` | 1 |

Одно исключение: в `index.html` есть строка `name@example.com` - это пример
почты в форме заявки, его менять не надо.

### Шаг 2. Проверить телефоны и почту

Телефоны и адрес почты лежат только в `index.html` и `privacy.html`.

Телефон записан **двумя способами** сразу, и поменять надо оба:

```html
<a href="tel:+79295555000">+7 (929) 555-50-00</a>
        ^^^^^^^^^^^^^                ^^^^^^^^^^^^^^^^^^
        для нажатия                  для чтения
```

- в `tel:` - только плюс и цифры, без пробелов и скобок: `tel:+79295555000`
- между `>` и `<` - как удобно читать: `+7 (929) 555-50-00`

Найдите в файле `555-50-00` - и увидите все места сразу. Второй номер ищется
по `561-54-07`. Почта ищется по `ooomaster2022`.

Телефон встречается в шапке, на первом экране, в меню на телефоне, в блоке
заявки, в контактах, в подвале и на кнопке внизу экрана - это нормально,
поменяйте везде.

### Шаг 3. Настроить, куда приходят заявки

Подробно - в разделе [«Куда приходят заявки»](#куда-приходят-заявки) ниже.
Коротко: откройте `send.php` и в самом верху, в блоке настроек, впишите почту,
на которую хотите получать письма.

### Шаг 4. Подключить Яндекс.Метрику (можно позже)

Откройте `assets/js/main.js`. В самом верху есть строка:

```js
metrikaId: '00000000'
```

Вместо нулей впишите номер своего счётчика, например `metrikaId: '98765432'`.
Номер выдаётся при создании счётчика на <https://metrika.yandex.ru>.

Пока стоят нули, счётчик не подключается и сайт вообще никуда не обращается -
это сделано специально, чтобы не грузить страницу впустую.

Две цели настроены заранее, в Метрике их надо создать с такими же названиями:

| Название цели | Когда срабатывает |
| --- | --- |
| `form_submit` | заявка успешно отправлена |
| `phone_click` | нажали на телефон |

### Шаг 5. Обновить дату политики

В `privacy.html` найдите строку `редакция от 21 августа 2026 года` и поставьте
дату, когда сайт открылся. Если позже будете править политику - меняйте дату
снова.

## Как залить сайт на хостинг

### Через FTP (самый частый случай)

1. Скачайте бесплатную программу FileZilla: <https://filezilla-project.org>
2. Хостинг присылает четыре вещи: **адрес сервера** (например `ftp.вашсайт.ru`),
   **логин**, **пароль** и **порт** (обычно 21). Впишите их в верхнюю строку
   FileZilla и нажмите «Быстрое соединение».
3. Слева окажутся файлы вашего компьютера, справа - файлы на сервере.
4. Справа зайдите в папку сайта. У неё бывают разные имена: `public_html`,
   `www`, `httpdocs`, `htdocs` или `domains/вашсайт.ru/public_html`. Если не
   понимаете, какая нужна, спросите у поддержки хостинга: «в какую папку
   загружать сайт».
5. Слева выделите **содержимое** этой папки (не саму папку!) и перетащите
   направо.

**Что загружать:**

```
index.html
privacy.html
send.php
robots.txt
sitemap.xml
site.webmanifest
favicon.ico
.htaccess
assets/          (целиком: css, js, fonts, img)
```

**Что загружать не нужно** - это рабочие файлы для разработчика, на сайте они
не используются:

```
README.md
CONTENT.md
DESIGN.md
tools/
```

Ничего страшного не случится, если загрузите и их: `.htaccess` закрывает такие
файлы от посторонних. Но чище без них.

Файл `.htaccess` начинается с точки, и FileZilla по умолчанию его прячет.
Включите показ: меню «Сервер» → «Принудительно отображать скрытые файлы».

### Через панель управления хостингом

Почти у всех хостингов есть «Файловый менеджер». Зайдите в папку сайта,
нажмите «Загрузить», выберите файлы. Папку `assets` удобнее загрузить одним
zip-архивом и распаковать прямо на сервере.

### Проверка после загрузки

1. Откройте `вашсайт.ru` - должна открыться главная.
2. Пролистайте до формы, отправьте пробную заявку на своё имя.
3. Проверьте, что письмо пришло.
4. Откройте сайт на телефоне.

Если открывается список файлов вместо сайта - значит, вы загрузили не в ту
папку либо загрузили папку целиком вместо её содержимого.

### Обязательно подключите SSL-сертификат

Сертификат делает адрес сайта `https://` вместо `http://`. Без него браузеры
показывают «Не защищено», а форма заявки выглядит подозрительно. У большинства
хостингов бесплатный сертификат Let's Encrypt включается одной кнопкой в панели
управления.

После подключения откройте `.htaccess`, найдите внизу закомментированный блок
и уберите символы `#` в начале четырёх строк - тогда сайт всегда будет
открываться по защищённому адресу.

## Куда приходят заявки

Заявка из формы уходит в файл `send.php`. Все настройки - в самом начале файла,
в блоке `$CONFIG`. Ниже него ничего трогать не нужно.

### Вариант 1: письмом на почту (по умолчанию)

```php
'mode' => 'mail',
'to' => 'ooomaster2022@mail.ru',      // кому приходят заявки
'from' => 'site@example.com',         // от кого уходит письмо
```

**Важно про `from`.** Адрес в `from` должен быть на вашем домене. Если сайт
работает на `ooo-master.ru`, напишите `site@ooo-master.ru`. Заводить такой
почтовый ящик не нужно - он существует только как обратный адрес. Если оставить
чужой адрес (например `@mail.ru`), письма будут попадать в спам.

Поле `to` может содержать несколько адресов через запятую:

```php
'to' => 'director@ooo-master.ru, ooomaster2022@mail.ru',
```

**Если письма не приходят.** Некоторые хостинги не отправляют почту сами. Тогда
переключите отправку на SMTP - это почтовый сервер вашего ящика:

```php
'mail_transport' => 'smtp',
'smtp' => [
    'host' => 'smtp.yandex.ru',       // или smtp.mail.ru, smtp.gmail.com
    'port' => 465,
    'secure' => 'ssl',                // 'ssl' для порта 465, 'tls' для 587
    'user' => 'site@ooo-master.ru',   // логин от ящика
    'pass' => 'пароль-приложения',    // см. ниже
],
```

Обычный пароль от почты здесь не подойдёт - нужен «пароль приложения». В Яндексе
он создаётся в настройках безопасности аккаунта, в Mail.ru - в разделе «Пароли
для внешних приложений».

### Вариант 2: сообщением в Telegram

Заявки приходят в Telegram сразу на телефон.

1. Напишите боту [@BotFather](https://t.me/BotFather) команду `/newbot`, придумайте
   имя. В ответ он пришлёт **токен** - длинную строку вида `1234567890:AAH...`.
2. Напишите своему новому боту любое сообщение (иначе он не сможет вам писать).
3. Узнайте id чата: напишите боту [@userinfobot](https://t.me/userinfobot), он
   пришлёт ваш числовой **id**.
4. Впишите оба значения в `send.php`:

```php
'mode' => 'telegram',
'telegram' => [
    'token' => '1234567890:AAH...',
    'chat_id' => '123456789',
],
```

Чтобы заявки шли и на почту, и в Telegram, поставьте `'mode' => 'both'`.

Хотите получать заявки в общий чат сотрудников: добавьте бота в группу, сделайте
администратором и укажите id группы (он начинается с минуса).

### Вариант 3: Telegram без PHP

Нужен, только если хостинг не умеет PHP - например, при публикации на GitHub
Pages. Откройте `assets/js/main.js` и в блоке `CONFIG` вверху укажите:

```js
formMode: 'telegram',
telegram: {
  token: '1234567890:AAH...',
  chatId: '123456789'
}
```

**Так делать нежелательно.** При этом варианте токен бота видит любой, кто
откроет исходный код страницы. Зная токен, посторонний может читать сообщения
бота и слать вам спам. Если PHP на хостинге есть - пользуйтесь вариантом 1
или 2, там токен остаётся на сервере.

### Если заявка не ушла

Посетитель увидит понятное сообщение с просьбой позвонить, а сама заявка
сохранится на сервере в файле `leads.log` рядом с `send.php`. Открыть его из
браузера нельзя - доступ закрыт файлом `.htaccess`. Скачайте его по FTP, если
понадобится.

На хостингах с nginx (не Apache) файл `.htaccess` не работает. Попросите
поддержку закрыть доступ к `leads.log` и включить сжатие gzip - в `.htaccess`
видно, что именно нужно.

### Защита от спама

Работает без капчи, посетителю ничего заполнять не нужно:

- в форме есть невидимое поле-ловушка: люди его не видят, роботы заполняют;
- заявка, отправленная быстрее чем за 3 секунды, отбрасывается;
- с одного адреса принимается не больше 10 заявок в час.

Числа меняются в `send.php`, в блоке настроек: `min_seconds` и `per_hour`.

## Как менять содержимое

Все тексты лежат прямо в `index.html`. Открывайте его в текстовом редакторе,
находите нужную фразу и правьте. Главное - не трогать то, что внутри
угловых скобок `< >`.

Полезные ориентиры для поиска по файлу:

| Что поменять | Ищите в `index.html` |
| --- | --- |
| Заголовок первого экрана | `hero__title` |
| Цифры (2022, 137, 125, 7, 8) | `stat__value` |
| Текст «О компании» | `about__body` |
| Виды работ | `work__list` |
| Преимущества | `adv__title` |
| Список объектов | `object__name` |
| Персонал и техника | `res__row` |
| Реквизиты | `req-list__row` |
| Адрес в подвале | `site-footer__legal` |

Заголовок вкладки браузера и описание для поисковиков - в самом верху файла,
в строках `<title>` и `<meta name="description">`.

### Как добавить объект в список

Скопируйте целиком один такой блок и поправьте в нём текст:

```html
<div class="object">
  <span class="object__num">09</span>
  <span class="object__name">Название объекта</span>
  <span class="object__addr">г. Город, ул. Улица, 1</span>
  <span class="object__year">2026</span>
</div>
```

### Как добавить фотографию в галерею

1. Уменьшите фото до ширины примерно 1280 точек (подойдёт любой онлайн-сервис
   или стандартный редактор изображений).
2. Положите файл в `assets/img/objects/`.
3. Скопируйте в `index.html` блок соседней фотографии и замените в нём все
   имена файлов на своё, а тексты - на свои.

Проще всего попросить об этом того, кто делал сайт: в разметке фотографии
указаны сразу два формата и два размера, чтобы страница грузилась быстро.

### Как поменять карту

В `index.html` найдите `data-map-src`. Внутри адреса после `text=` записан
адрес офиса. Замените его на нужный, пробелы пишите как `%20`, а запятые -
как `%2C`.

```
index.html          главная страница, весь текст сайта здесь

robots.txt          указания поисковым роботам

favicon.ico         значок сайта во вкладке браузера

assets/
  css/style.css     всё оформление сайта
  js/main.js        меню, галерея, форма; вверху файла блок настроек

tools/              скрипт извлечения картинок из PDF (для разработчика)
```

## Технические заметки

Раздел для того, кто будет дорабатывать сайт.

**Стек.** HTML5, CSS с custom properties, ванильный JavaScript. Сборка не
нужна, зависимостей нет. Поддержка - все актуальные браузеры, включая
мобильные Safari и Chrome.

**Шрифты.** Literata (заголовки) и Onest (интерфейс) - переменные, лицензия
SIL Open Font License 1.1, разрешает коммерческое использование. Лежат
локально, обрезаны до нужных символов: 4 файла, 92 КБ на всё. Внешних
подключений к Google Fonts нет принципиально.

**Критический CSS.** Стили первого экрана продублированы прямо в `<style>`
в шапке `index.html` и `privacy.html`, остальное подгружается из
`assets/css/style.css` без блокировки отрисовки. Если правите шапку, первый
экран или блок с цифрами - поправьте оба места, иначе при загрузке страница
будет дёргаться.

**Картинки.** Извлечены из презентации скриптом `tools/extract-images.py`.
Каждая - в webp и jpg, в двух размерах, с указанными `width`/`height`, так
что вёрстка не прыгает при загрузке. Пересобрать: `python3
tools/extract-images.py путь/к/презентации.pdf` (нужны пакеты `pymupdf`,
`pillow`, `fonttools[woff]`).

**Внешние подключения.** Кроме Яндекс.Метрики их нет. Карта грузится только
после нажатия кнопки, до этого страница не обращается к сторонним доменам.

**Доступность.** Контраст всех сочетаний цветов проверен и не ниже уровня AA.
Вся навигация работает с клавиатуры, фокус видно. У аккордеона, меню и
галереи проставлены aria-атрибуты. Учтена системная настройка
«уменьшить движение».

**Результаты Lighthouse** (локальный запуск, мобильный профиль с эмуляцией
медленной сети):

| Страница | Производительность | Доступность | Лучшие практики | SEO |
| --- | --- | --- | --- | --- |
| `index.html` | 97 | 100 | 100 | 100 |
| `privacy.html` | 99 | 100 | 100 | 100 |

На десктопном профиле главная набирает 100 по всем четырём метрикам. На
рабочем хостинге цифры обычно чуть выше локальных: включается сжатие gzip и
кеширование из `.htaccess`.

**Что осталось незаполненным.** В презентации нет фактического адреса офиса и
часов работы - на сайте указан только юридический адрес. Нет отзывов, цен,
сертификатов и допусков СРО. Если такие данные появятся, их можно добавить
отдельными блоками; выдумывать их специально не стали.

**Про кавычки.** Название компании везде записано как `ООО «МАСТЕР»` - в
кавычках-ёлочках. Это принятая форма записи наименования юридического лица, и
именно так оно напечатано в презентации. Прямые кавычки используются во всех
остальных случаях.

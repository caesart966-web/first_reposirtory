ПРОВЕРКА СТРОИТЕЛЬНЫХ КОМПАНИЙ РОСТОВСКОЙ ОБЛАСТИ ЧЕРЕЗ CHECKO
==============================================================

Что делает программа. По каждой из 987 компаний двух файлов реестра
Союза «Строители Ростовской области» спрашивает у Checko данные ЕГРЮЛ/ЕГРИП:
действует компания, ликвидируется, в банкротстве или уже закрыта, и её
контакты — почты, телефоны, сайт. Итог — таблица Excel
«Строители_РО_статус_и_почты.xlsx» в этой же папке. В неё же входит всё,
что уже нашёл поиск по ИНН.


1. КЛЮЧ CHECKO

   Зарегистрируйтесь на checko.ru и получите API-ключ в разделе API
   (checko.ru/integration/api). Одна компания — один запрос, всего 987.
   Бесплатно Checko даёт 100 запросов в сутки на ключ — это 10 запусков,
   по одному в день. С платным тарифом (минимальный платёж — 1000 ₽,
   запрос — 0,15 ₽) всё проходит за один запуск, примерно за 10 минут.
   Цены — по странице тарифов Checko на октябрь 2026, проверьте их у себя
   в кабинете.


2. PYTHON

   Windows: установите Python с https://www.python.org/downloads/ —
   при установке отметьте галочку «Add Python to PATH».
   macOS и Linux: Python обычно уже есть.


3. ЗАПУСК

   Windows: двойной щелчок по start_windows.bat
   macOS / Linux: откройте терминал в этой папке и выполните  sh run.sh

   Программа спросит ключ (при вводе он не виден на экране) и предложит
   сохранить его в checko_key.txt, чтобы в следующий раз не вводить.


4. НЕСКОЛЬКО КЛЮЧЕЙ

   Откройте checko_key.txt Блокнотом и впишите ключи по одному в строке
   (или введите их по очереди при первом запуске: программа спросит
   «Ключ №1», «Ключ №2»… — пустой Enter заканчивает ввод).
   Когда у ключа кончается суточный лимит или деньги на балансе, программа
   сама переходит к следующему ключу и продолжает с той же компании.
   Если какой-то ключ Checko не принял, в конце будет сказано, какой
   именно. На экране ключи видны только последними четырьмя знаками.

   Берите ключи, которые принадлежат вам или выданы вам (например, ключи
   вашей компании). Заводить несколько бесплатных аккаунтов только ради
   обхода суточного лимита правила Checko могут запрещать — проверьте их,
   иначе ключи могут заблокировать.


5. ЕСЛИ ЛИМИТ КОНЧИЛСЯ

   Программа остановится сама и напишет, сколько компаний осталось.
   Запустите её снова на следующий день — она продолжит с того же места:
   полученные ответы лежат в папке checko_cache и повторно не запрашиваются,
   каким бы ключом их ни получили. Первыми проверяются компании, по которым
   поиск ничего не нашёл.


6. ЧТО ПРИСЛАТЬ В ЧАТ

   Готовую таблицу «Строители_РО_статус_и_почты.xlsx».
   Если что-то в ней выглядит странно — заархивируйте папку checko_cache
   и пришлите её: ответы Checko можно перечитать без новых запросов.
   Файл checko_key.txt НЕ присылайте и никому не передавайте — в нём ваши ключи.


Дополнительно:
   start_windows.bat --limit 50    не больше 50 запросов за запуск
   start_windows.bat --offline     без запросов, только пересобрать таблицу
   (на macOS / Linux — то же самое через  sh run.sh ...)

Задача: для каждой компании из входного файла установить по открытым источникам её ТЕКУЩИЙ статус в ЕГРЮЛ/ЕГРИП (действует / ликвидирована / и т.д.) и электронную почту. Компании — бывшие и нынешние члены Союза «Строители Ростовской области», почти все из Ростовской области.

ВХОД: {IN} — JSON-массив объектов {inn, ogrn, name, address, head}. 
ВЫХОД: {OUT} — JSON-массив, по одному объекту на КАЖДУЮ компанию входа, в том же порядке.

ИНСТРУМЕНТ. Единственный рабочий источник — инструмент WebSearch (загрузи его через ToolSearch "select:WebSearch", если он ещё не загружен). WebFetch, curl и любые прямые запросы к rusprofile/checko/list-org/nalog.ru из среды закрыты сетевой политикой — не трать на них время.

ПОРЯДОК ПОИСКА для каждой компании (не больше 3 поисков на компанию):
1. WebSearch, mode "standard", query: `<name> ИНН <inn>`, allowed_domains: ["rusprofile.ru","checko.ru","list-org.com","zachestnyibiznes.ru","companies.rbc.ru","saby.ru","audit-it.ru","vbankcenter.ru","kontragent.vbr.ru","checkspot.ru","comfex.ru","spark-interfax.ru","synapsenet.ru","datanewton.ru"]
2. Если в выдаче нет результата именно с этим ИНН/ОГРН или статус не ясен — WebSearch, mode "extended", без allowed_domains, query: `<name без кавычек и ОПФ> <город из адреса> ИНН <inn> ОГРН <ogrn> статус ликвидирована действует e-mail`.
3. Третий поиск — только если компания действует, а почты нет: mode "extended", query `<inn> электронная почта e-mail <name>`.
Для ИП (ИНН из 12 цифр) в запросах пиши «ИП <ФИО>».

ПРАВИЛА ДОСТОВЕРНОСТИ (это важнее полноты):
- Данные принимай, только если источник явно привязан к ЭТОМУ ИНН или ОГРН (ИНН/ОГРН в заголовке, адресе ссылки или в тексте ответа рядом с данными). Компания с похожим названием и другим ИНН — НЕ она, игнорируй.
- Статус не угадывай. Если источник прямо не говорит «действует / действующая / ликвидирована / прекратила деятельность / исключена / в стадии ликвидации / банкротство», а лишь косвенно (есть выручка, сотрудники) — ставь статус "Действует" ТОЛЬКО если есть финансовые данные или сведения не старше 2024 года, и в status_detail пиши «косвенно: …». Иначе "Не установлено".
- Почту записывай только дословно из результата, привязанного к этому ИНН. Не выдумывай адрес по домену сайта. Не бери почты самих сайтов-агрегаторов. До 3 адресов через "; ".
- Название могло смениться — запиши текущее в current_name, если оно другое.

ЗНАЧЕНИЯ status (строго одно из):
"Действует" | "В процессе ликвидации" | "Банкротство" | "Предстоящее исключение" | "Ликвидирована" | "Исключена ФНС" | "Реорганизована" | "ИП прекратил деятельность" | "Не установлено"
- "Банкротство" — идёт процедура банкротства, но из реестра ещё не исключена.
- "Предстоящее исключение" — ФНС приняла решение о предстоящем исключении, но запись ещё не внесена.
- "Ликвидирована" — прекратила деятельность через ликвидацию или после завершения банкротства.
- "Исключена ФНС" — исключена из ЕГРЮЛ как недействующая / из-за недостоверных сведений.
- "Реорганизована" — прекратила деятельность путём присоединения, слияния, преобразования.

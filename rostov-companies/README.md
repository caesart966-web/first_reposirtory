# Строители Ростовской области: статус компаний и почты

Задача: по двум выгрузкам реестра Союза «Строители Ростовской области»
(`input/register-1-500.xlsx`, `input/register-501-988.xlsx`, 988 строк,
987 разных ИНН) найти электронные почты и разложить компании по тому,
действуют ли они сейчас.

**Итог — `Строители_РО_статус_и_почты.xlsx`**: лист «Сводка» (сколько
действует, закрывается, не существует, не найдено, с почтой — формулами
по листу «Все компании») и отдельный лист на каждый итог.

## Два источника

1. **Checko API — основной.** Выписка из ЕГРЮЛ/ЕГРИП по каждому ИНН:
   точный статус и контакты. Один запрос на компанию, бесплатно — 100 в сутки.
   Из облачной среды Claude api.checko.ru закрыт, поэтому запуск — на своём
   компьютере: `checko_paket.zip` (внутри `README.txt`, `start_windows.bat`,
   `run.sh`). Программа `work/checko_status.py` сама продолжает с места
   остановки (ответы — в `checko_cache/`) и пересобирает таблицу.
2. **Веб-поиск по ИНН — запасной.** Статус и почта из выдачи поиска,
   только если результат привязан к этому ИНН/ОГРН; у каждой строки записан
   источник и что в нём сказано. Поиск ограничен: 200 запросов за ход,
   это 110–130 компаний.

`build.py` сводит оба: статус из Checko важнее статуса из поиска, почты
объединяются, столбец «Откуда статус» говорит, чей статус в строке.

## Как продолжить (для Claude)

Пользователь прислал готовую таблицу после запуска пакета — это и есть итог:
в ней уже сведены Checko и поиск. Прислал архив `checko_cache/` — распаковать
в `work/checko_cache/` и выполнить `python3 -I checko_status.py --offline`
(разбор без новых запросов, таблица пересоберётся).

Ещё один ход поиска:

```bash
cd rostov-companies/work
python3 -I make_round.py <номер хода> 5 25   # очередь непроверенных -> batches/rNN_XX.json
```

Пять помощников, каждому `agent_prompt_round.md` с подстановками
`{IN}` = `batches/rNN_XX.json`, `{OUT}` = `out/rNN_XX.json`, `{BUDGET}` = 38.
После хода:

```bash
python3 -I build.py "../Строители_РО_статус_и_почты.xlsx"
python3 -I make_package.py      # обновить checko_paket.zip свежими результатами поиска
```

- `parse.py` — исходные файлы → `all.json`;
- `batches/batch_NN.json` — 20 частей по 50 компаний (первый проход),
  `agent_prompt.md` — его инструкция;
- `make_round.py`, `agent_prompt_round.md` — следующие ходы поиска с бюджетом;
- `checko_status.py`, `start_windows.bat`, `run.sh`, `README.txt` — пакет Checko,
  `make_package.py` собирает из них `../checko_paket.zip`.

Ключ Checko (`checko_key.txt`) и сырые ответы (`checko_cache/`) в git
не попадают — правило в `.gitignore` корня.

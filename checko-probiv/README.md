# Пробив контактов членов СРО через Checko

Программа берёт реестр, отбирает нужные компании, запрашивает по каждому ИНН контакты
в [Checko](https://checko.ru/user/account/api) и складывает результат в Excel.

Главное: **суточный лимит учитывается между запусками**. За день программа не потратит
больше разрешённого, а завтра продолжит ровно с того места, где остановилась. Одну и ту же
компанию дважды не пробивает.

## Что нужно сделать один раз

1. **Установить Python** — https://www.python.org/downloads/
   При установке обязательно поставьте галочку **«Add python.exe to PATH»**.
2. **Положить реестр** в папку `input`. Годится любое:
   - `Реестр_членов_СРО_ПОС.xlsx` — сводная таблица (уже лежит там);
   - zip-архив с выгрузкой с сайта СРО;
   - файлы `register-1-500.xlsx`, `register-501-1000.xlsx` и т.д.
3. **Запустить `Запустить.bat`** — программа спросит ключ API один раз и сохранит его
   в `config.ini`. Ключ берётся в личном кабинете Checko.

Библиотеку `openpyxl` установит сам `Запустить.bat`.

## Как пользоваться

Раз в день двойным кликом запускаете **`Запустить.bat`**. Программа:

- берёт следующие 100 непробитых компаний,
- опрашивает Checko,
- кладёт в папку `Отчеты` два файла Excel,
- пишет в окне, сколько сделано и сколько осталось дней.

Когда лимит на сегодня исчерпан, она сообщает об этом и выходит — ничего не ломается,
просто запустите завтра.

Ещё два ярлыка:

- **`Демо без запросов.bat`** — показывает, как будет выглядеть отчёт, не тратя ни одного
  запроса. Полезно посмотреть перед первым боевым прогоном.
- **`Показать статус.bat`** — сколько пробито, сколько осталось, сколько потрачено сегодня.
  Тоже без запросов.

## Что в отчётах

В папке `Отчеты` появляются:

- **`Отчет_ГГГГ-ММ-ДД_ЧЧ-ММ.xlsx`** — результат конкретного прогона (сегодняшняя сотня);
- **`Все_результаты.xlsx`** — накопительный файл: всё, что пробито за все дни. Перезаписывается
  каждый прогон, так что итоговую таблицу всегда берите отсюда.

Колонки:

| Колонка | Что внутри |
|---|---|
| № | номер компании в реестре СРО |
| Наименование (реестр) | сокращённое наименование из реестра |
| ИНН | ИНН из реестра, по нему и шёл запрос |
| Телефоны (Checko) | что нашлось в Checko; несколько номеров — через запятую |
| Почта (Checko) | e-mail |
| Сайт (Checko) | сайт |
| Статус (Checko) | действующая / ликвидирована и т.п. |
| Адрес (Checko) | юридический адрес |
| Телефон в реестре | что стояло в выгрузке СРО — для сравнения |
| Новый контакт | «Да», если телефон из Checko отличается от реестрового |
| Дата вступления | из реестра |
| Дата прекращения | из реестра, пусто у действующих |
| Результат | найдено / контактов нет / не найдено / текст ошибки |

Фильтруйте по колонке **«Новый контакт» = Да** — это и есть добытые контакты, которых
в реестре не было.

## Настройки — `config.ini`

```ini
[checko]
key = ваш ключ
daily_limit = 100        ; сколько запросов в сутки разрешает тариф
base_url = https://api.checko.ru/v2
pause = 0.7              ; пауза между запросами, секунд

[выборка]
scope = active           ; кого пробивать
```

Значения `scope`:

| Значение | Кого берём | Сколько это |
|---|---|---|
| `active` | действующие члены СРО | 972 — стоит сейчас |
| `active_no_phone` | действующие, у кого в реестре нет своего телефона | 499 |
| `no_phone` | все, у кого в реестре нет своего телефона | 698 |
| `all` | вообще все записи реестра | 1590 |

Поменять `scope` можно в любой момент — уже пробитые компании повторно не запрашиваются,
программа просто добавит недостающих.

## Если что-то пошло не так

**В отчёте у всех «ошибка: HTTP 401/403».** Неверный ключ — проверьте `config.ini`.

**В отчёте у всех «в Checko не найдено», хотя компании существуют.** Скорее всего, у метода
API другой формат ответа, чем ожидает программа. Все ответы Checko сохраняются как есть
в папке `состояние/ответы/` — пришлите мне **один любой файл оттуда**, и я поправлю разбор.
Повторно тратить запросы не придётся: программа пересоберёт отчёт из сохранённых ответов.

**«Суточный лимит исчерпан», а Checko говорит, что запросы есть.** Счётчик считает по дате
вашего компьютера, а Checko может обнулять лимит по Москве. Сбросить счётчик вручную:
`Запустить.bat --reset-day`, либо из командной строки `python probiv.py --reset-day`.

**Ошибка сети или сервера** по конкретной компании — не страшно: такие записи программа
сама повторит в следующие прогоны, до трёх попыток.

## Как устроено внутри

- `probiv.py` — программа.
- `phones.py` — приведение телефонов к единому виду (используется при чтении сырой выгрузки).
- `config.ini` — ключ и настройки. **Содержит ваш ключ API, не выкладывайте его никуда.**
- `состояние/состояние.json` — что уже пробито и сколько запросов потрачено по дням.
  Удалите этот файл, если хотите начать с нуля.
- `состояние/ответы/ИНН.json` — сырые ответы Checko. Благодаря им отчёт можно пересобрать
  без новых запросов.

Запросы считаются по факту ответа сервера. Если до Checko не достучались (нет интернета),
запрос не засчитывается и компания остаётся в очереди.

# Контакты членов СРО из Checko

Программа берёт реестр, по каждому ИНН запрашивает контакты в Checko и складывает всё
в один файл `Отчет.xlsx`. Суточный лимит соблюдается сам: за день не потратит больше
разрешённого, назавтра продолжит с того места, где остановилась, дважды никого не спросит.

## Куда вставить ключ API

Откройте `config.ini` (правая кнопка → Открыть с помощью → Блокнот). Найдите строку:

```
key =
```

Впишите ключ сразу после «равно», сохраните Ctrl+S. Ключ берётся здесь:
https://checko.ru/user/account/api

## Что запускать

| Файл | Что делает |
|---|---|
| **`Проверка 3 компании.bat`** | 3 запроса вместо 100 — убедиться, что ключ работает. **С этого начните.** |
| **`Запустить.bat`** | обычный прогон: очередные 100 компаний. Раз в день. |
| **`Показать статус.bat`** | сколько пробито, сколько осталось. Запросы не тратит. |

Если удобнее из командной строки: щёлкните в адресной строке проводника, напишите `cmd`
и нажмите Enter — откроется окно в этой папке. Дальше:

```
python probiv.py              обычный прогон
python probiv.py --limit 3    только 3 запроса
python probiv.py --status     что сделано, без запросов
python probiv.py --reset-day  обнулить счётчик за сегодня
```

## Отчёт

Файл **`Отчет.xlsx`** в этой же папке. Он один и обновляется после каждого прогона —
в нём накапливается всё, что пробито за все дни.

Колонки: № · Наименование · ИНН · Телефоны · Почта · Сайт · Статус · Адрес ·
Дата вступления · Дата прекращения · Дата пробива.

Первые восемь — из Checko, даты вступления и прекращения — из реестра СРО,
«Дата пробива» — когда эта строка была получена. Отфильтруйте по ней, если нужно
посмотреть только сегодняшнюю сотню.

Если `Отчет.xlsx` открыт в Excel в момент прогона, программа не потеряет данные —
запишет рядом `Отчет_новый.xlsx` и скажет об этом.

## Настройки — `config.ini`

```ini
key = ваш ключ
daily_limit = 100        ; сколько запросов в сутки даёт тариф
scope = active           ; кого пробивать
```

Значения `scope`: `active` — действующие члены (972, стоит сейчас) · `active_no_phone` —
действующие без своего телефона (499) · `no_phone` — все без своего телефона (698) ·
`all` — весь реестр (1590). Менять можно в любой момент: пробитые повторно не запрашиваются.

## Если что-то не так

**У всех «ошибка: HTTP 401» или «403»** — неверный ключ, проверьте `config.ini`.

**У всех «не найдено в Checko», хотя компании существуют** — у API другой формат ответа,
чем ожидает программа. Все ответы Checko сохраняются в папке `состояние/ответы/`.
Пришлите мне один любой файл оттуда — поправлю, и отчёт пересоберётся из уже сохранённых
ответов, без новых запросов.

**«Суточный лимит исчерпан», а на Checko запросы есть** — счётчик идёт по дате компьютера,
а Checko может обнулять по Москве. Выполните `python probiv.py --reset-day`.

**Ошибка сети по отдельной компании** — не страшно, программа сама повторит её в следующие
прогоны, до трёх раз.

## Файлы папки

- `probiv.py`, `phones.py` — сама программа.
- `config.ini` — ключ и настройки. **Ключ никому не показывайте.**
- `input` — сюда кладётся реестр (уже лежит). Годится и zip-архив выгрузки с сайта СРО.
- `состояние` — память программы: что пробито и сколько запросов потрачено по дням.
  Плюс сырые ответы Checko. Удалять не нужно; удалите, если хотите начать с нуля.
- `Отчет.xlsx` — результат.

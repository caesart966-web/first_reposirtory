# Как собрать почты — пошагово

Инструкция для Windows. На Mac/Linux всё то же самое, только вместо `python`
пишите `python3`, и папка с результатом не откроется сама.

---

## ШАГ 1. Установить Python

1. Откройте https://www.python.org/downloads/ и нажмите жёлтую кнопку
   **Download Python**.
2. Запустите скачанный файл.
3. **САМОЕ ВАЖНОЕ:** на первом экране установщика внизу поставьте галочку
   **«Add python.exe to PATH»**. Без неё команды из инструкции работать не
   будут, и придётся переустанавливать.
4. Нажмите **Install Now**, дождитесь конца, нажмите **Close**.

**Проверка.** Нажмите `Win + R`, введите `cmd`, Enter. В чёрном окне наберите:

```
python --version
```

Должно ответить `Python 3.12.x` (цифры могут отличаться, главное — 3 и выше).
Если пишет «не является внутренней или внешней командой» — Python
установился без галочки PATH. Переустановите с галочкой.

---

## ШАГ 2. Разложить файлы

1. Создайте папку `C:\parser` (прямо в корне диска C, чтобы путь был коротким
   и без пробелов).
2. Положите в неё четыре файла — я их прислал в чат:
   - `stage0_discover.py`
   - `stage1_sites.py`
   - `stage2_merge.py`
   - `Компании (4).xlsx`

Должно получиться так:

```
C:\parser\
    stage0_discover.py
    stage1_sites.py
    stage2_merge.py
    Компании (4).xlsx
```

Файл xlsx скрипты найдут сами — указывать путь не нужно.

---

## ШАГ 3. Установить две библиотеки

Откройте `cmd` (`Win + R` → `cmd` → Enter) и выполните две команды по очереди:

```
cd C:\parser
pip install requests openpyxl
```

Должно закончиться словами `Successfully installed ...`.
Если `pip` не найден — используйте:

```
python -m pip install requests openpyxl
```

Окно `cmd` дальше не закрывайте, все команды выполняются в нём.

## ШАГ 4. Пробный прогон парсера (5 компаний, полминуты)

```
python stage1_sites.py --limit 30
```

Скрипт возьмёт строки, где почта пустая, а сайт указан. Таких в файле пять.

**Что должно появиться на экране:**

```
Подходит под условие «email пустой И сайт заполнен»: 5
Пропущено (почта пустая, сайта нет): 1194
[1/5] OK ООО "СПЕЦМОНТАЖСТРОЙ"   найдено -> info@complectm.ru;...
...
Найдено    : 3
```

В конце сама откроется папка `C:\parser\result` с файлом
**`stage1_emails.xlsx`** — откройте, посмотрите глазами.

Сколько именно найдётся — не знаю: у меня в облаке эти сайты не открывались,
там закрыт выход в интернет. У вас должны открыться.

Если все пять — «сайт не открылся», проверьте, что сайты вообще живы: вбейте
`complectm.ru` в браузер. Возможно, часть просто закрылась.

## ШАГ 5. Пробный поиск сайтов (30 компаний, 3–5 минут)

Это для тех 1 194 строк, где сайта нет — сначала надо его найти.

```
python stage0_discover.py --limit 30
```

Скрипт ищет сайт по ИНН и проверяет: **берёт только тот, на котором этот
самый ИНН реально написан**. Одного совпадения названия мало — одноимённых
ООО в России десятки, так в таблицы и попадают чужие почты.

**Что появится:**

```
[1/30] OK ООО "..."   найден и подтверждён -> primer.ru
[2/30]    ООО "..."   сайт не найден
[3/30]    ООО "..."   не подтверждён
```

Результат — `result\discovered_sites.csv`.

### ⚠️ Здесь остановитесь и посчитайте

Посмотрите, у скольких из 30 статус **«найден и подтверждён»**, и напишите мне
цифру. От неё зависит, стоит ли гонять остальные 1 164:

- **найдено 5 и больше** — отлично, идём дальше по шагам;
- **найдено 1–4** — на весь список выйдет 40–150 сайтов, решайте, стоит ли
  нескольких часов;
- **найдено 0** — дальше идти смысла нет, у этих компаний сайтов просто нет.
  Напишите мне, обсудим другой путь.

## ШАГ 6. Полный поиск сайтов (несколько часов)

Только если шаг 5 дал приемлемый результат.

```
python stage0_discover.py
```

Пойдёт по всем 1 194 компаниям. Это долго: между запросами к поисковику стоит
пауза, иначе он начнёт блокировать.

**Прерывать можно спокойно.** Закройте окно или нажмите `Ctrl + C` — прогресс
сохраняется после каждой компании. Запустите ту же команду снова, и скрипт
продолжит с места, где остановился, а не начнёт заново.

**Если пошли сплошные «сайт не найден»** — скорее всего, поисковик начал
показывать капчу. Два варианта:

- подождать час и запустить снова;
- завести ключ на https://serpapi.com (есть бесплатный лимит), и перед
  запуском выполнить в том же окне `cmd`:

```
set SERPAPI_KEY=ваш_ключ_сюда
python stage0_discover.py
```

Скрипт сам переключится на платный поиск, капчи не будет.

## ШАГ 7. Основной прогон парсера

```
python stage1_sites.py --extra-sites result/discovered_sites.csv
```

Теперь парсер обойдёт и те пять сайтов из таблицы, и все найденные на шаге 6.
Тоже можно прерывать и продолжать.

## ШАГ 8. Собрать итоговую таблицу

```
python stage2_merge.py
```

Возьмёт ваш исходный файл и подставит в него всё найденное. Получится
**`Компании (4) — с почтами.xlsx`** рядом с исходным.

Что будет в колонке email:

| Что видите | Что это значит |
|---|---|
| обычный адрес | был в исходном файле |
| адрес на зелёном фоне | найден парсером, рядом в колонке «Источник» видно откуда |
| `нет в открытых источниках` | проверено, на сайте почты нет |
| `не проверялось` | до этой строки прогон не дошёл |

Пустых ячеек не останется. Выдуманных адресов тоже — подставляется только то,
что реально снято со страницы.

## Если что-то пошло не так

**«python не является внутренней или внешней командой»**
Python поставлен без галочки «Add python.exe to PATH». Переустановите с ней.

**«ModuleNotFoundError: No module named 'requests'»**
Не выполнен шаг 3. Выполните `python -m pip install requests openpyxl`.

**«!! Не нашёл входной xlsx»**
Файл `Компании (4).xlsx` не лежит рядом со скриптами. Либо положите его туда,
либо укажите путь явно:
```
python stage1_sites.py --input "C:\путь\к\файлу.xlsx"
```

**В окне cmd вместо русских букв кракозябры**
Выполните `chcp 65001` и запустите команду заново. На работу скриптов это не
влияет, только на вид в консоли.

**Антивирус ругается на скрипт**
Это обычные текстовые файлы Python, их можно открыть «Блокнотом» и прочитать.
Добавьте папку `C:\parser` в исключения.

**Всё зависло и ничего не происходит**
Скрипт ждёт ответа от сайтов, у каждого таймаут 10 секунд. Подождите минуту.
Если не отмерло — `Ctrl + C`, прогресс сохранён, запускайте снова.

# Правила кита (source of truth)

Этот файл — разбор промта заказчика. `build_kit.py` повторяет эти правила в коде
и падает с ошибкой, если содержимое кита их нарушает. Меняете правило — меняйте
обе стороны.

## 1. Уровень привязан к номеру кита

| Кит | Level | Что это значит для содержания |
|-----|-------|-------------------------------|
| 1–3 | **B2 Beginner** | обычная лексика, частотные коннекторы, ясная структура абзаца |
| 4–7 | **B2 Advanced** | более плотный синтаксис, тонкие коннекторы, абстрактные темы абзацев |
| 8–12 | **C1 Entry** | инверсии, академический регистр, многослойный вывод (inference) |

Подпись обязательна вверху первой страницы: `Kit X / 12 — Level: B2 Beginner /
B2 Advanced / C1 Entry`. Строку собирает `level_for_kit()`, вручную её не пишут.

Отдельно на обложке печатается фактический разрез: `Seviye: B2 (X soru) / C1 (Y
soru)`. Числа не выдумываются — они считаются по полю `level` каждого вопроса,
поэтому подпись не может разойтись с содержанием.

## 3. Типы ловушек по разделам

**Sentence Completion.** Основа должна быть грамматически незаконченной, а не
только незаконченной по смыслу. Набор: рассогласование времени и маркера
времени, `so ... that` / `such ... that`, висячий причастный оборот (кто субъект),
логика связи (контраст / добавление / причина-следствие), пропуск в
относительном придаточном (`which / where / when / whose`).

**Translation.** Один явно верный вариант и четыре правдоподобных с конкретным
дефектом. EN→TR: перевернуть `little / few / rarely / seldom` в положительное;
сломать инверсию (`Not until ... did`, `Rarely does`, `Seldom is`); перепутать
направление `nor / neither`. TR→EN: ошибка согласования подлежащего и сказуемого;
не то относительное местоимение (`who / whose / which`); двойное отрицание
(`unless + don't`); не та конструкция (`worth to` вместо `worth Ving`);
переворот залога.

**Paragraph Questions.** В каждом тексте есть все четыре типа: `according to the
passage`, `it is clear that`, вывод (inference), главная мысль (main idea).
Это правило проверяется при сборке: текст без одного из типов не соберётся.
Ловушки: наполовину верный вариант; искажающие слова (`specifically /
immediately / only / all / credited with`); сказанное сравнение против
подразумеваемого; метафора, прочитанная как факт.

**Dialogue Completion.** Пропущенная реплика должна быть логически необходимой,
а не просто «на ту же тему». Дистракторы — по теме, но логически неверные.

**Restatement.** Ловушки: подмена слова меняет смысл; несовпадение модальности
(`may / must / should`); переворот залога.

**Paragraph Completion.** Проверяются отсылки и течение смысла. Ловушки: не то
направление коннектора (`however / therefore / moreover`); неоднозначный
референт у `it / this / they`.

**Odd Sentence Out.** Лишнее предложение должно быть по теме, но рвать связность.
Очевидно посторонним делать нельзя.

## 4. Обязательные части документа

- **Обложка.** `YDS DENEME — [тема/дата]`, `Kit No: X / 12`,
  `Seviye: B2 (X soru) / C1 (Y soru)`, инструкции по-турецки.
- **Тело.** Две колонки, каждый вопрос в рамке, основа полужирным, варианты A–E
  обычным с отступом, турецкие заголовки разделов.
- **SORU AÇIKLAMALARI.** По каждому вопросу одна фраза, почему верный ответ
  верен, и одна — про ловушку в самом популярном неверном варианте. Формат:
  `Q27 — Doğru: B. [açıklama]. Tuzak: [açıklama].`
- **CEVAP ANAHTARI.** Сетка «номер | правильный | мой ответ | ✓/✗», колонка
  «мой ответ» пустая. Плюс сплошной список `27-A 28-C ...` до 80.
- **KELİME RÖNTGENİ.** Все C1+ слова, встретившиеся в тесте: две колонки
  «английское слово/выражение | турецкое значение», по алфавиту, без примеров
  и определений. Минимум 40 позиций, максимума нет; коллокации и устойчивые
  выражения включаются (`subject to → tabi olmak`).

Порядок последних страниц: açıklamalar → cevap anahtarı → kelime röntgeni.

## 5. Два расхождения в исходном промте

1. Обложка требует `Kit No: X / 15`, а раздел про уровни — `Kit X / 12` с
   диапазонами 1–3, 4–7, 8–12. Взято **12**: диапазоны уровней покрывают ровно
   1–12, а число 15 не покрыто ничем. Если китов всё-таки 15 — поменять
   `TOTAL_KITS` и `LEVEL_BANDS` в `build_kit.py` и таблицу выше.
2. Промт говорит «full 54-question booklet», а нумерация 27–80 — это часть
   80-вопросного экзамена ÖSYM. Оставлена нумерация 27–80: 54 вопроса, номера
   как в настоящем буклете.

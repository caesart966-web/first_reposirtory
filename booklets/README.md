# Буклеты — генератор профессиональных изданий (.docx)

Собирает буклет формата A4 из структурированного содержания: обложка, оглавление
с реальными номерами страниц, разделители глав с аннотациями, нумерованные
разделы, сноски, врезки, таблицы, чек-листы, библиография и указатель.

Сейчас собираются два буклета:

| Буклет | Файл | Объём |
|---|---|---|
| **Turkish Export Operations** — практическое руководство для специалистов по экспортным продажам и внешней торговле | `dist/Turkish-Export-Operations-Field-Guide.docx` | 46 страниц, 6 глав, 4 приложения |
| **Economic Diplomacy in Practice** — руководство для входящих в институты экономической дипломатии (DEİK-типа) | `dist/DEIK-Economic-Diplomacy-Formation-Guide.docx` | 48 страниц, 7 глав, 4 приложения, библиография |

## Как собрать

```bash
cd booklets
npm install          # ставит docx (docx-js)
node build.js all    # или: node build.js export | node build.js deik
```

Для сборки нужны `node`, а для оглавления — `soffice` (LibreOffice) и `pymupdf`
(`pip install pymupdf`). Без них документ соберётся, но номера страниц в
оглавлении будут прочерками.

## Почему оглавление собирается в два прохода

Word умеет собирать оглавление сам, полем `TOC`, но такое поле выглядит пустым,
пока читатель не обновит его вручную, и в PDF попадает надпись «обновите поле».
Поэтому номера страниц здесь **настоящие**: первый проход собирает документ без
номеров, LibreOffice превращает его в PDF, `tools/pagemap.py` находит, на какой
странице оказался каждый заголовок, второй проход подставляет номера. Затем
сборка проверяет, что подстановка номеров не сдвинула вёрстку, и при
необходимости делает третий проход. В выводе это строка
`içindekiler : sayfa numaraları oturdu`.

## Как писать содержание

Глава — это объект с заголовком, аннотацией для разделителя, списком целей и
массивом блоков:

```js
module.exports = {
  title: 'Documentation Master Guide',
  abstract: ['Абзац для страницы-разделителя.'],
  outcomes: ['Что читатель сможет делать после главы.'],
  blocks: [
    { h2: 'Заголовок раздела' },          // нумеруется сам: 3.1, 3.2, …
    { h3: 'Подраздел' },                  // 3.1.1
    { lead: 'Вводный абзац покрупнее.' },
    { p: 'Обычный абзац с **жирным** и *курсивом*.' },
    { bullets: ['пункт', 'пункт'] },
    { steps: ['шаг', 'шаг'] },            // нумерованные шаги
    { checklist: ['пункт с квадратиком'] },
    { table: { title: 'Table 3.1 — …', head: […], rows: [[…]], widths: [2, 3], note: '…' } },
    { box: { kind: 'field', title: '…', body: ['абзац', { bullets: […] }] } },
    { quote: 'Врезка-цитата', by: 'источник' },
  ],
};
```

Виды врезок (`kind`): `definition`, `field`, `warning`, `case`, `exercise` —
у каждой свой цвет, подпись и левая полоса.

**Сноски** пишутся прямо в тексте: `текст[^Источник, издательство, год.]`.
Нумерация сквозная, сноски печатаются внизу своей страницы.

**Указатель** строится сам: в сборке буклета перечисляются термины, а генератор
ищет, в каких разделах они встречаются, и печатает ссылки на **номера разделов**
(§4.3), а не на страницы — такие ссылки не ломаются при перевёрстке.

## Что важно не сломать

- **Ширины колонок задаются дважды** — в `columnWidths` таблицы и в `width`
  каждой ячейки, обе в DXA. Проценты ломаются в Google Docs.
- **Заливка ячеек — только `ShadingType.CLEAR`**; `SOLID` рисуется чёрным.
- **Точки-лидеры в оглавлении** сделаны настоящей табуляцией с `LeaderType.DOT`,
  а не `PositionalTab`: последний Word рисует, а LibreOffice игнорирует, и в PDF
  номера страниц уезжают к тексту.
- **Шрифты заданы как Times New Roman / Arial.** В контейнере их нет, но
  Liberation Serif и Liberation Sans метрически с ними совпадают, поэтому PDF из
  LibreOffice показывает ту же вёрстку, что увидит читатель в Word.
- Списки не набираются символом «•» руками — они идут через `numbering`.

## Про содержание

Оба буклета написаны так, чтобы не выдавать за факт то, что меняется. Тарифы,
ставки, санкционные списки, проценты репатриации выручки и подобные величины в
тексте **не приводятся**: вместо них назван первоисточник, который нужно открыть.
Это осознанное решение, а не осторожность: справочник с устаревшей цифрой хуже,
чем справочник без неё.

Ни один из буклетов не является изданием какой-либо организации и не связан с
ней. В обоих это сказано прямо — на обложке и в предисловии.

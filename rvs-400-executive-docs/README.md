# Исполнительная документация — монтаж и сварка РВС-400 м³ (2 шт.)

Комплект исполнительной документации на монтаж и сварку двух стальных вертикальных
цилиндрических резервуаров объёмом 400 м³ для хранения спиртов.

| | |
|---|---|
| Объект | Монтаж РВС-400 м³ (2 шт.) для хранения спиртов |
| Адрес | Московская обл., муниципальный округ Шатура, г. Рошаль |
| Заказчик | ООО «ЮГМЕТПРОМ» |
| Подрядчик | ООО ПО «ВЗРК» |
| Основание | Договор строительного подряда № 93 от 29.09.2025 |
| Рабочая документация | VZRK-012.ТВС.772-КМ, VZRK-012.ТВС.772-КМД |
| ППР | VZRK-012.ТВС.772-ППР |

## Что здесь

```
project_data.py   исходные данные объекта, ведомость элементов, реестр материалов,
                  объёмы неразрушающего контроля — всё выписано из КМ и ППР
acts_data.py      содержание 12 актов освидетельствования скрытых работ
docxlib.py        обёртка над python-docx (формы, бланочные строки, таблицы)
generate.py       генератор комплекта
output/           сформированный комплект (69 файлов)
```

Пересборка:

```bash
pip install python-docx openpyxl
python3 generate.py            # → ./output
python3 generate.py /путь      # → произвольный каталог
```

## Состав комплекта (`output/`)

**00 Общие документы**
- Пояснительная записка по комплектации
- Опись исполнительной документации
- Перечень актов освидетельствования скрытых работ
- Ведомость объёмов контроля сварных соединений
- Реестр сертификатов, паспортов и документов о качестве (`.xlsx`, 3 листа)

**01 / 02 РВС-400 №1 и №2** — по каждому резервуару 29 документов:
1. Приёмка и входной контроль — 4 акта
2. Акты освидетельствования скрытых работ — 12 актов (АОСР 01–12)
3. Контроль качества — 6 документов (ВИК, РК, вакуумирование, «мел-керосин»,
   схема сварных соединений, контроль геометрии)
4. Испытания — 5 актов (готовность, гидравлическое, избыточное давление,
   вакуум, осадка и отклонения)
5. Приёмка — акт освидетельствования ответственных конструкций, акт завершения монтажа

**04 Журналы** — общий журнал работ, журнал сварочных работ, журнал входного
контроля, журнал антикоррозионных работ.

**PDF для печати** — сводные комплекты актов по каждому резервуару (59 стр.),
журналы и общие документы в PDF.

**КОМПЛЕКТ АКТОВ РВС-400 №1/№2 (для печати).docx** — все акты одного резервуара
в одном файле, с автоматической сменой ориентации страниц под широкие формы.

## Нормативная основа

- Формы АОСР и акта освидетельствования ответственных конструкций —
  приложения к приказу Ростехнадзора от 16.05.2023 № 344 (действует с 01.09.2023
  взамен РД-11-02-2006).
- Технические требования, объёмы и методы контроля — ГОСТ 31385-2023,
  СП 365.1325800.2017, СП 70.13330.2012, РД 03-606-03, ГОСТ 7512-82,
  ГОСТ 3242-79, ГОСТ 23055-78 и ППР VZRK-012.ТВС.772-ППР.

## Важно

Документы — подготовленные к заполнению формы. Номера и даты актов, реквизиты
организаций (ОГРН, ИНН, СРО), фамилии и подписи, номера сертификатов, фактические
результаты измерений и испытаний заполняются ответственными лицами по фактически
выполненным работам. Никакие результаты контроля, испытаний и клейма сварщиков
в формах не проставлены.

# ИИ-ассистент строительного контроля — Claude Code Skill

Кастомный Claude Code skill **`/construction-control`**: оркестратор строительного
контроля, который по документам стройки (договор, смета/ВОР, календарный график,
проектная/рабочая документация, планы помещений, техкарты) и видеообходам объекта
оценивает фактический прогресс, сопоставляет факт с графиком и сметой, выявляет
отклонения, дефекты и риски и формирует недельный отчёт.

## Пять агентов

**Document Extraction** → **Visual Progress** → **Schedule Control** ∥ **Quality
Control** → **Chief Construction**. Каждый возвращает строго структурированный JSON
по своей схеме; критические выводы уходят на подтверждение человеку.

## Ключевые принципы

- Доказательность: факт — только по кадрам (`EvidenceFrame`); ссылки на документы —
  только реальные, иначе `null`.
- Строгий JSON по схемам из `schemas/` (валидация `scripts/validate.py`).
- Human-in-the-loop: система не подписывает акты, не подтверждает скрытые работы по
  видео, не принимает работы окончательно; критическое — специалисту.
- MVP без BIM: планы помещений + ручная привязка задач к помещениям + ключевые
  кадры. Готовые модели (мультимодальная LLM, OCR, ASR, векторный поиск), без
  обучения своих нейросетей на первом этапе.

Подробности — в `.claude/skills/construction-control/SKILL.md`.

## Быстрая проверка

```bash
cd .claude/skills/construction-control

```

# файл будет скачан и сконвертирован в Markdown автоматически.

#   - прямые ссылки (https://.../file.pdf)

#   - Яндекс.Диск   (публичная ссылка)
#   - Dropbox       (обычная ссылка «поделиться»)
#
# Строки, начинающиеся с #, игнорируются.
# Уже обработанные ссылки повторно не скачиваются

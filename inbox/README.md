# 📥 Inbox — папка для загрузки файлов

Загрузите сюда любой файл — PDF, Word, Excel, PowerPoint, картинку, скан,
HTML, CSV — и он **автоматически** сконвертируется в Markdown. Результат
появится в папке [`converted/`](../converted/) через 1–2 минуты.

## Как загрузить через сайт GitHub

1. Откройте эту папку (`inbox/`) на GitHub
2. Нажмите **Add file → Upload files**
3. Перетащите файлы в окно и нажмите **Commit changes**
4. Подождите 1–2 минуты (вкладка **Actions** покажет прогресс)
5. Готовый `имя_расширение.md` появится в папке `converted/`

## Что происходит под капотом

GitHub Action запускает MarkItDown + Tesseract OCR:

- обычные документы → извлечение текста, таблиц, заголовков;
- сканы и картинки → OCR (английский + русский);
- результат коммитится в `converted/` автоматически.

В сессии Claude Code файлы из этой папки конвертируются и локальным хуком —
Action нужен, чтобы конвертация работала даже без запущенной сессии.

## Большие файлы (больше 25 МБ) — через ссылку

Через веб-интерфейс GitHub нельзя загрузить файл больше 25 МБ, но это не
проблема: откройте [`links.txt`](./links.txt) в этой папке (карандаш ✏️ —
Edit), вставьте ссылку на файл и нажмите **Commit changes**. Файл будет
скачан и сконвертирован, в репозиторий попадёт только лёгкий `.md` —
поэтому размер почти не ограничен (до 2 ГБ).

Поддерживаются ссылки: прямые, **Google Drive** («все, у кого есть ссылка»),
**Яндекс.Диск** (публичная), **Dropbox**.

## Ограничения

- Файл в эту папку: до **25 МБ** через сайт, до 100 МБ через `git push`;
  больше — используйте `links.txt` (см. выше).
- Рукописный текст OCR не распознаёт — но Claude может посмотреть
  картинку/страницу глазами (`scripts/pages.py`).
- Зашифрованные PDF нужно расшифровать перед загрузкой.
- Очень большие сканы (сотни страниц OCR) конвертируются несколько минут.

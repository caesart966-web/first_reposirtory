# Архитектура MVP (без BIM)

Цель MVP — доказать ценность на реальном объекте без BIM-модели, без обучения
собственных нейросетей, на готовых сервисах. Привязка «работа ↔ место» держится на
**планах помещений + ручной привязке + ключевых кадрах из видео**.

## Что входит в MVP

- **Документы:** договор + доп. соглашения, смета/ВОР (XLSX/PDF), календарный
  график (XLSX/MPP-экспорт/PDF), планы этажей (PDF/изображение), техкарты/требования
  к качеству (PDF/DOCX). Проектная документация — читается для требований, но 3D не
  используется.
- **Структура объекта:** плоская — `Building → Floor → (Zone) → Room`. `Room` —
  единица привязки. Разметка помещений на плане — вручную (полигоны/коды) один раз.
- **Привязка работ к помещениям:** **ручная**, с автоподсказками по совпадению
  названий/кодов. `EstimateItem.room_ids`, `ScheduleTask.room_ids`.
- **Видео:** обычная или 360° камера. Сегментация по помещениям — по табличкам
  (OCR) и/или речи оператора (ASR); где не вышло — ручная привязка сегмента.
- **Анализ кадров:** готовая мультимодальная LLM по отобранным ключевым кадрам;
  статус и грубый % готовности.
- **Расчёты:** отклонения, просрочка, последовательность, прогноз — обычная
  арифметика (`deviation.py`).
- **Отчёт:** недельный, в JSON + markdown, с очередью на подтверждение человеком.

## Чего в MVP НЕТ (сознательно отложено)

- BIM-модель и автосопоставление кадров с 3D-геометрией.
- Обучение/дообучение собственных CV-моделей и детекторов дефектов.
- Автоматические обмеры и вычисление объёмов из видео (только грубая оценка %).
- Полная автопривязка видео к помещениям без табличек/речи (только эвристика).
- Интеграция с датчиками/IoT, фотограмметрия, облака точек.
- Автоматическое формирование исполнительной документации и актов.

## Технологический стек (готовые компоненты)

| Функция | Готовый компонент (пример класса) |
|---|---|
| Оркестрация агентов | Claude Code Skill + субагенты |
| Мультимодальный анализ кадров | облачная мультимодальная LLM |
| OCR (таблички, сметы-сканы, штампы) | готовый OCR-сервис |
| Распознавание речи (RU) | готовый ASR-сервис |
| Эмбеддинги/векторный поиск | готовая векторная БД |
| Извлечение кадров, разворот 360° | ffmpeg + библиотека проекций |
| Парсинг PDF/DOCX/XLSX/график | готовые парсеры |
| Хранилища | реляционная БД + объектное + векторное |
| PM-задачи, уведомления | внешние API (PM-система, email/мессенджер) |

## Минимальный сквозной сценарий MVP (демо)

1. Загрузить договор, смету, график, план 3-го этажа, техкарту отделки.
2. Извлечь структуру → подтвердить/поправить (шаг 3).
3. На плане привязать 10–15 позиций сметы/задач к помещениям 301–315.
4. Загрузить видеообход 3-го этажа (оператор называет помещения вслух / снимает
   таблички).
5. Получить наблюдения по помещениям, отклонения по графику, 2–3 дефекта.
6. Проверить критические выводы (шаг 12).
7. Выпустить недельный отчёт с 5–10 ранжированными проблемами и рекомендациями.

## Организация ручной привязки (ключ к MVP без BIM)

- Один раз на объект: разметка помещений на планах (коды + полигоны).
- Далее привязка позиций/задач к помещениям — таблица с автоподсказками; человек
  подтверждает. Это единственная существенная ручная работа, и она разовая на
  задачу, а не на каждый обход.
- Дисциплина съёмки: оператор проговаривает номера помещений и снимает таблички —
  это резко повышает автосегментацию без всякого BIM.

## Путь развития после MVP (не реализуется сейчас)

1. Автопривязка кадров к помещениям по визуальным признакам (снижение ручного труда).
2. Специализированные детекторы типовых дефектов и стадий работ.
3. Оценка объёмов по 360°/фотограмметрии.
4. Интеграция с BIM (сопоставление наблюдений с элементами модели).
5. Обучение на накопленном журнале правок человека (см. `human-in-the-loop.md`).

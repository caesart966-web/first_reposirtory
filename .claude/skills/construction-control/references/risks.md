# Основные технические и юридические риски

Читать перед продакшн-внедрением. Для каждого риска — суть, последствие и меры,
уже заложенные в дизайн.

## Технические риски

| Риск | Последствие | Меры (заложены в систему) |
|---|---|---|
| **Галлюцинации мультимодальной LLM** | Ложные выводы о работах/дефектах | Только по кадрам-доказательствам; строгий JSON; `confidence`; критическое — на человека; запрет фактов без `EvidenceFrame` |
| **Ошибка привязки к помещению** | Наблюдение отнесено не к тому помещению | Приоритет OCR-табличек/речи; `room_assignment_method`+`confidence`; при неоднозначности — ручная привязка, не угадывание |
| **Слепые зоны и неполный обход** | Пропущенные проблемы, ложное «всё ок» | `coverage.rooms_missing`, `Issue(coverage_gap)`, KPI покрытия; отсутствие данных ≠ готовность |
| **Плохое качество кадров (свет, смаз, 360-искажения)** | Неверная оценка статуса | `quality_flags`; запрет единственного «плохого» доказательства; низкий `confidence`→человек; рекомендация пересъёма |
| **Неверная оценка % готовности** | Ошибочные отклонения | Грубая оценка + MAE-контроль (≤15 п.п.); отклонения считает арифметика, не LLM; калибровка по журналу правок |
| **Регресс/скачки между обходами** | Артефакт распознавания принят за факт | Флаг регресса → человек; сравнение ракурсов через `search_video_archive` |
| **Разнородные форматы документов (сканы, нетабличные сметы)** | Ошибки извлечения | OCR + `extraction_gaps(needs_human)`; проверка человеком на шаге 3; `source` для аудита |
| **Изменение версий документов** | Работа по устаревшему графику/смете | `diff_documents`, версионирование, пересчёт при обновлении |
| **Дрейф качества готовых моделей/API** | Нестабильные результаты во времени | Версионирование промптов и моделей; регресс-тесты (T1–T12); детерминированность расчётов |
| **Масштаб/стоимость обработки видео** | Дорого/медленно | Ключевые кадры вместо всех; лёгкие сигналы (ASR/OCR) до дорогой LLM; кэш эмбеддингов |
| **Prompt injection через тексты в кадрах/документах** | Подмена выводов | Тексты OCR/документов — как данные, не инструкции; изоляция инструментов; валидация выходов |

## Юридические и организационные риски

| Риск | Последствие | Меры |
|---|---|---|
| **Юридический статус выводов** | Попытка использовать отчёт как приёмку/основание для оплаты или санкций | Обязательный `disclaimer`: отчёт информационный, не приёмка; система не формирует акты; критическое — за специалистом |
| **Скрытые работы** | Незаконное «подтверждение» по видео | Жёсткий запрет `confirmed_visual` для `is_hidden_work`; только `needs_instrumental_check`/освидетельствование человеком |
| **Ответственность за ошибочные обвинения подрядчика** | Споры, репутационный/финансовый вред | Уведомления только после подтверждения человеком; формулировки как гипотезы при недостатке доказательств |
| **Персональные данные (лица рабочих на видео)** | Нарушение законодательства о ПДн | Размытие лиц до анализа; хранение с ограничением доступа; политика ретенции видео |
| **Коммерческая тайна (договор, цены, смета)** | Утечка чувствительных данных | Разграничение доступа; аудит-лог; при использовании внешних API — контроль передачи/локализации данных |
| **Договорная терминология и нормативка (СП, ГОСТ, техрегламенты)** | Неверная трактовка требований | Извлечение с `source`+цитатой; проверка человеком; система не даёт юридических заключений |
| **Доказательность в спорах/суде** | Кадр/вывод оспорим | Полная трассируемость (кадр+таймкод+пункт), журнал аудита, неизменяемость истории обходов |
| **Расхождение с исполнительной документацией** | Конфликт «видео vs бумага» | Система сопоставляет, но не заменяет исполнительную документацию; расхождения → человеку |

## Принципиальные ограничения (честно заявить пользователю)

- Видео показывает **видимое** состояние в момент съёмки — не прочность, влажность,
  геометрию с допусками, соответствие сертификатов. Эти проверки — вне системы.
- Оценка % готовности — **приблизительная**; служит для приоритизации внимания, не
  для расчётов за выполненные объёмы.
- Система — инструмент поддержки решений строительного контроля, а не его замена и
  не субъект приёмки.

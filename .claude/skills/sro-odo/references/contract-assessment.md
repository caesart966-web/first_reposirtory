# Оценка одного договора

Режим «договор на входе — заключение на выходе». Отвечает на два вопроса
и обосновывает каждый шаг нормой:

1. **Требуется ли подрядчику членство в СРО по этому договору?**
2. **Входит ли договор в совокупный размер обязательств по КФ ОДО?**

Плюс третий, для разделения цены: **какие виды работ по договору относятся
к СРО, а какие нет** — построчно, с пунктом Перечня 624.

## Что читает Claude и куда кладёт

Из договора и приложений заполняется карточка
`schemas/contract-card.schema.json`. Каждое поле — с `basis`: пункт
договора, цитата, документ. Неизвестное — `null`.

| Поле | Откуда | На что влияет |
|---|---|---|
| `contract.kind` | предмет, порядок сдачи-приёмки, название не решает (ст. 431 ГК РФ) | шаг 1 |
| `contract.mixed_parts` | предмет и цена по частям | шаги 1, 4 |
| `contract.price_rub`, `addenda` | цена с НДС с учётом всех ДС | шаг 4, суммы |
| `contract.procurement` | преамбула («по итогам аукциона № …»), протокол, письмо заказчика | шаг 5 |
| `contract.status`, `has_final_act`, `executed_rub`, `termination_document` | акты, соглашение о расторжении | шаг 5, остаток |
| `customer.kind` | разрешение на строительство, проектная декларация, договор техзаказчика | шаг 3 |
| `object.is_capital`, `permit_required`, `housing_type`, `category` | проектная документация, ЕГРН, ст. 48.1 | шаг 2, звёздочки |
| `work_type` | строительство / реконструкция / капремонт / текущий ремонт / благоустройство | шаг 2 |
| `works[]` | предмет, ВОР, смета, приложение с ценами | разбор видов работ |
| `member.role`, `member.is_state_entity` | шапка договора, ЕГРЮЛ | шаги 3, исключение |

## Шаги и нормы

| Шаг | Вопрос | Нормы |
|---|---|---|
| 1. Вид договора | подряд (строительный, ПИР, снос) / поставка / услуги / аренда / смешанный | ст. 702, 740, 758, 506, 779, 606, п. 3 ст. 421, ст. 431 ГК РФ |
| 2. Объект и характер работ | ОКС? разрешение? ИЖС и приравненные? строительство/реконструкция/капремонт или текущий ремонт/благоустройство? категория ст. 48.1? | пп. 10, 10.2, 13, 14, 14.2, 14.4 ст. 1, ч. 17 ст. 51, ст. 48.1 ГрК РФ; п. 2 приказа 624; примечание к Перечню; письмо 33838-КК/08 |
| 3. Стороны | член СРО — подрядчик? заказчик — застройщик / техзаказчик / эксплуатант / региональный оператор? исключение ч. 2.2 ст. 52 для подрядчика? | пп. 16, 22 ст. 1, ч. 2, 2.1, 2.2, 4 ст. 52, ч. 4 и 4.1 ст. 48, ч. 2 и 2.1 ст. 47 ГрК РФ; письмо Минстроя № 18965-ОС/02 |
| 4. Порог | 10 млн ₽ (стройка), 1 млн ₽ (снос), без порога (ПИР); для смешанного — по строительной части | ч. 2.1 ст. 52, ч. 5 ст. 55.31, ч. 4 ст. 48, ч. 2 ст. 47 ГрК РФ; 124-ФЗ |
| 5. Совокупный размер | конкурентный (44-ФЗ, 223-ФЗ, обязательные торги) — входит; добровольный тендер и прямой — не входят, уведомляются (policy.json); ниже порога — не входит; исполнен / расторгнут; остаток = цена − принято по актам | ч. 3 и 4 ст. 55.8, ч. 7 ст. 55.13, ч. 11, 13 ст. 55.16, ч. 1 ст. 60.1 ГрК РФ; 309-ФЗ; ст. 753 ГК РФ; п. 1.2 Положения СРО о КФ ОДО |
| 6. Виды работ | по Перечню 624 с учётом звёздочек и категории объекта | приказ 624, примечание, ст. 48.1; ст. 506, 779, 606 ГК РФ для «не работ» |

Полное содержание норм — `scripts/data/law.json`; в заключении выводится
раздел «Нормы, на которые опирается заключение» с сутью каждой.

## Как читать вердикт

- `membership_required`: **yes** — членство обязательно; **no** — не
  требуется (в `summary` сказано почему); **conditional** — зависит от
  подтверждения (заказчик-учреждение, физлицо, части смешанного договора);
  **needs_facts** — без недостающих фактов вывода нет.
- `counts_for_odo`: **yes** — входит (конкурентный договор с подходящим
  заказчиком, в том числе ниже порога — по `policy.json`); **no** — не входит
  (прямой договор, субподряд, исполнен, расторгнут, не подряд);
  **conditional** — заказчик-учреждение или физлицо без подтверждения,
  части смешанного договора без цен; **needs_facts**.
- Суммы: `amount_total_rub` — цена; `amount_sro_rub` — часть по работам
  Перечня; `remaining_rub` — остаток; `remaining_sro_rub` — остаток по
  работам Перечня. Доля считается по стоимости видов работ; если цен нет —
  по числу строк с пометкой «приближение».
- `confidence` — снижается за каждый недостающий факт, каждое условие и за
  нерешённые строки; не выше уверенности извлечения со скана.

## Команды

```bash
python3 scripts/assess.py card.json -o assessment.json --md zaklyuchenie.md
python3 scripts/validate.py card.json --schema contract-card
python3 scripts/cases.py find card.json
```

## Чего скилл не делает

Не назначает статус заказчика и категорию объекта, не переводит спорную
строку в «СРО» без основания, не выносит вердикт о превышении уровня.
Всё это — `references/human-in-the-loop.md`.

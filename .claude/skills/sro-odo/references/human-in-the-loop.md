# Human-in-the-loop

Скилл советует, человек решает. Границы зашиты в скрипты и схему.

## Никогда не автоматизируется

- **Вердикт о превышении уровня.** `odo.py` выдаёт суммы и справочно
  уровень по таблице закона; сравнивать с фактическим уровнем члена и
  делать вывод о нарушении — человек, по выписке из реестра СРО.
- **Категория объекта по ст. 48.1 ГрК РФ.** `objects[].category` задаёт
  человек и указывает источник. Пока `unknown`, строки со звёздочкой
  в «СРО» не идут.
- **Статус заказчика.** Застройщик ли контрагент, техзаказчик ли — по
  разрешению на строительство, реестру застройщиков, тексту договора.
  `unknown` включается в расчёт условно с пометкой.
- **Перевод спорной строки в «СРО».** Без основания в документе строка
  остаётся «не решено» и показывается отдельной суммой.
- **Изменение сумм.** Числа в реестре — из документов; если документ
  прочитан плохо, исправляется чтение, а не число «по смыслу».

## Что обязательно уходит человеку (`review_queue`)

1. Строки с `review_status: pending` — уверенность ниже порога, ничья
   между правилами с разным итогом, звёздочка при незаданной категории,
   ничего не совпало.
2. Объекты с категорией `unknown`, если по ним есть договор в расчёте.
3. Договоры с заказчиком `unknown` или способом заключения `unknown`.
4. Договоры без сметы: доля СРО в остатке оценена по актам.
5. Договоры без документов: остаток без разделения.
6. Предупреждения: выполнено больше цены, строка без суммы, документ
   без договора.

## Действия человека над строкой

| Действие | `review_status` | Что происходит |
|---|---|---|
| Подтвердить предложение | `confirmed` | строка считается решённой, `classify.py` её больше не трогает |
| Исправить | `corrected` | в `classification` — новое решение, в `human_note` — почему |
| Отклонить (не работы, не по этому договору) | `rejected` | строка исключается из сумм, остаётся в реестре |
| Оставить | `pending` | сумма идёт в «не решено» |

## Почему так

Отчёт попадает проверяющему СРО и может лечь в основу предписания.
Ошибка «в пользу СРО» (лишняя сумма в остатке) стоит компании
дополнительного взноса; ошибка «в пользу компании» — дисциплинарного
взыскания. Скилл не берёт на себя ни ту, ни другую: он показывает обе
границы и всё, что между ними не решено.

# База прецедентов

Решённые договоры, возражения и строки — то, на чём скилл учится от
договора к договору. Одна запись = одно решение человека с основанием.

- `index.jsonl` — по записи в строке, читается `cases.py`.
- `case-ГГГГ-NNN.json` — та же запись отдельным файлом.

**Записи анонимны.** Имена сторон, ИНН, номера договоров и адреса
не сохраняются: только признаки (вид договора, статус заказчика, ценовая
полоса, слова предмета, виды работ), решение скрипта, решение человека
и нормы. Полные материалы дела остаются у владельца вне репозитория.

Как пополняется:

```bash
python3 scripts/cases.py add --from-assessment a.json --decision "…" --note "…" --by "…"
python3 scripts/cases.py add --from-objection o.json --decision "…" --note "…"
python3 scripts/cases.py find card.json      # похожие прецеденты
python3 scripts/cases.py suggest             # заготовки правил из расхождений
```

Первые две записи — учебные, по вымышленной компании из
`examples/contract-demo/`.

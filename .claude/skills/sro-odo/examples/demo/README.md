# Учебный пример

Вымышленная компания ООО «Пример-Строй»: пять договоров, показывающих все
ветки логики.

| Договор | Что показывает |
|---|---|
| ГП-01/2026 — генподряд у застройщика, конкурентный | входит в расчёт; смета делит цену на СРО/не СРО (монолит и наружные сети — СРО; кладка и кровля со звёздочкой на обычном объекте — не СРО; отделка и благоустройство — не в Перечне; поставка лифтов — не работы) |
| СП-07/2026 — субподряд у генподрядчика | не входит: заказчик не застройщик |
| ПД-03/2026 — проектирование для техзаказчика | отдельный вид СРО; сметная документация и дизайн-проект — не СРО; раздел ЭО со звёздочкой при незаданной категории объекта — решает человек |
| ОХР-11/2026 — охрана, компания — заказчик | не входит: не подряд, и роль — заказчик |
| КР-05/2026 — капремонт ниже 10 млн ₽, без документов | флаг «ниже порога», остаток не разделён |

Файлы: `register.json` (после `classify.py`), `result.json`, `summary.md`,
`report.html`. Пересобрать:

```bash
python3 scripts/classify.py examples/demo/register.json --force
python3 scripts/odo.py examples/demo/register.json -o examples/demo/result.json --md examples/demo/summary.md --quiet
python3 scripts/report.py examples/demo/result.json -o examples/demo/report.html --register examples/demo/register.json
```

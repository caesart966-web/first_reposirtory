# Структура разбора письма и проекта ответа

Строит `objection.py --md`.

1. **Шапка.** От кого, дата, номер, суть письма, договор.
2. **Итог** одной строкой: доводы обоснованы / частично / не обоснованы /
   требуют документов — и что это значит для учёта договора.
3. **Доводы и их оценка.** Для каждого: заголовок типа и статус, цитата
   из письма, объяснение, «Основание: …», «Нужно представить: …».
4. **Проект ответа.** Обращение, по пунктам: «По доводу о том, что … —
   принимается / принимается частично / не может быть принят / необходимы
   документы», объяснение, нормы, просьба представить документы. Итоговая
   фраза о судьбе договора.
5. **Нормы** с сутью.
6. Пометка о сверке норм.

Проект ответа — черновик для юриста: реквизиты, тон, подпись, сроки ответа
по внутренним документам СРО — человек.

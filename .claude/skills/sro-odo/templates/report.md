# Структура отчёта проверяющему

`report.py` строит HTML по этой структуре. Здесь же — сопроводительное
письмо, которое пишется руками.

## Отчёт (HTML)

0. **Шапка.** Компания, ИНН, членство (СРО, номер, уровни — из выписки),
   дата расчёта, базис (с НДС / без), дата формирования. Дисклеймер:
   информационный расчёт, числа со сканов подлежат сверке, вердикт
   о соответствии уровню — не здесь.
1. **Итог: все подходящие договоры.** По видам СРО: договоров, цена,
   из них СРО, выполнено, из них СРО, остаток, остаток СРО, остаток
   не разделён, выполнено не решено.
2. **Итог: только конкурентные.** Та же таблица по выборке `competitive_only`.
3. **Справочно: уровень по ст. 55.16.** Какой уровень минимально покрывает
   остаток СРО, остаток без разделения, цену СРО; заявленный уровень.
4. **Договоры.** Таблица: договор, контрагент и его статус, вид, способ,
   в расчёт / нет, цена, выполнено, остаток, остаток СРО.
5. **Разбор по договорам.** Для каждого: основания включения/исключения,
   четыре числа (цена, из них СРО, выполнено, остаток), таблица строк:
   документ, строка, сумма, итог (СРО / не СРО / решает человек),
   код Перечня, основание.
6. **На проверку человеку.** Список из `review_queue`.
7. **Предупреждения.** Из `warnings`.
8. **Источники.** Документы: вид, номер, дата, договор, суммы, файл,
   уверенность извлечения.
9. **Методика.** Четыре правила из `method_notes`.

## Сопроводительное письмо (Markdown, пишется вручную)

```
Кому: [проверяющий / компания]
Что приложено: register.json, summary.md, report.html

1. Что считали: обязательства [компания] по договорам подряда на [дата].
2. Какие документы были: [опись]. Каких не хватает: [КС-2 по договору …,
   смета по …, выписка из реестра СРО].
3. Решения, принятые человеком: категория объектов, статус заказчиков,
   способ заключения, спорные строки — с датой и кем.
4. Итог в двух числах на вид СРО: остаток по договорам целиком и остаток
   только по работам СРО; отдельно — что не разделено и не решено.
5. Что не сверено: Перечень 624 с официальным текстом; редакция ч. 3
   ст. 55.8 после 309-ФЗ; положение о контроле конкретной СРО.
```

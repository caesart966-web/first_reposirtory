# Структура заключения по договору

Строит `assess.py --md`. Раздел за разделом:

1. **Шапка.** Номер и дата договора, подрядчик (член СРО), заказчик и его
   статус, объект, цена, способ заключения.
2. **Вывод.** Четыре строки: обязательное членство (да / нет / условно /
   нужно установить) и вид СРО; входит ли в совокупный размер по КФ ОДО;
   остаток обязательств и его часть по работам Перечня 624 с долей;
   уверенность. Ниже — вывод одним абзацем.
3. **Разбор по шагам.** Шесть шагов (вид договора; объект и характер работ;
   стороны; порог; совокупный размер; исполненная часть), у каждого —
   объяснение, «Основание: …» со ссылками на нормы, «Нужно установить: …».
4. **Виды работ.** Таблица: вид работ, сумма, итог (СРО / не СРО / решает
   человек), пункт Перечня со звёздочкой, основание с нормами.
5. **Что нужно установить** для окончательного вывода.
6. **Похожие прецеденты** из базы, если есть.
7. **Нормы**, на которые опирается заключение: ссылка и суть каждой.
8. Пометка о том, что нормы не сверены с официальным текстом.

Сопроводительное письмо к заключению пишется руками: кому, по какому
запросу, какие документы были, какие решения принял человек.

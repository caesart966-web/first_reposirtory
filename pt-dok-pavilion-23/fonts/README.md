`osifont-lgpl3fe.ttf` — чертёжный шрифт по ISO 3098 (https://github.com/hikikomori82/osifont),
лицензия GNU LGPL 3 с исключением для шрифтов. Нужен только для вывода PDF: в DXF стиль
текста ссылается на `isocpeur.ttf`, который есть в AutoCAD, а при выводе листов вместо
него подставляется этот файл (`src/export.py`).

Файл исправлен: в исходном шрифте вместо «ё», «Ё» и «Э» печатался чёрный прямоугольник.
У «ё» и «Ё» (U+0451, U+0401) удалён лишний прямоугольный контур; «Э» (U+042D) в шрифте
не было, она построена зеркальным отражением «Є».

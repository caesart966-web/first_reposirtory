## Как пересобрать

Фамилии в основной надписи (Разраб., Пров., Н.контр., ГИП) вписываются в `src/stamp.py`,
после чего комплект пересобирается. Текст на листах — чертёжным шрифтом: в DXF стиль ссылается
на `isocpeur.ttf` из AutoCAD, для PDF используется близкий к нему свободный osifont (`fonts/`).
PDF выводятся чёрно-белыми, как при печати с monochrome.ctb: цветное — чёрным, подоснова АР и заливки —
серым (`export.py`). Надписи на листах приводятся к тому, как их набирают в AutoCAD (`ru.cad`): «отм. -1,900»
вместо значка отметки в строке, дефис вместо длинного тире, «2хДу150».

Нужны Python 3.13 (проверено) и пакеты `ezdxf==1.4.4`, `matplotlib`, `pymupdf`, `reportlab`, `openpyxl`.

```bash
cd src
python3 design.py        # модель сети -> model.json
python3 hydro.py         # диаметры и гидравлика -> model_sized.json, hydro_report.json
python3 calc_final.py    # насосы, ВПВ, давления -> calc_final.json
python3 bom.py && python3 cables.py && python3 spec_data.py   # ведомости и спецификация
python3 build_all.py     # DXF + PDF всех листов + альбом (около 4 минут)
python3 build_all.py 5 9 # только PDF выбранных листов (DXF пересобирается целиком)
```

Трассы раздела ВК — `src/vk_nets.json` (см. «Увязка с разделом ВК»): при новой версии ВК выгрузить DWG
`tools/vk_dump.mjs` (npm `@mlightcad/libredwg-web@0.7.17`), пересобрать `tools/vk_extract.py` и цепочку.

# Сайт частного специалиста по СРО

Одностраничный сайт (landing page) независимого эксперта, который помогает компаниям и ИП
вступить в СРО, подобрать и проверить СРО, подготовить документы, решить вопросы НРС и НОК
и получить сопровождение.

## Стек

- React 18 + TypeScript
- Vite 5
- Tailwind CSS 3
- lucide-react (иконки)
- Inter Variable (шрифт, локально через `@fontsource-variable/inter` — без внешних запросов)

Без бэкенда, без роутера, без тяжёлых зависимостей. Все изображения — SVG.

## Запуск

```bash
cd sro-site
npm install
npm run dev        # http://localhost:5173
npm run build      # typecheck + прод-сборка в dist/
npm run preview    # локальный просмотр прод-сборки
```

## Перед публикацией: замените плейсхолдеры

Реальные данные пока не предоставлены, поэтому в проекте используются заглушки.

| Плейсхолдер | Где заменить |
| --- | --- |
| `[ИМЯ]`, `[ТЕЛЕФОН]`, `[EMAIL]`, `[WHATSAPP_LINK]`, `[MAX_LINK]` | `src/content/contacts.ts` — единственное место, весь сайт обновится сам |
| `[ЦЕНА]` (3 шт.) | `src/components/Pricing.tsx` |
| Домен (`https://example.com/`) | `index.html` (canonical, og:url), `public/robots.txt` (Sitemap) |
| Title / description под имя специалиста | `index.html` |

Пока заглушки не заменены, кнопки «Позвонить / WhatsApp / MAX» ведут к блоку контактов
(`#contacts`); после замены они автоматически становятся ссылками `tel:`, `mailto:`
и ссылками на мессенджеры (логика — в `src/content/contacts.ts`).

## Приём заявок из квиза

Форма работает без перезагрузки страницы. После заполнения посетителю предлагается
отправить готовый текст заявки (ответы квиза + контакты) в один клик — в WhatsApp
или на e-mail (ссылки формируются автоматически после замены плейсхолдеров).
Автоматическую отправку (backend, email-сервис, CRM, бот) подключите в
`src/lib/lead.ts` (функция `sendLead`); до подключения заявка дополнительно
выводится в консоль браузера.

«Политика конфиденциальности» и «Согласие на обработку персональных данных»
открываются из футера и из чекбокса формы как модальные окна с **шаблонными**
текстами (`src/components/LegalDocs.tsx`) — перед публикацией замените их
финальными редакциями документов.

Перед публикацией также стоит добавить `og:image` (баннер 1200×630 в `public/`
и тег в `index.html`) — сейчас Open Graph работает без картинки.

## Структура

```
sro-site/
├── index.html                  # SEO: title, description, OG, canonical, robots, favicon
├── public/                     # favicon.svg, robots.txt
└── src/
    ├── content/contacts.ts     # все контакты и плейсхолдеры (единая точка правды)
    ├── lib/lead.ts             # точка интеграции формы заявки
    ├── components/
    │   ├── ui/                 # Button, Section/SectionHeading, Reveal (scroll-анимация)
    │   ├── Header.tsx          # sticky-шапка + мобильное меню
    │   ├── Hero.tsx            # заголовок + SVG-композиция из 4 этапов
    │   ├── Services.tsx        # 8 услуг
    │   ├── Problems.tsx        # 4 типовые ситуации
    │   ├── Process.tsx         # 4 шага работы
    │   ├── AboutExpert.tsx     # «специалист, а не отдел продаж» + 6 преимуществ
    │   ├── Pricing.tsx         # 3 формата работы (цены — плейсхолдеры)
    │   ├── Quiz.tsx            # пошаговый квиз (4 вопроса + форма контактов)
    │   ├── Documents.tsx       # состав пакета документов
    │   ├── Trust.tsx           # полоса доверия
    │   ├── FAQ.tsx             # аккордеон, 9 вопросов
    │   ├── FinalCTA.tsx        # тёмный финальный призыв
    │   ├── Contacts.tsx        # кликабельные контакты
    │   ├── Footer.tsx
    │   └── MobileBar.tsx       # фиксированная нижняя панель на мобильных
    └── index.css               # Tailwind + reveal-анимации + reduced-motion
```

## Принципы контента

На сайте нет фотографий, отзывов, выдуманных цифр, достижений, лицензий, цен и сроков —
только описание услуг и формата работы. Всё, что требует реальных данных, вынесено
в плейсхолдеры. Анимации лёгкие (fade/reveal/hover) и отключаются при
`prefers-reduced-motion`.

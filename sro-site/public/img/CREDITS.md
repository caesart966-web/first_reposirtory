### design.webp / design.avif — проектирование

| Поле | Значение |
|---|---|
| Статус | **боевой кадр установлен** |
| Где на странице | секция «Документы», левая колонка |
| Что на кадре | архивная синька: продольный разрез жилого дома, лестничные марши, перекрытия |
| Размер | 1200×900, `aspect-[4/3]`, 84 КБ WebP / 63 КБ AVIF |
| URL источника | https://unsplash.com/photos/9tmKEDz03uw |
| Автор | Amsterdam City Archives (Городской архив Амстердама) |
| Лицензия | Unsplash License |
| Дата получения | 27.08.2026 |
| Обработка | кадрирование + `scripts/prepare-photo.py … design --width 1200 --normalize --webp-quality 74 --dark 700` |

Архив выложил на Unsplash 227 своих работ бесплатно:
https://unsplash.com/@amsterdamcityarchives

Исходник 2000×1619, обрезан до 4:3 по самому чертежу: рамка оттиска ушла за
кадр целиком, чтобы в углах не висели обрывки линеек.

Два отступления от обычного рецепта, оба вынужденные:

- **`--normalize`.** Цианотипная синька малоконтрастная: весь диапазон яркости
  сидит в середине, и дуотон без растяжки гистограммы давал вялое сиреневое
  пятно вместо чертежа. С растяжкой фон садится в accent-900, линии выходят
  почти белыми — кадр совпадает с фирменным синим сам собой.
- **`--webp-quality 74`** вместо 82. Растяжка вытягивает и зерно бумаги, на
  82 файл весил 142 КБ. На 74 — 84 КБ при тех же линиях; проверял увеличением,
  штрих не поплыл.
- **`--dark 700`** — нижняя точка дуотона поднята с accent-900 до accent-700.
  На accent-900 фон синьки (81% кадра) давал кадру среднюю яркость 92, и среди
  светлых соседей (папки 218, тахеометр 161) он читался тёмным пятном. Из трёх
  плотностей заказчик выбрал среднюю (117): вариант на accent-600 попадал в
  формальную цель 120–140, но фон совпадал с цветом кнопок сайта и кадр
  начинал «звенеть» — новый конфликт вместо решения старого.

### legal.webp / legal.avif — юридическая часть

| Поле | Значение |
|---|---|
| Статус | **боевой кадр установлен** |
| Где на странице | секция «Услуги», блок «Смежные юридические задачи» |
| Что на кадре | штриховой рисунок: равновесные аптекарские весы с двумя чашами |
| Размер | 1200×1238, рамка `aspect-[4/3]` с `object-contain`, 79 КБ WebP / 27 КБ AVIF |
| URL источника | https://www.rawpixel.com/image/6271178/png-sticker-vintage |
| Автор | не указан; изображение архивное |
| Лицензия | Public Domain (Rawpixel) |
| Дата получения | 27.08.2026 |
| Обработка | `scripts/prepare-photo.py … legal --width 1200 --cutout` |

Два отступления от ТЗ, оба по факту исходника:

- **Размер 1200×1238 вместо 1200×800.** Это вырезанный объект, а не фотография:
  подгонять его под прямоугольник нечем, `object-cover` отрубил бы чаши и
  основание. Поэтому у `Figure` появился проп `fit`, и весам поставлен
  `contain` внутри рамки 4:3 — объект вписывается целиком.
- **Флаг `--cutout` вместо обычного дуотона.** В присланном файле прозрачности
  не оказалось: она была **запечена в пиксели серо-белой шашечкой** (31.6%
  пикселей `#FFFFFF` и 28.8% `#EEEEEE`, канала альфы нет вовсе). Дуотон такого
  файла дал бы двухцветную сетку вместо весов. `--cutout` восстанавливает
  прозрачность из яркости: светлое — фон, тёмное — объект, — и заливает сам
  объект accent-900, чтобы по краям не лезла серая кайма от сглаживания.
  Разделение чистое: 86.7% пикселей ярче 237 (фон), 8.1% темнее 40 (штрих).

  Если когда-нибудь найдётся исходник с настоящей альфой, он обработается тем
  же флагом — `--cutout` сначала проверяет, есть ли альфа, и восстанавливает её
  только когда её нет.

Запрет T30 на PNG касается фотографий; на выходе здесь WebP и AVIF, оба держат
альфу, так что `legal.png` из ТЗ не понадобился.

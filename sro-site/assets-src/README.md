# Исходники кадров

Сюда кладутся оригиналы фотографий и рисунков. В сборку папка не попадает:
`public/img/` собирается из этих файлов скриптами `scripts/prepare-photo.py`
и `scripts/make-*.py`, а команда обработки каждого кадра записана
в `public/img/CREDITS.md`.

## Кандидаты, ещё не выбранные заказчиком

- `quiz-1-src.jpg` — совещание, снятое через стеклянную перегородку.
- `quiz-2-src.jpg` — совещание за столом переговоров у окна.

Оба присланы заказчиком 03.09.2026 для фона секции заявки. Собраны и
показаны обе версии; выбор за заказчиком, источник и лицензию он ещё
не назвал.

Готовые `quiz-1.*` / `quiz-2.*` в `public/img/` НЕ лежат намеренно:
проверка T31 сверяет число файлов там с числом боевых кадров в CREDITS.md,
и невыбранные кандидаты её роняют. Как заказчик выберет — кадр собирается
командой из CREDITS.md и кладётся под именем `quiz-bg`.

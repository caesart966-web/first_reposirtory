# Исходники кадров

Сюда кладутся оригиналы фотографий и рисунков. В сборку папка не попадает:
`public/img/` собирается из этих файлов скриптами `scripts/prepare-photo.py`
и `scripts/make-*.py`, а команда обработки каждого кадра записана
в `public/img/CREDITS.md`.

## Кадры видов СРО

С 25.09.2026 — серия заказчика, собирается `scripts/prepare-slide-photos.py`:
`slide-construction-src.jpg` → `public/img/hero-day.*` (кран; с 26.09.2026
он же первый экран главной — справа во всю высоту, на телефоне полосой
сверху), `slide-design-src.jpg` → `public/img/slide-design.*` (план этажа),
`slide-survey-src.jpg` → `public/img/slide-survey.*` (изыскатели на закате).
Все три стоят в шапках страниц своих видов. До 26.09.2026 все три были ещё
и слайдами первого экрана. Команда и права — в `public/img/CREDITS.md`.

Прежние исходники этих слотов остаются как история: `hero-day-src.png`,
`quiz-3-src.png` (каска с надписью «СРО», корешки кодексов, чертежи; прислан
заказчиком 03.09.2026, до 24.09.2026 из него собирался фон под квизом),
`survey-card-src.png`.

## Отклонённые кандидаты

- `quiz-1-src.jpg` — совещание, снятое через стеклянную перегородку.
- `quiz-2-src.jpg` — совещание за столом переговоров у окна.

Оба присланы заказчиком 03.09.2026 и проиграли кадру со «СРО»: он по теме,
а у них центр занят людьми — ровно там, где лежала белая карточка квиза.
Оставлены на случай, если понадобится кадр с людьми в другой слот.

Готовых `quiz-1.*` / `quiz-2.*` в `public/img/` нет намеренно: проверка T31
сверяет число файлов там с числом боевых кадров в CREDITS.md, и невыбранные
кандидаты её роняют. Собирать их заново — командой из CREDITS.md.

## Откуда взялась ссылка на MAX

`max-qr-src.png` — QR-код профиля, присланный заказчиком. Из него получена
ссылка в `src/content/contacts.ts` (`CONTACTS.max`). Файл лежит здесь как
след происхождения ссылки: проверить её можно, только пересчитав код.
Обычные декодеры (OpenCV `QRCodeDetector`, zxing-cpp) на нём не срабатывают
— код стилизован, с логотипом в центре; берёт `cv2.wechat_qrcode`.

# Recon map: biznesgrp.ru (веб, телефон и компьютер)

Набор Replica придуман, чтобы повторить чужое приложение. Здесь он применён
к своему сайту как проверка (просьба заказчика 23.10.2026): карта — это наш
сайт как он есть, а «оригинал» в `features.csv` — что предлагают сайты
конкурентов (`competitors.md`).

Scope: весь сайт — главная, 3 страницы видов СРО, 7 страниц услуг, раздел
«Статьи» (список и 4 статьи), 404.
For: компании Ростова-на-Дону и других регионов, которым нужно вступить в СРО
строителей, проектировщиков или изыскателей, и тем, кто уже в СРО (НРС, НОК,
уровень ответственности, проверки).
Date: 2026-10-23

## Core loop

Человек понимает, нужна ли ему СРО и какая, видит, что с этим помогут честно
и по закону, и пишет или звонит — в WhatsApp с готовым началом сообщения
по теме страницы, по телефону или приходит в офис.

## Flows

```
F01 Строитель из поиска выбирает вид СРО и пишет
    S01 (карточка «Строительство…») -> S02 -> «Связаться» -> S18 -> WhatsApp
    happy path (телефон): 3 касания до мессенджера с готовым началом
    edge: без JS, медленная сеть, «Назад» из мессенджера, 320 px, уменьшить движение

F02 Человек из поиска выясняет, нужна ли СРО при договоре до 10 млн
    S14 (статья) -> «Связаться» -> S18 -> WhatsApp
    happy path: 2 касания
    edge: читает с компьютера, переходит в «Статьи по теме»

F03 Звонок с любой страницы
    значок телефона в шапке -> звонок
    happy path: 1 касание

F04 Клиент хочет прийти в офис
    S01 -> раздел «Связаться» (или «Контакты» в меню телефона) -> адрес, часы -> Яндекс Карты
    happy path: 2 касания

F05 Нужна конкретная услуга (НРС, НОК, документы)
    меню «Услуги» -> S05–S11 -> «Связаться» -> S18
    happy path: 3–4 касания

F06 Проверить, что компания настоящая
    подвал: ИНН, КПП, ОГРН строкой -> вручную в реестре
    happy path: копировать ИНН и искать самому (ссылки на реестр нет)

F07 Написать на почту
    «Связаться» -> адрес (mailto) или значок копирования -> бирка «Скопировано»
```

## Inferred data model

Сайт статический, базы нет. Данные — модули TypeScript:

```
SRO_DETAILS   slug, path, card, scope, threshold, cases, steps, documents, funds (harm, contract)
              src/content/sroDetails.ts            confidence: факт (код)
SERVICE_PAGES slug, path, short, hint, sections (rows | statement | scale | actions | cards)
              src/content/services.ts
ARTICLES      slug, title, seoTitle, description, lead, published, image, answer, sections, related, on
              src/content/articles.ts (читает и Node — без импортов значений)
CONTACTS / REQUISITES / OPENING_HOURS / MAP_URL   contacts.ts, facts.ts
REGIONS, EXTRA (лицензии), TOPICS (начало сообщения WhatsApp), IMAGES, LAW
```

Relationships: статья `on` → вид СРО или услуга («Статьи по теме»);
статья `related` → услуги («Услуги по теме»); TOPICS → кнопки `data-topic`.

## Out of scope (решения заказчика, не недоделки)

- цены и калькулятор с суммами за работу — цену заказчик называет по телефону;
- форма заявки, квиз, приём заявок — сняты 24.09.2026;
- политика обработки данных и Яндекс Метрика — без формы и счётчика они не нужны (22.10.2026);
- лицо и имя специалиста;
- отзывы, число клиентов, годы работы — данных нет, выдумывать нельзя.

и браузера (`hydrateRoot`), смена страниц (`@view-transition`), контраст
надписей на фотографиях. Размер набора по шкале Replica — M (уже сделан).

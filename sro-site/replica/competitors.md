# Конкуренты biznesgrp.ru: что есть на их сайтах

Дата: 23.10.2026. Метод — replica-recon, правила «только публичное, читаем, а не выкачиваем»:
без входа в аккаунты, без обхода сайтов, без JS-бандлов и сетевых запросов страниц.

## Главная оговорка: ни один сайт не открылся

- **WebFetch** не работает в этой среде вообще: `getaddrinfo ENOTFOUND` на любом адресе, включая
  ru.wikipedia.org.
- **Прокси среды** отвечает `403` (запрет сетевой политики) на все 8 сайтов конкурентов, проверено
  одним запросом к главной каждого (журнал прокси: `connect_rejected … policy denial`). Обходить
  запрет (зеркала, архивы) не пробовал — так велит правило среды.
- Поэтому **всё ниже — «по выдаче поиска»**: заголовки страниц и фрагменты, которые показал
  WebSearch (запросы с ограничением на один домен). Читано страниц напрямую: **0**.
- Виды пометок в таблице:
  - **да** — видно в заголовке страницы из выдачи или в дословном фрагменте выдачи (в кавычках);
  - **да°** — только в пересказе поисковой системы, без дословного фрагмента. Надёжность ниже;
  - **не видно** — в выдаче не встретилось. **Это не значит «нет на сайте»**: виджеты чата,
    кнопки мессенджеров, карты, формы, реквизиты в подвале и политики поиск показывает редко. По этим
    строкам числа — нижняя граница;
  - **нет°** — в выдаче есть прямо противоположное утверждение.
- Цитаты — короткие фразы, только чтобы показать формулировку. Тексты конкурентов не копировались.

# Компоненты biznesgrp.ru (replica-design, 23.10.2026)

Цвета — роли из `tokens.json` (там же пары контраста). Наведение у кнопок
и стрелок — только при `@media (hover: hover)`: на телефоне касание
оставляло «наведение» включённым.

```
Button («Связаться», кружок со стрелкой)
  variants  на светлом (графит), на тёмном (крем), на кадре
  sizes     высота от 44 px
  states    default, hover (только hover:hover), focus-visible, active
  tokens    text / on-dark, кружок accent-line
  a11y      ссылка или кнопка с текстом; до 1024 px открывает ContactSheet,
            «Контакты» в меню телефона — переход к разделу (data-direct)
  used on   все страницы

GoTo (простая стрелка перехода)
  states    hover только hover:hover; кружка нет нарочно — он только у «Связаться»
  used on   карточки услуг, статьи, «Услуги по теме», «Статьи по теме»

Карточка услуги (Services)
  variants  светлая (строка на телефоне, карточка с 640 px), тёмная «Бесплатная консультация»
  states    hover/focus с 640 px — карточка темнеет; на телефоне фокус — кольцо
  tokens    ring-soft (accent-400) на светлом — 2,3–2,5:1, ниже 3:1 → заменить на accent-600 (bugs.md, B01)

ContactSheet (<dialog>)
  states    открыта, закрыта; тема WhatsApp из data-topic
  a11y      showModal, закрытие Esc и кнопкой, фокус возвращается

Header
  variants  компьютер: выпадающие «Виды СРО» и «Услуги»; телефон: лист меню поверх страницы
  states    отмеченная открытая страница, «Перейти к содержанию» → main#main

PageExtras
  parts     «Сколько стоит» (две строки без цифр), «Услуги по теме», «Статьи по теме»
  note      на статье «Сколько стоит вступление в СРО» повторяет её последний раздел (bugs.md, B02)

Article blocks
  kinds     p, list, rows, note, links (кнопки реестров), tables (уровни фондов)
  a11y      у таблиц caption, th scope="col"

Footer
  parts     знак строкой бланка, три группы ссылок (на телефоне раскрываются), реквизиты ИНН/КПП/ОГРН
  note      год в «©» считается в отрисовке; при смене года ошибок нет (проверено часами 02.01.2027)
```

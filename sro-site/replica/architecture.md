# Architecture: biznesgrp.ru (как есть, 23.10.2026)

Шаг replica-architect для своего сайта: стек не выбирается заново, а
записывается как есть, с тем, что в нём может подвести. Базы, входа
и оплаты нет и не нужно: сайт рассказывает и ведёт к звонку или сообщению.

## Stack

| layer | choice | why |
| --- | --- | --- |
| web | React 18 + TypeScript, Vite 5, Tailwind 3.4, lucide-react | уже работает; страниц мало, данные в коде |
| render | готовая разметка при сборке (`entry-server.tsx` → `scripts/prerender.mjs`), в браузере `hydrateRoot` | текст виден до скрипта, поисковику — сразу |
| pages | отдельный HTML на каждую страницу (`vite.config.ts`, `rollupOptions.input`); статьи — `scripts/build-articles.mjs` | обычные адреса без маршрутизатора в браузере |
| data | модули `src/content/*.ts` | одна точка правды на факт |
| database / auth / payments / email / jobs | нет | формы и оплаты нет по решению заказчика (24.09.2026) |
| SEO | JSON-LD (`build-jsonld.mjs`), карта сайта, свой `og:image` у страниц | |
| hosting | Timeweb, архив `dist` без `api/` | заливает заказчик |
| preview | GitHub Pages из `main` (`.github/workflows/deploy-orders-app.yml`) | |

## The parts that bite

- **Разметка сборки и браузера обязаны совпасть узел в узел.** Любое
  `window`, `document` или `typeof window` в отрисовке — расхождение и ошибка
  в консоли. Год в «©» подвала считается в отрисовке (`new Date()`);
  проверено часами 2 января 2027 года: браузер показывает 2027 без ошибок
  в консоли, так что это не ошибка, но новых значений «от времени»
  в отрисовку не добавлять.
- **Смена страниц** (`@view-transition`) включается, только если стили
  применены к первой отрисовке — строчка `TAIL` в конце `<body>` не удалять.
- **Кеш картинок** — отпечаток `?v=` в адресе (`asset()`), иначе после замены
  кадра браузер показывает старый.
- **Контраст надписей на фотографиях** меряется по пикселям
  (`test-hero-contrast.mjs`), статический расчёт его не видит.
- **Сервер.** Своего `.htaccess` нет: перенаправления на https и без www,
  страница 404 и кеш — на настройках хостинга (deploy.md, проверки).
- **Числа и нормы закона** — только сверенные; суммы фондов в статье
  о стоимости сверяет с таблицами страниц видов `test-site.mjs`.

## Build order

Сайт собран. Порядок сборки архива:
`npm run build` → `node scripts/build-og.mjs --pages` → `npm run articles` →
`npm run build` → проверки → `zip` из `dist` без `api/`.

# Задача: заполнить email для 1199 компаний в "Компании (4).xlsx"

## Решения заказчика (зафиксировано)
- Полный проход по ВСЕМ 1199 (не пилот).
- Ненайденные -> в ячейку email текст: "нет в открытых источниках".
- Почта принимается ТОЛЬКО если привязана к точному ИНН. Почта похоже
  названной компании с ДРУГИМ ИНН - не берётся ни при каких условиях.

## Среда
- Работает только WebSearch. curl/WebFetch к .ru и агрегаторам заблокированы
  политикой egress (403 CONNECT). Сайты компаний не резолвятся.

## Файлы
- work/todo.json  - очередь 1199, поле seq = порядок (1 = самый перспективный)
- work/found.json - {inn: {email, source, note}} накопленные находки
- work/done.json  - {inn: true} обработанные (в т.ч. без находки)
- work/rec.py     - записать результат

## Запись результата
python3 work/rec.py <ИНН> <email|-> "<источник>"
  email = "-"  -> обработано, не найдено

## Финальная сборка
python3 work/build.py  -> "Компании (4) - с почтами.xlsx"

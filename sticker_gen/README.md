# Sticker Gen — пакетная генерация стикеров 512×512

Программа автоматически превращает исходные картинки персонажа в готовые
стикеры в едином стиле: прозрачный фон, белая обводка, подпись капсом с
золотым градиентом, синей обводкой и белым кантом.

## Как пользоваться

1. Положите исходные картинки (JPG/PNG) в папку `input/`.
2. Заполните `captions.csv` (UTF-8) — соответствие файла и подписи:

   ```
   filename,caption
   hero_01.jpg,Ща соображу
   hero_02.jpg,Не сдавайся!
   ```

   Если файла нет в `captions.csv` (или самого csv нет) — подписью станет
   имя файла без расширения.
3. Запустите `run.bat` (Windows) или `python main.py`.

Готовые стикеры появятся в `output/` с именами вида `01_Ща_соображу.png`;
на Windows папка с результатами откроется сама.

## Что происходит при первом запуске

- создаются папки `input/`, `output/`, `fonts/`;
- автоматически скачивается шрифт **Russo One** с Google Fonts
  (если сети нет — берётся системный шрифт);
- при отсутствии библиотек ставятся зависимости из `requirements.txt`.

Ручная установка зависимостей: `pip install -r requirements.txt`
(Python 3.10+).

## Пайплайн обработки

1. Удаление серого водяного знака в левом нижнем углу (inpaint).
2. Вырезание белого фона в прозрачность floodfill'ом от границ кадра —
   белые детали внутри персонажа (глаза, зубы, логотип) сохраняются.
3. Цветокоррекция: насыщенность ×1.18, яркость ×1.04.
4. Белая обводка 4px вокруг персонажа.
5. Вписывание персонажа во весь кадр 512×512.
6. Подпись капсом поверх нижней части персонажа: золотой градиент,
   синяя обводка, белый кант; длинный текст переносится на 2 строки,
   при необходимости кегль уменьшается.
7. Сохранение PNG 512×512 с прозрачностью.

Ошибка на одной картинке не прерывает прогон: файл логируется, обработка
продолжается, в конце печатается сводка.

## Настройка стиля

Все параметры (цвета градиента и обводок, толщины, размер текста, поля,
коэффициенты цветокоррекции) — в `config.json`. Меняйте их без правки кода.
